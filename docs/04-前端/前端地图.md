## 跨端

产品页（对话 / 文件 / IM / 设置 / 登录）走桌面 renderer 单树，壳自适应；能力黑名单减法。fold 生产实现只留桌面一套。改 fold 必跑 `pnpm conformance`。权威 → [前端技术 §五](/docs/04-前端/前端技术与架构.md)。
