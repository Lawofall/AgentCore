# AI 协作白板

> 桌面内页面（非独立 app）；空间 JSON 为真相。→ `apps/desktop/src/renderer/whiteboard/`。冲突以代码为准。

## 定位与差异

真白板（无限画布）✅。人主画；AI 助手（读图 / 摆普通形状）**⏳ 未落地**。白板不是团队进度面、不是工作区。**不做**把团队图做成对话页第三宿主（否决 → [协作图 UX §六](/docs/04-前端/协作图与双视图UX.md)）、不做独立 app。空间 JSON 与「文本典范」不冲突——scene 本质空间，文本表达不了。重叠面（团队图/mermaid/文件列表）不重做。

**前台入口（现状）**：手动画布 ✅ 可用；老板命令栏与选区 AI 动作（整理 / 让团队实现）**⏳ 暂下线**，画布不摆命令栏空壳。`sendBoardTurn` / `board_ops` / `board_read` 协议与注册保留，恢复时不开新契约。工具箱文案：「画布可用 · AI 指挥尚未开放」。跟进面 → [路线图 · AI 协作白板的 AI 指挥](/docs/01-产品/产品路线图摘要.md)。

主循环归属：支线**创作工具**；交付仍走工作区（「收」）。AI 指挥未落地前不是交付主路径 → [定位 §二](/docs/01-产品/产品定位与品牌.md)。

## 关键决策

| # | 决策 |
|---|---|
| 形态 | desktop 路由 `/whiteboard`；工具箱入口，**不**进侧栏主导航 |
| 引擎 | 自研 Canvas 2D；文字就地编辑挂 React。导图若开工，在本引擎注册树形状，不另起无限画布、不迁入外部仓。→ [引擎按需求改什么](#引擎按需求改什么) |
| 归属 | 账号级独立，不挂文件夹；专用 AI 对话为裸聊。独立 `boards` 表 + scene blob（<256KB JSONB，否则 S3）+ CAS version。列 `folder_id` 残留不读（不是以后会读）。**否决**挂到工作区 / 当场选桌 |
| AI 写 | 结构化 `board_ops`（catalog 工具），非裸 REST、非整图生成；形状闭集 = 便利贴 / 方 / 圆 / 菱 / 字 |
| 读图 | 选区混合：结构→JSON，手绘/截图→栅格化→`VisionReader` |
| 团队 | 复用 `sendBoardTurn` + CEO `delegate`/`debate`；**零新编排/fold**。进度看协作图，成品进工作区 |
| 前台闸 ⏳ | AI 入口暂关（命令栏 + 选区 AI）；画布与后端能力保留 |
| 画布导航 | 左侧大纲（按类型分组；单击选中、双击缩放到元素）。**不做**资源库搜索 Tab、**不做**画布内 AI 对话栏 |
| 属性栏 | 选中后右侧停靠变换 + 样式（单选 Tab；多选对齐 / 批量样式）。选区旁不再跟悬浮条。**不做**超链接 / 业务 Section |

**否决**：独立 web app；stock Excalidraw（美学+形状不归自己）；tldraw（授权）；Fork Excalidraw（merge 税）；侧栏直达；`briefRegion` 原生形状（brief=选区/`frame`）；创建时挂文件夹（board ∈ folder）；当场选桌 / 实现到工作区；**第二套无限画布引擎**（导图 / 幻灯片帧另起炉灶）；把画布做成工作区容器；协作图 / 工作流 DAG 并进此引擎；**整仓迁入参考实现**（参考只借分层思路）；**团队以专用卡住在白板**（队员卡 / 产物卡 / 进度贴上板 / 结晶化——看已有协作图，收已有工作区；圈选「照这实现」若再开，板上最多用普通便利贴留一句）。

## 引擎按需求改什么

主循环归属：支线创作。引擎只服务「人画 + 日后 AI 共编同一份 scene」，不为把团队搬上板而改。

| 谁 | 要什么 |
|---|---|
| 人 | 手绘、形状、便签、图 |
| 日后 AI 指挥 | 共编同一份板：`board_ops` 摆普通形状、`board_read` 读图 |
| 日后导图 | 同一引擎加树形状，不新开画布内核 |

**要改**：无。文字就地编辑：引擎只持会话；输入框由 React 钉在元素屏幕框上（平移 / 缩放 / 旋转跟手）；几何与手绘仍走 Canvas。不为便签常驻 HTML，不为对齐参考仓拆 Store / 空间索引 / LOD。导图开工时再注册树形状，**现在不实现导图交互**。

**不改**

手绘与基础几何手感；`boards` CAS；`agentcore-board` scene；`board_ops` 动词；`sendBoardTurn` / 零新编排；账号级归属；产品入口。板小，不做 500 节点空间索引与 LOD。History 整表快照先留。未知元素类型解析时丢弃（内测，无兼容层）。

**导图**：产品仍观察、创作页卡不可点。约束只是开工时走本引擎，禁止另起无限画布。文档 / 表格不进此引擎。

## 引擎不变量

历史深拷不别名；仅 engine 持可变态；编组扁平；箭头绑定删除连带；CAS 冲突不覆盖；applier 仅画布打开时在册。瞬时 overlay 不进 history / 不落盘 / 不命中。文字编辑草稿在宿主输入框，load / undo / 指针提交前同步 flush。配色走 token。→ `WhiteboardApi`（`whiteboard/types.ts`）。
