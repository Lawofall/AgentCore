## 一、全局布局与侧栏

侧栏 + 页面自布局；对话页单栏聊天。**窄屏壳**（<768px）：☰ overlay 打开与宽屏同一棵侧栏（不上工具箱）+ 右坞改全屏 sheet；文件 / IM / 设置是列表推进详情（设置入口不上 Git / 通用 / 快捷键），产品页仍是这棵树 → [前端技术 §五](/docs/04-前端/前端技术与架构.md)。内嵌图「在画布打开」→ `TurnDetailPage`；点节点 → 宽屏 SidePanel run tab / 窄屏 sheet。输入框：空草稿居中（`card` 摊开配置），首条后 FLIP 落底（`bar`：＋收纳配置 · 输入 · 语音 · 发送）。当前这场「收到的上下文」窗口环贴在**整块输入框外侧右边**（不进卡片、不跟发送簇；与底排＋/语音/发送同一行盒，不贴卡片底边），`run_context` 到即亮、不等停笔；有 `last_prompt` 与目录窗口后画填充环（占模型总上下文），气泡底栏「收到的上下文」仍留当时快照 → [上下文传递可视化](/docs/03-AI核心/上下文传递可视化.md)。**否决**空草稿只留输入+发送、把工作区/模型/权限藏到发出后（ChatGPT / Claude 空态几乎只有输入框）——第一屏就要选地方，见 §七。按下发送立刻出用户气泡与助手 Thinking（含草稿首发等建会话；失败撤回）。云桌开通中空气泡改「正在准备云端环境」（`desk_provision_wait`），写锁短等改「等待工作区…」——禁空 Thinking… 冒充。`@` 点选的材料（文件 / 文件夹 / 对话 / 按需设定）与点名角色落在输入**正文药丸**（与句子同一序列，两侧可继续打字、用剪切重排）；**否决**框外芯片托盘作为主呈现（与正文两条路径）。无标记的旧消息仍可在泡上方出芯片。输入框粘贴只吃纯文本（文件/截图仍走附件链）；用户气泡与输入框划词复制只出纯文本，避免气泡底色进剪贴板。助手划词不拦——出口仍是复制两档按钮。→ `ChatView.tsx`、`useComposerDockFlip.ts`、`ComposerPlusMenu.tsx`、`ComposerReceivedContextButton.tsx`、`lib/clipboardPlain.ts`。

**切会话落点**：无目的地打开贴最新（底部），对齐 ChatGPT / Cursor；搜索命中 / 当次大纲仍跳目标。贴底时跟上异步撑高。**否决**消息永久链接（`?msg=` 深链）：回看走搜索或大纲。**否决**记住每条对话的滚动位置；残留 `messageFocus` 不跨次打开。→ `useChatScroll.ts`

**自动标题**：侧栏 UX，不进 Agent 上下文。首条用户消息可用后并行铸题（只用用户首句）。`title` 只存模型铸出的真标题：失败不写库、靠「title 为空」再铸。读接口用 `fallback_title` 填展示。已有真标题后再铸仍否决。克隆对话 `{stem} (n)` 写入列，不是铸题兜底。→ 见代码 `schedule_title_generation` · 桌面 `POST …/auto-title`

**侧栏 IA（三区）**：顶=全局置顶（裸聊 + 文件夹内的对话均可；按最近活动；零重复）；中=文件夹分组（Top 5/组、≤6 组；组内仅未置顶；**组头可拖排序**——未拖过按最近活动，拖过后手排钉死、活动不跳组；新夹接序末；空夹隐藏但保留序位；帽按用户序取前 6；「等你」组挤进盖过不写回。**否决**拖对话行 / 拖进另一夹 / 拖到裸聊区）；底=未置顶裸聊扁平（有分组 10 / 无分组 15）。「等你」留原组、不另开栏：组内帽外 required 挤进（行数 ≤6）、required 所在组挤进 ≤6 组、裸聊像当前对话回塞；折组 required 期间盖过 persist、不写回。归档不拉回。「最近活动」= `updated_at`，仅回合 `touch_activity`（用户句 / 占位 / 助手 upsert）写入；改名 / 置顶 / 压缩 / 规则写入不顶位次。列表 `last_message_preview` 读时投影最后可见助手句（跳过空 / running / 无正文 cancelled·incomplete / 停止中断套话），禁止回落用户句、不加 conversations 列。**否决**跨区「最近」、裸聊「未分组」空组（管理页过滤与 Composer 通道同名「快速对话」）、置顶与组内/裸聊双显。三区无标题，分隔线区分。**Ctrl/Cmd+1–9** 切当前看得见的对话行（折叠组内不计；输入框内也生效；按住 Ctrl/Cmd 才在行尾出淡色 1–9，默认不占标题，hover 动作优先；空槽不抢键。桌面为主，浏览器常被标签页占用）。对话**归属中途不改挂**（不支持事后把对话移入另一个文件夹；要换心智→新开）。**≠**手不能达他项——同对话可跨文件夹派工。归档可撤销；**删除对话亦可恢复（✅「最近删除」）**——`DELETE` 一直是软删（行从没走），缺的只是一条回头路。主路径是删除后的「撤销」toast（多数误删几秒内就发现；发起那一行此时常已卸载，故撤销归 hook 级 mutation 而非逐调用回调），兜底是 `/conversations` 左栏「最近删除」——它与已删文件夹同一视图的两半（文件夹那半见 §九）。**恢复只清 `deleted_at`**：`folder_id` / 置顶 / 归档 / `updated_at` 一个都不动，才回得到原分组与原「最近活动」位次；软删同理**禁止**改写 `updated_at`（一改就落进「今天」，且原值再也追不回来）。保留期沿用 `workspace_retention_days`；过期、以及与清扫竞态输了，都返 **409 如实报**，不静默成功、不对账重试。**分享链接不随恢复复活**（删除时级联吊销是有意的——过期快照不该比删除活得久）。删除对话不二次确认（与归档同一键），安全网是撤销 toast +「最近删除」；批量同理、一条 toast 撤销本次已成功项。**否决**软删再勾叉确认。「最近删除」每条可彻底删除（再确认一次；`DELETE …/trash/{id}`，过期 / 与恢复竞态 409）；**否决**清空回收站。删除文件夹仍弹窗。四处入口话术共用、不得声称不可恢复。→ `lib/conversationDeleteCopy.ts` · `pages/conversations/DeletedConversationManageRow.tsx`。「对话」导航 = 新建草稿（`/` 唯一真相）。侧栏选中态跟路由（顶栏区段与对话行同一「我在哪」，含回合详情）；`currentConversationId` 是运行时指针（切走不清、列表回塞上场对话），不驱动选中铬。→ `lib/conversationLocation.ts`。**草稿不可用右坞**（不出现、快捷键/`openPanel` 等也不能打开；有会话后用户再开）。

**全局协作感知**：列表状态点（执行中脉动 / 「等你决策」光环）。出口按壳 × 场面：壳在场且场面在眼前 → 静默（正文 / 卡 / 灯自己变）；壳在场但人不在这条对话（也没打开它的浮窗）→ 应用内提示；壳不在场（主窗最小化 / 隐藏，或本应用没有任何产品窗在前台）→ 桌面只走系统通知。场面 = 对话路由（含回合详情）或已打开浮窗所跟的对话，不是切走仍留的运行时指针。应用内提示只报对话名 + 要你干什么（完成 / 失败 / 需要审批·决定·回应 / 计划待确认），不贴卡正文。系统通知：title=对话名、body=短句；身份只走系统顶栏，不把产品名/产品标再塞进内容槽（缺对话名时 title 用短句、body 空）。横幅只在卡从无到有时弹（fulfill 快照 / 重连不重弹）；同一对话一条槽位，新卡再响一次并替换，不叠第三条相同文案。关掉横幅 ≠ 已处理（侧栏灯与卡继续在）。`finish_reason=paused` ≠ 完成。手机在线仍走应用内提示（不发 FCM）。→ `teamActivityNotifications.ts`、`notification-service.ts`。

**操作回执**：场面或控件已经变了，不再另贴成功收据——复制、当场停人、市场安装后按钮变「已装」、多端卡已结。删除 / 归档的撤销条仍是跳过确认后的安全网。失败、降级、结果在画面外（导出 / 合回 / 安装包）仍报。

**产品公告**（运营 Notice，≠ 群公告）：顶栏 Banner（同时 ≤1，紧急/维护）+ 登录后一次性弹窗（`surface=modal`，关即 dismiss）+ 消息页「AgentCore 官方」只读会话回看；Banner/Modal 软轮询；inbox 走 IM 未读。More「公告」已撤（`#/more/notices` → 官方会话）。官方号双模板 ✅（`service` 卡面看完 / `article` 摘要进应用内详情）→ [管理员后台 · 官方号双模板](/docs/05-平台与运维/管理员后台.md#官方号双模板服务通知--图文)。契约 → [管理员后台 · 产品公告](/docs/05-平台与运维/管理员后台.md#产品公告全局-notice)、[消息 IM](/docs/05-平台与运维/消息IM.md)。→ `ProductNoticeBanner`、`ProductNoticeModal`、`ProductNoticeCard`、`ProductNoticeDetail`、MessagesPage 官方号。

**团队展示**：多 Agent 走内联 `ProcessTimeline`，协作图嵌在 `delegate`/`debate` 步；单 Agent / 零 run **不出图**。**否决**气泡顶栏派工铬条（「本轮未派工 / N 人进行中 / 已收工」）→ [协作图 UX](/docs/04-前端/协作图与双视图UX.md)。

**团队收益**：协作计数口径仍在 kit（`formatCollabSummary`），**用户面不渲染**（状态条 / 气泡脚 / 手机团队条都不挂「互相把关」）。完成态并行省时芯片 → [协作图 UX](/docs/04-前端/协作图与双视图UX.md)。→ `packages/protocol-fold-kit/src/teamGain.ts`。

### 一B、ProcessTimeline

思考·正文·工具按时序交织；末段正文=答案。活过程（工具进行中 / 空思考 / 组装参数）走标题字形流光 `data-live-flow`，不是三点或转圈；答案流式仍只尾光标。分层权威 → [UI-Pattern 索引](/docs/04-前端/UI-Pattern索引.md)。

**收起态（对齐 Cursor / ChatGPT）**：过程摘要是答案的 caption——一行 muted 披露，不是和正文平级的过程行。竖距走 [间距档](/docs/04-前端/UI-Pattern索引.md#间距档) 的 row；图 / 待拍板 / 插话是独立槽，走 block。聊天 Markdown 按嵌入正文：首尾子边距归零，`##` 开头的答案不另起章。**否决**把折叠栏当章节头。**否决**收起后仍给思考正文留高度。

**折叠行右侧**：只挂对象身份（页面标题 / URL / 路径 / 读窗口「a–b 行」）或会改下一步的结果（验证「未通过」）。shell / run / terminal 的命令，以及 test_run 的 command 检查，进展开。**否决**动词复述（「读取页面结构」「截取当前页面」）、模型 ref / 快照版本、默认失败同义词「未完成」「未找到」（查找失败标题已有路径）。过程与产品失败句进展开。→ `ToolLine.tsx` · `message-bubble/constants.ts` · `toolFaultFace.ts` · `BrowserActivityCard.tsx`

**秒表**：过程行（空思考 / 等锁 / 开云桌 / 工具行 / 折叠组头 / 浏览器卡 / 来源集合）不出直播秒——还在动靠字形流光。工具行因此不另写 Running / Working（认不出的相位同样不写）；相位词只留能换腿的（排队、正在搜、换备用、抓页、抽正文、网络被拦、等仓库、核凭证、连远端）。协作图节点活动行仍用全表。记分牌三口：回合气泡脚（整轮墙钟）、协作图状态条（协作跨度）、节点 face（该 run 用时）。限流倒计时、升级上限、录音 `m:ss` 不走秒表。队长「已等 Ns」否决 → [协作图 UX](/docs/04-前端/协作图与双视图UX.md)。→ `hooks/useRunningElapsed.ts` · `lib/runningElapsed.ts`

**气泡脚时刻**：用户泡末尾常显**发送**时刻（`createdAt`）；助手泡末尾常显**完成**时刻（`createdAt + duration_ms`，与脚上秒数同锚）。复制 / 克隆对话 / 编辑 / 重新生成仍 hover。缺 `duration_ms` 的老助手行回落 `createdAt`，不编造完成点。IM 时间仍走操作行 reveal。→ `MessageTime` · `completedAtIso` · `CloneMessageAction`

**否决**常驻吵闹工具卡、按类别归桶。**否决**折叠检索 / 盘点行挂条数（grep 命中与「未匹配」、`web_search`、`list_folders`、`search_conversations`；空结果同样不挂。标题已有查询词或动作名；展开看名单。数字不改变下一步）。**否决**读页来源集合折叠头挂「未找到」（已写 N sources；抓页失败不改变用户下一步）。连续 ≥2 工具保序折叠（纯渲染）。完成态可折过程：思考 / 工具 / 已答复 ask 进折；用户可见正文（含中间段）/ 待拍板 / 协作图 / 插话不入折。**否决**把非末段正文当旁白一律收进过程折（位置≠价值；直播可见、收场消失）。复制两档：仅交付 / 含过程。失败说明走输入框上方可关横幅（不叠软收尾灰标、不挂气泡错误卡 → [协作图 UX · 一回合一处判决](/docs/04-前端/协作图与双视图UX.md#一内嵌协作图与状态条)）。工具失败旁白只留人要动手或本回合仍生效的约束；自愈下一步不进用户面（改道行只留标题）。**否决**引用/格式核验回炉 chip（「正在按规则修订…」「引用/格式核验后已重写」）与 process `rework` 步——引用是检索产物，不是质检失败态；结构回炉若仍 `content_reset` 只清正文，走思考尾。→ `ProcessTimeline.tsx`、`lib/processTimeline.ts`、`runtime/engine/tool_failure_face.py`。

**已否决（聊天）**：Slash、Agent/Team 选择器、产物 Pill、草稿「存储⊥文件夹」双入口、空草稿藏配置、＋当附件入口、流式字级打字机。

## 二、首启与空态

激活 = 首次真实回合成功。平台代付开箱即用；**无接入门**；BYOK 仅设置可选升级。**否决**服务端 onboarding 状态、form gate、多步 Tour、活工作面上一次性情境浮层（协作图「点节点」卡：浮层比节点更像按钮，第一下点在关提示上）。空态两态客户端推导；新用户 starter chips（老用户消失）。产品心智第一次真跑时看见；手册走设置·关于与命令面板。**否决**空态「怎么用」讲义 / 空态直链 `/toolbox/manual`。→ `components/onboarding/`。Mobile：keyless 同无接入门。列表 / 网格页空态走 `EmptyHint`（本稿仍只谈对话草稿）；跨页骨架 → [UI-Pattern 索引](/docs/04-前端/UI-Pattern索引.md#桌面-ui-统一)。

## 三、文件交互

子目录的「删除」仍是工作区软删，与删整夹不是同一个动作。文件树「新建文件夹」（工作区 mkdir）已卸。新建文件仍先填名。**否决**只为起一个名字弹居中 Dialog；**否决**锚点 Popover；**否决**先填名、失焦取消的容器空行。云端裸聊 `conv:` scratch **不**列（写盘进自动建桌，落「我的文件」）；本地对话写出过用户可见文件的 scratch CRUD，实际整页换到文件中枢）；本页选中文件夹时用「浏览文件」。草稿「在哪工作」单一 chip；文件夹行用云/硬盘图标区分通道，顶层无「我的文件 / 本机文件夹」副标题，嵌套才写祖先路径。删文件夹：对话归档、这张桌的设定退出注入（恢复一起回来；彻底删除/过保留期才清 documents）、文件保留期清理；**否决**级联删聊天、`Folder.archived`。**最近删除（✅，本条说文件夹那半；对话那半见 §一）**：保留期内可恢复——主路径是删除后的「撤销」toast（多数误删几秒内发现），兜底是 `/conversations` 左栏「视图」组与「已归档」并排的「最近删除」。恢复**故意不含**裸聊 auto-desk 指针（恢复它会造幽灵工作区，下回合自动重建）；本机文件夹那一支的 OS 目录删除与恢复都不碰。前端删文件夹**禁止**逐条走归档接口——那会把成员对话标成「用户主动归档」，恢复时就分不出该解档哪些（只做客户端侧效：卸运行时 / 导航离开 / 刷缓存）。「最近删除」每条可彻底删除 ✅（再确认一次；与弹窗勾选同语义：成员对话 + 云端文件 + 桌设定）。不走活文件夹 `permanent_delete`（四步非原子、会误删已释放名位上的新夹）；走墓碑清盘（`rel_path=None`），与恢复抢跑 409。删除当下勾选仍可用。**否决**清空回收站。恢复只认 access session（不给 folders 窄票、不给 AI）；过保留期返 409 如实提示，不对账不重试。「清空本对话产物」仅云端 `conv:` scratch。审批：信任档下文件改动免逐次卡（永久删仍问）。预览矩阵：md 默认阅读；常见图内联 contain、点图灯箱（≤10 MiB）；**否决**面板内缩放铬条与 mime·体积底栏（灯箱已有；体积不改变认出）；PDF 面板 iframe（≤15 MiB）；HTML 面板显源码，完整效果走统一浏览器壳（→ [前端技术 §7.6](/docs/02-架构/工作区.md)）。扩展名过安全白名单（`shared/openable-ext.ts` 单一真相源，主进程硬拒 + renderer 不渲染入口），名单外只留下载：云端字节是 AI 产出的，「弹框让用户点确认」对这个来源不构成防线，故与本地源「名单外确认后仍可开」刻意不同。`/files` 搜索框筛工作区名 + 已展开树内路径/文件名（非内容搜）。云文件 CRUD 含 copy（`POST …/copy`，与 move 同口径）；删进软删区/回收站，确认文案须诚实可还原。产物主清单认 `delivery_status.artifacts`；呈现口径 → [执行引擎 · 可用性诚实性](/docs/03-AI核心/执行引擎架构设计.md)。「查看改动」与右坞「改动」tab 同源（见 §十）。约定文档徽章复用文件树；**否决**阶段 Tab。**否决**项目级 execution 实体；**否决**全部对话页协作时间线/阶段产物卡（选中文件夹只留对话列表 +「浏览文件」）。「与我共享」列成员桌（扁平根，同一 `folder:`）；所有者有名册的桌根用人图标标协作，不写「已共享」。**否决**第三种容器 / 独立共享盘。→ [工作区](/docs/02-架构/工作区.md)。

**「我的文件」云端工作区能力（版本 / 软删区；导出 ZIP 已卸）**：文件页用户手里没有会话，入口必须挂在云端工作区**根节点右键菜单**，不能只活在对话右坞。按能力位 + ws 种类**先行门控**：本机工作区服务端一律 409；只读协作桌（viewer）不挂版本 / 软删区，不让用户点进一个必然失败的动作；本机的版本与回收站是另一条轨（盘上 `AgentCore/versions` / 系统回收站），**不在这里冒充**。版本与软删区开成右侧详情区标签页（合成 tab 路径骑真 ws id，工作区消失即带走它的标签页，且复用与普通文件同一个「打开」接缝）。**云端命名版本只在这里创建 / 列表 / 恢复 / 下载**——右坞「改动」tab 不再列版本、也不再提供「留版本」（那是审本对话 AI 改动与回合基线回滚，见 §十）。**「版本」= 用户留存版本 + 交接存档**，**不含**回合基线与回合后自动备份：回合 N 的结束态与回合 N+1 的基线是同一个时间点，「改动」tab 的回合条目已经代表它；导出 / 预览 / 合回这些传输副产物同理不入列。云端版本卡有下载没有删除接口。**本机命名版本无产品 UI**（盘上 `AgentCore/versions` 与 sidecar API 仍在、永不自动清；已留下的 zip 不删，产品不再提供创建 / 列表 / 恢复入口——本机持久历史走 Git）。**否决**在文件页用云快照菜单冒充本机版本轨。→ `fileWorkbench/WorkspaceSection.tsx` · `WorkspaceVersionsPanel.tsx` · `workspace/ChangesVersionEntry.tsx` · `changesTimeline.ts`

**文件树下载文件夹已卸**：云端工作区与对话文件树对文件夹不再打 zip；只下单文件。本机 LocalRoot 无 download（文件已在盘上，用资源管理器）。GET `.../files/{path}` 仍只下单文件（目录 NotAFile），预览占用同一 URL。→ `FileTreeRowMenu.tsx` · `workspace/files.py`

**文件树元信息与排序（✅）**：行尾只显示修改时间（后端软元信息 `mtime_ms` → [工作区 §三](/docs/02-架构/工作区.md)）。列举仍带回 `size_bytes`，供预览过大 / 本机打开上限 / 版本包与下载等决策点使用，**不**画在列表行（产出卡与文件树同一套行尾）——典型 AI 产物的 KB 级数字不改变「认出并打开」，且和文件名抢位。**否决**行尾常驻大小；**否决**「超阈值才显」启发式。只在源真给出 mtime 时才占位，合成源与 stat 不到的条目宁可少一列，也不用「未知」这种会被读成事实的占位符。排序两档（名称 / 时间新在前）是**整个文件中枢一个偏好**且跨会话保留：用户想的是「我要按时间看文件」，不是「这个夹按时间那个夹按名字」。已持久化的「按大小」回落到名称。排序**纯前端重排、绝不重新拉取**（只为改顺序把整棵树再拉一遍是白付代价）。三条不变量：「`.agentcore`」（盘上 `AgentCore/`）→ 目录 → 文件三档次序**恒定优先于**排序键；名称永远是兜底 tie-break；缺 mtime 的条目在按时间排时沉到该档末尾。被上限截断的那一层须显式提示「还有更多未显示」（源可选实现 `listDirBounded`；不提供的源枚举天然完整，按未截断处理）。→ `files/useFileTreeData.ts` · `fileWorkbench/FileSortMenu.tsx`

**面板内编辑（✅ 文本/代码与 md 同一套 CAS）**：非 Markdown 文本 / 代码文件的编辑改走与 `MarkdownFileEditor` **同一条编辑契约**——`readForEdit` 取全文 + 版本基线，`writeText` 写前比对基线。同回合 Agent 完全可能正在写同一个文件，故保存结果只有**成功 / 冲突 / 明确失败**三态，**没有「悄悄覆盖」那一档**；冲突时给「重新加载 / 仍然覆盖」两个明确出口，「仍然覆盖」以**磁盘当前版本**为新基线重写（明确覆盖 ≠ 盲写）。编辑入口因此门控 `readForEdit + writeText` 而**不接受**裸 `writeBytes`（后者没有基线，只能静默覆盖）；被截断的预览保持只读——保存会丢尾。→ `workspace/FilePreviewView.tsx` · `files/FileDetail.tsx`

## 四、详情面板（右坞）

单一 `SidePanel`（对话/画布**主坞**）。高亮跟**焦点面板**的 run（主坞活跃 tab 或某浮窗；`focusSurface` / `sidePanelFocusTabId`）。**否决**覆盖式单 tab、独立 reasoning Tab、并排双右坞、顶栏全局命令板（首期）。委派：单一 GraphView + 单一 `AgentRun` 模型。run 详情时间线：进行中贴底跟随（同主对话 stick 语义，上滑脱钩 +「回到底部」）；回看已结束 run 打开置顶。坞内未激活的 run 详情卸树（切回再挂）；浮窗里正在看的仍保活。整栏（头区 + 过程行 + 脚）同一条虚拟列表、同一滚动容器，过程只画视野里的行；任务跟着划走。**否决**只窗口化过程段（任务在同一栏却不在列表坐标系，划过会空一截）；**否决**钉任务 / 双滚动 / 用 `scrollMargin` 对账头高。→ `stores/sidePanel.ts`、`RunDetailScroll.tsx` / `RunDetailBody.tsx` / `RunDetailList.tsx`。

**否决**诊断模式 / 开发者模式、侧面板 run 详情「诊断信息」、协作图工具栏调度摘要（峰值 / 串行）：查 bug 走排查包喂 AI，不给人眼检视铬条。

**拓扑不进详情（✅）**：依赖 / 后续 / 上级 / 子任务只在协作图上表达（点邻居节点即换人）；run 详情不复述邻居列表，也不挂「数据从哪来」inject 索引（审计叠加在图上按需高亮；正文仍在「收到的上下文」）。**否决**详情迷你 DAG / 关系卡。

**交接简报（✅）**：成功 `handoff` 工具行即简报卡（与页脚同一张卡：折叠面只有「交接简报」，过程行密度、无灰底壳；展开后灰底只包正文，`summary` 当 markdown 便条，历史数据若仍带要点 / 假设 / 下一步才再跟四格）。新回合便条是收尾轮正文（参数表空）：紧邻成功 `handoff` 前的 content 并进卡，时间线不再单独画那块。协议回执「已收尾。」不进用户面。页脚「交接简报」只留给未打到工具、系统降级合成的 debrief。失败仍是错误工具行。协作图边不标保真度（指针 / 摘要 / 截断），也不把 summary 写到边上。手机队员详情同行为。**否决**队长详情再拼全队简报；**否决**用模型把多份简报合成一段；**否决**从成稿切「## 交接简报」；**否决**JSON 里再留一个 `text` 字段。数据通道仍是机器接力契约 → [Agent 协作 · handoff](/docs/03-AI核心/Agent协作模式.md)。

按人干预（只改这个人 / 只停这个人）**仅引擎还够得着时出现**（`running` / `pending`）；终局（跑完 / 失败 / 取消 / 跳过）整条不渲染——点不动的按钮没有下一步。排队中仍可停，改方向变灰 + 原因（还没开工）。桌面右坞与手机队员详情共用 `RunInterveneControls` + `protocol-fold-kit/runIntervene`（同判定同文案）；图节点不挂这两枚按钮。**整轮 Stop 不进队员详情**：那是回合级硬停，主槽常显（输入框「停止生成」）+ captain 详情；点击即冻图。**否决**状态条再挂「停止整轮」；**否决**全屏顶栏再挂一份（无命令栏）；**否决**图画布「停止任务」（整队留 CEO，与主槽整轮停撞名）。**否决**右坞「记下改法（跑完后发送）」：只往输入框填前缀、不发送不绑 run；「跑完再说」走输入框排队。姿态与否决 → [协作图 · 图视图](/docs/04-前端/协作图与双视图UX.md)。手机对应面在队员详情顶部（`TeamView` · `RunInterveneBar`）；排队中不可用原因恒为可见文字。

**主坞定义**：未弹出内容的**停靠条 + 右侧布局槽**（非唯一可见/唯一可操作面）。关主坞 = 收起右侧槽，不销毁已弹出浮窗。

**「改动」tab**：一处看变了什么。**上** = 这次对话动过的文件（只读真 diff + 回滚；行标签=新建/更新/删除，相对回合基线；**否决**工具名「写入/编辑」；**零文件差异不列出、不挂恢复**；**没改文件不留底**）。**下** = 这个文件夹的 Git（仅该文件夹根有 `.git`；不跟授权盘走、不自动用上一层仓库；**有未提交或领先/落后远端才占下面，干净不占**；会话条仍可显示分支）。点一行开 File tab（与文件树同一接缝；深链可先挂再聚焦该回合）。**不含**用户留存版本与交接存档（云端命名版本只在「我的文件」；本机命名版本无产品入口，见 §九）。**出现** = 用户显式打开（Git chip / `+`·改动）；无货也可先挂再看。**不**因 AI 写盘或本机回合 zip 基线自动挂。恢复文案诚实：尽力 overlay，非完整镜像。**卸下** = 用户关掉（顶栏 × / 应用内浮窗 ×）或切对话；关后新写盘也不再挂。**否决**有货自动占条；**否决**关后因新写盘再挂（彻底安静）；**否决**空态常驻入口（自动挂；用户从 `+` 打开的空面板不是常驻）；**否决**把「留版本」当空态主按钮；**否决**「清空本对话产物」作为卸 tab 条件（清空只抹云 scratch 盘，process/execution 改动史仍在）；**否决**把仓的脏状态说成这次对话的改动。文案用「改动」；**否决** tab 名 `diff`。→ `ConversationChangesPanel.tsx` · `conversationFileChanges.ts`
