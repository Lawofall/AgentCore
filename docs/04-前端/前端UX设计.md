## 一、全局布局与侧栏

侧栏 + 页面自布局；对话页单栏聊天。**窄屏壳**（<768px）：底栏 4-tab + 对话页 ☰ 抽屉 + 右坞改全屏 sheet；文件 / IM / 设置是列表推进详情（设置入口不上 Git / 通用 / 快捷键 / 反馈），产品页仍是这棵树 → [前端技术 §五](/docs/04-前端/前端技术与架构.md)。内嵌图「在画布打开」→ `TurnDetailPage`；点节点 → 宽屏 SidePanel run tab / 窄屏 sheet。输入框：空草稿居中（`card` 摊开配置），首条后 FLIP 落底（`bar`：＋收纳配置 · 输入 · 语音 · 发送）。**否决**空草稿只留输入+发送、把工作区/模型/权限藏到发出后（ChatGPT / Claude 空态几乎只有输入框）——第一屏就要选地方，见 §十三。按下发送立刻出用户气泡与助手 Thinking（含草稿首发等建会话；失败撤回）。`@` 点选的材料（文件 / 文件夹 / 对话 / 按需设定）与点名角色落在输入**正文药丸**（与句子同一序列，两侧可继续打字、用剪切重排）；**否决**框外芯片托盘作为主呈现（与正文两条路径）。无标记的旧消息仍可在泡上方出芯片。输入框粘贴只吃纯文本（文件/截图仍走附件链）；用户气泡与输入框划词复制只出纯文本，避免气泡底色进剪贴板。助手划词不拦——出口仍是复制两档按钮。→ `ChatView.tsx`、`useComposerDockFlip.ts`、`ComposerPlusMenu.tsx`、`lib/clipboardPlain.ts`。

**切会话落点**：无目的地打开贴最新（底部），对齐 ChatGPT / Cursor；搜索命中 / `?msg=` / 当次大纲仍跳目标。贴底时跟上异步撑高。**否决**记住每条对话的滚动位置；残留 `messageFocus` 不跨次打开。→ `useChatScroll.ts`

**侧栏 IA（三区）**：顶=全局置顶（裸聊 + 文件夹内的对话均可；按最近活动；零重复）；中=文件夹分组（Top 5/组、≤6 组；组内仅未置顶；**组头可拖排序**——未拖过按最近活动，拖过后手排钉死、活动不跳组；新夹接序末；空夹隐藏但保留序位；帽按用户序取前 6；「等你」组挤进盖过不写回。**否决**拖对话行 / 拖进另一夹 / 拖到裸聊区）；底=未置顶裸聊扁平（有分组 10 / 无分组 15）。「等你」留原组、不另开栏：组内帽外 required 挤进（行数 ≤6）、required 所在组挤进 ≤6 组、裸聊像当前对话回塞；折组 required 期间盖过 persist、不写回。归档不拉回。「最近活动」= `updated_at`，仅回合 `touch_activity`（用户句 / 占位 / 助手 upsert）写入；改名 / 置顶 / 压缩 / 记忆不顶位次。列表 `last_message_preview` 读时投影最后可见助手句（跳过空 / running / 无正文 cancelled·incomplete / 停止中断套话），禁止回落用户句、不加 conversations 列。**否决**跨区「最近」、裸聊「未分组」空组（管理页过滤与 Composer 通道同名「快速对话」）、置顶与组内/裸聊双显。三区无标题，分隔线区分。对话**归属中途不改挂**（不支持事后把对话移入另一个文件夹；要换心智→新开）。**≠**手不能达他项——同对话可跨文件夹派工。归档可撤销；**删除对话亦可恢复（✅「最近删除」）**——`DELETE` 一直是软删（行从没走），缺的只是一条回头路。主路径是删除后的「撤销」toast（多数误删几秒内就发现；发起那一行此时常已卸载，故撤销归 hook 级 mutation 而非逐调用回调），兜底是 `/conversations` 左栏「最近删除」——它与已删文件夹同一视图的两半（文件夹那半见 §九）。**恢复只清 `deleted_at`**：`folder_id` / 置顶 / 归档 / `updated_at` 一个都不动，才回得到原分组与原「最近活动」位次；软删同理**禁止**改写 `updated_at`（一改就落进「今天」，且原值再也追不回来）。保留期沿用 `workspace_retention_days`；过期、以及与清扫竞态输了，都返 **409 如实报**，不静默成功、不对账重试。**分享链接不随恢复复活**（删除时级联吊销是有意的——过期快照不该比删除活得久）。删除对话不二次确认（与归档同一键），安全网是撤销 toast +「最近删除」；批量同理、一条 toast 撤销本次已成功项。**否决**软删再勾叉确认。删除文件夹仍弹窗。四处入口话术共用、不得声称不可恢复。→ `lib/conversationDeleteCopy.ts` · `pages/conversations/DeletedConversationManageRow.tsx`。「对话」导航 = 新建草稿（`/` 唯一真相）。**草稿不可用右坞**（不出现、快捷键/`openPanel` 等也不能打开；有会话后用户再开）。

**全局协作感知**：列表状态点（执行中脉动 / 「等你决策」光环）；跨对话完成 Toast + 原生通知。`finish_reason=paused` ≠ 完成。→ `teamActivityNotifications.ts`。

**产品公告**（运营 Notice，≠ 群公告 / ≠ 站立收件箱）：顶栏 Banner（同时 ≤1，紧急/维护）+ 登录后一次性弹窗（`surface=modal`，关即 dismiss）+ 消息页「AgentCore 官方」只读会话回看；Banner/Modal 软轮询；inbox 走 IM 未读。More「公告」已撤（`#/more/notices` → 官方会话）。官方号双模板 ✅（`service` 卡面看完 / `article` 摘要进应用内详情）→ [管理员后台 · 官方号双模板](/docs/05-平台与运维/管理员后台.md#官方号双模板服务通知--图文)。契约 → [管理员后台 · 产品公告](/docs/05-平台与运维/管理员后台.md#产品公告全局-notice)、[消息 IM](/docs/05-平台与运维/消息IM.md)。→ `ProductNoticeBanner`、`ProductNoticeModal`、`ProductNoticeCard`、`ProductNoticeDetail`、MessagesPage 官方号。

**团队展示**：多 Agent 走内联 `ProcessTimeline`，协作图嵌在 `delegate`/`debate` 步；单 Agent / 零 run **不出图**。**否决**气泡顶栏派工铬条（「本轮未派工 / N 人进行中 / 已收工」）→ [协作图 UX](/docs/04-前端/协作图与双视图UX.md)。

**团队收益**：协作计数口径仍在 kit（`formatCollabSummary`），**用户面不渲染**（状态条 / 气泡脚 / 手机团队条都不挂「互相把关」）。完成态并行省时芯片 → [协作图 UX](/docs/04-前端/协作图与双视图UX.md)。→ `packages/protocol-fold-kit/src/teamGain.ts`。

### 一B、ProcessTimeline

思考·正文·工具按时序交织；末段正文=答案。**否决**常驻吵闹工具卡、按类别归桶。连续 ≥2 工具保序折叠（纯渲染）。完成态可折过程：思考、工具、非末段正文（旁白）进摘要；末段正文、待拍板检查点前的正文、强交互卡、协作图、插话不入折。直播中不折。**否决**把答案折进 Thought；**否决**扫正文猜是否进度。复制两档：仅交付 / 含过程。失败走红卡（不叠软收尾灰标 → [协作图 UX · 一回合一处判决](/docs/04-前端/协作图与双视图UX.md#三内嵌协作图与状态条)）。**否决**引用/格式核验回炉 chip（「正在按规则修订…」「引用/格式核验后已重写」）与 process `rework` 步——引用是检索产物，不是质检失败态；结构回炉若仍 `content_reset` 只清正文，走思考尾。→ `ProcessTimeline.tsx`、`lib/processTimeline.ts`。

**已否决（聊天）**：Slash、Agent/Team 选择器、产物 Pill、草稿「存储⊥文件夹」双入口、空草稿藏配置、＋当附件入口、流式字级打字机。

## 二、首启与空态

激活 = 首次真实回合成功。平台代付开箱即用；**无接入门**；BYOK 仅设置可选升级。**否决**服务端 onboarding 状态、form gate、多步 Tour。空态两态客户端推导；新用户 starter chips（老用户消失）。「怎么用」开当场说明（窄屏不链手册——整棵工具箱仍不上；宽屏说明里可进手册）。**否决**空态直链 `/toolbox/manual`。情境提示 ≤3，仅协作图一枚。→ `components/onboarding/`。Mobile：keyless 同无接入门。列表 / 网格页空态走 `EmptyHint`（本稿仍只谈对话草稿）；跨页骨架 → [UI-Pattern 索引](/docs/04-前端/UI-Pattern索引.md#桌面-ui-统一)。

## 九、文件交互

入口 = SidePanel + `/files`（窄屏树 → 文件推进，不并排空详情）。文件中枢左栏：我的文件 / 本机文件夹 / 与我共享（协作桌 → [工作区 · §八、协作桌（文件夹成员）](/docs/02-架构/双模式工作区.md)），**不**列裸聊 `conv:` scratch；「快速对话」只留 Composer 与侧栏对话入口。双通道、Composer 三选、合回/ZIP、裸聊建桌、文案禁令 → [工作区 · §五、绑定：文件夹即工作区 · 双通道入口](/docs/02-架构/双模式工作区.md)。手机无本机传统。**否决**在 `/conversations` 左栏挂「管理文件夹」常驻跳转（文案像本页 CRUD，实际整页换到文件中枢）；本页选中文件夹时用「浏览文件」。草稿「在哪工作」单一 chip；文件夹行用云/硬盘图标区分通道，顶层无「我的文件 / 本机文件夹」副标题，嵌套才写祖先路径。删文件夹：对话归档、这张桌的设定退出注入（恢复一起回来；彻底删除/过保留期才清 documents）、文件保留期清理；**否决**级联删聊天、`Folder.archived`。**最近删除（✅，本条说文件夹那半；对话那半见 §一）**：保留期内可恢复——主路径是删除后的「撤销」toast（多数误删几秒内发现），兜底是 `/conversations` 左栏「视图」组与「已归档」并排的「最近删除」。恢复**故意不含**白板的文件夹归属（`Board.folder_id` 置 NULL 是「白板永不丢失」的设计，原值无处可查）与裸聊 auto-desk 指针（恢复它会造幽灵工作区，下回合自动重建）；本机文件夹那一支的 OS 目录删除与恢复都不碰。前端删文件夹**禁止**逐条走归档接口——那会把成员对话标成「用户主动归档」，恢复时就分不出该解档哪些（只做客户端侧效：卸运行时 / 导航离开 / 刷缓存）。**否决**回收站内「彻底删除」：`permanent_delete` 是四步非原子流程，与恢复交错会留下空壳文件夹；要立刻清盘仍走删除弹窗的勾选框。恢复只认 access session（不给 folders 窄票、不给 AI）；过保留期返 409 如实提示，不对账不重试。「清空本对话产物」仅云端 `conv:` scratch。审批：信任档下文件改动免逐次卡（永久删仍问）。预览矩阵：md 默认阅读；常见图内联（缩放/灯箱，≤10 MiB）；PDF 面板 iframe（≤15 MiB）；HTML 面板显源码，完整效果走统一浏览器壳（→ [前端技术 §9.12](/docs/04-前端/前端技术与架构.md)）；Office/其它二进制不内联，兜底面并排「下载」+「用本机默认应用打开」（✅ 两源同一菜单项、语义不同）：本地源开磁盘上的真实文件；云端文件本机无实体，落**只读**临时副本再 `openPath`——只读是防「用户在 Word 里改完保存、以为存进了云端」的主防线（本期**不做**外部改动回写，也**不**做本地镜像 → [工作区 §7.6](/docs/02-架构/双模式工作区.md)）。扩展名过安全白名单（`shared/openable-ext.ts` 单一真相源，主进程硬拒 + renderer 不渲染入口），名单外只留下载：云端字节是 AI 产出的，「弹框让用户点确认」对这个来源不构成防线，故与本地源「名单外确认后仍可开」刻意不同。`/files` 搜索框筛工作区名 + 已展开树内路径/文件名（非内容搜）。云文件 CRUD 含 copy（`POST …/copy`，与 move 同口径）；删进软删区/回收站，确认文案须诚实可还原。产物主清单认 `delivery_status.artifacts`；呈现口径 → [执行引擎 · 可用性诚实性](/docs/03-AI核心/执行引擎架构设计.md)。「查看改动」与右坞「改动」tab 同源（见 §十）。约定文档徽章复用文件树；**否决**阶段 Tab。协作时间线=读时聚合；**否决**项目级 execution 实体。HEAD 第三区仍是独立共享盘、角标「共享」。⏳ 落地改为所有者桌留「我的文件」打已共享、成员见「与我共享」；**否决**把该区叫「项目」。→ [工作区 · §八、协作桌（文件夹成员）](/docs/02-架构/双模式工作区.md)；终稿路径可点 → `lib/remarkWorkspacePaths.ts`。

**「我的文件」云端工作区三件能力（版本 / 软删区 / 导出 ZIP）**：文件页用户手里没有会话，入口必须挂在云端工作区**根节点右键菜单**，不能只活在对话右坞。按能力位 + ws 种类**先行门控**：本机工作区服务端一律 409（`shared:` 工作区已删除）；不让用户点进一个必然失败的动作；本机的版本与回收站是另一条轨（盘上 `AgentCore/versions` / 系统回收站），**不在这里冒充**。版本与软删区开成右侧详情区标签页（合成 tab 路径骑真 ws id，工作区消失即带走它的标签页，且复用与普通文件同一个「打开」接缝）。**云端命名版本只在这里创建 / 列表 / 恢复 / 下载**——右坞「改动」tab 不再列版本、也不再提供「留版本」（那是审本对话 AI 改动与回合基线回滚，见 §十）。**「版本」= 用户留存版本 + 交接存档**，**不含**回合基线与回合后自动备份：回合 N 的结束态与回合 N+1 的基线是同一个时间点，「改动」tab 的回合条目已经代表它；导出 / 预览 / 合回这些传输副产物同理不入列。云端版本卡有下载没有删除接口。**本机命名版本无产品 UI**（盘上 `AgentCore/versions` 与 sidecar API 仍在、永不自动清；已留下的 zip 不删，产品不再提供创建 / 列表 / 恢复入口——本机持久历史走 Git）。**否决**在文件页用云快照菜单冒充本机版本轨。→ `fileWorkbench/WorkspaceSection.tsx` · `WorkspaceVersionsPanel.tsx` · `workspace/ChangesVersionEntry.tsx` · `changesTimeline.ts`

**文件树下载文件夹 ≠ 根上导出 ZIP**：云端工作区与对话文件树对文件夹点「下载」，走独立 archive 端点，把**当前子树**打成 zip（选中目录为根），容量闸与面板单文件下载/上传同一套。**不是**根节点「导出 ZIP」（那是先建一份整桌快照再下载，语义不变）。文件夹 zip 走独立 archive，不要套快照的 409。本机 LocalRoot 无 download（文件已在盘上，用资源管理器）。GET `.../files/{path}` 仍只下单文件（目录 NotAFile），预览占用同一 URL。→ `FileTreeRowMenu.tsx` · `workspace/files.py`

**文件树元信息与排序（✅）**：行尾只显示修改时间（后端软元信息 `mtime_ms` → [工作区 §三](/docs/02-架构/双模式工作区.md)）。列举仍带回 `size_bytes`，供预览过大 / 本机打开上限 / 版本包与下载等决策点使用，**不**画在列表行（产出卡与文件树同一套行尾）——典型 AI 产物的 KB 级数字不改变「认出并打开」，且和文件名抢位。**否决**行尾常驻大小；**否决**「超阈值才显」启发式。只在源真给出 mtime 时才占位，合成源与 stat 不到的条目宁可少一列，也不用「未知」这种会被读成事实的占位符。排序两档（名称 / 时间新在前）是**整个文件中枢一个偏好**且跨会话保留：用户想的是「我要按时间看文件」，不是「这个夹按时间那个夹按名字」。已持久化的「按大小」回落到名称。排序**纯前端重排、绝不重新拉取**（只为改顺序把整棵树再拉一遍是白付代价）。三条不变量：「`.agentcore`」（盘上 `AgentCore/`）→ 目录 → 文件三档次序**恒定优先于**排序键；名称永远是兜底 tie-break；缺 mtime 的条目在按时间排时沉到该档末尾。被上限截断的那一层须显式提示「还有更多未显示」（源可选实现 `listDirBounded`；不提供的源枚举天然完整，按未截断处理）。→ `files/useFileTreeData.ts` · `fileWorkbench/FileSortMenu.tsx`

**面板内编辑（✅ 文本/代码与 md 同一套 CAS）**：非 Markdown 文本 / 代码文件的编辑改走与 `MarkdownFileEditor` **同一条编辑契约**——`readForEdit` 取全文 + 版本基线，`writeText` 写前比对基线。同回合 Agent 完全可能正在写同一个文件，故保存结果只有**成功 / 冲突 / 明确失败**三态，**没有「悄悄覆盖」那一档**；冲突时给「重新加载 / 仍然覆盖」两个明确出口，「仍然覆盖」以**磁盘当前版本**为新基线重写（明确覆盖 ≠ 盲写）。编辑入口因此门控 `readForEdit + writeText` 而**不接受**裸 `writeBytes`（后者没有基线，只能静默覆盖）；被截断的预览保持只读——保存会丢尾。→ `workspace/FilePreviewView.tsx` · `files/FileDetail.tsx`

**交接简报（✅）**：成功 `handoff` 工具行即简报卡（与页脚同一张卡：折叠面只有「交接简报」，过程行密度、无灰底壳；展开后灰底只包正文，`summary` 当 markdown 便条，历史数据若仍带要点 / 假设 / 下一步才再跟四格）。新回合便条是收尾轮正文（参数表空）：紧邻成功 `handoff` 前的 content 并进卡，时间线不再单独画那块。协议回执「已收尾。」不进用户面。页脚「交接简报」只留给未打到工具、系统降级合成的 debrief。失败仍是错误工具行。协作图边仍只标有损保真度，不把 summary 写到边上。手机队员详情同行为。**否决**队长详情再拼全队简报；**否决**用模型把多份简报合成一段；**否决**从成稿切「## 交接简报」；**否决**JSON 里再留一个 `text` 字段。数据通道仍是机器接力契约 → [Agent 协作 · handoff](/docs/03-AI核心/Agent协作模式.md)。

## 十三、模型与自主度

设置拆「模型」（组合）/「服务商」（BYOK）/「Git 凭据」（云私仓 PAT；Local 说明继承 OS/`gh auth`）。会话选**组合**非裸模型。组合槽位候选来自统一目录（BYOK：default ∪ 厂商预设 ∪ 发现）；另支持对 BYOK 服务商**手填** model id（平台行仍只 allowlist）。人侧 picker 与辩论/委派工具 `model` 都只填一条目录身份 `@platform/{id}` / `@byok/{provider_id}/{id}`（付款来源是行属性，不是并列字段）→ [平台 LLM 接入](/docs/05-平台与运维/平台LLM接入.md)。设置页对协作/工具调用能力作静态诚实提示（**否决**质量档/自动降级）。**否决**账号级角色→模型矩阵、质量档、组合入口双 picker。**Per-worker 模型覆盖 ✅**：默认跟 Worker 槽；CEO/`tasks[]` 节点显式仍有效；人侧 picker 不改队员模型；完成后协作图 peek / 用量详情见 `run.model` → [编排器](/docs/03-AI核心/编排器与CEO主Agent.md#per-worker-模型覆盖abc-同一功能)。自主度配方三选一（谨慎 / 全放行（默认）/ 托管）→ [安全权限与治理 §三](/docs/05-平台与运维/安全权限与治理.md)。账户默认：桌面经对话权限徽章「设为新会话默认」写入；手机可经设置或会话内「＋」菜单同入口写入。会话内默认只出三配方；「改某一条」才展开轴（含本机）。**桌面**空草稿 `card` 靠底栏权限徽章与 @；有消息后的底栏 `bar` 与**手机**一样收进 composer「＋」。**Composer 通道（✅）**：草稿第一屏选地方；本机后再三选。选项语义与否决 → [工作区 · §五、绑定：文件夹即工作区 · 双通道入口](/docs/02-架构/双模式工作区.md)。界面不出现「云协作 / 本机传统」。「＋」常显工作区 · Git? · 模型 · 权限 · @ 引用（本机附件收进 @ 菜单；合回主入口在工作区芯片，导出在工作区工具条，只合回产物在导出菜单 → [§7.6](/docs/02-架构/双模式工作区.md)；Composer「＋」不再常驻；遗留 handoff **不再**从芯片武装）。**否决**有消息后「＋」改成附件入口（ChatGPT 回形针）：附件走 @ 与附件链，「＋」只收配置；不在「＋」上叠第二入口。顶栏不再展示配方后缀。非法组合不可选；自定义四轴不可存为账户默认。

## 十五、待定与收藏

窄屏协作图走桌面 `InlineTeamGraph`（点节点开 sheet）；竖排 `TeamView` 与旧手机辩论精简面**已随 fold 退役**。跨会话多任务总览、无障碍、虚拟滚动 ⏳。**否决**流式字级打字机（token 已到再往外挤；与 rAF 合批、停止/插队诚实性冲突）。流式答案末尾光标 ✅（思考空态仍 `ThinkingDots`）。**断线只读 / 完全离线** → [双模式工作区](/docs/02-架构/双模式工作区.md)（本文不复述）。消息收藏 ✅：命令面板「已收藏」facet；**否决**侧栏独立列表。**否决逐条消息删除**：单行硬删只删半个回合（配对消息成孤儿）、连带销毁 journal 重放与审计而用量账单仍留、手机端本就没有；「这答案我不要」走**重新生成**，其余走**对话级删除**。对齐行业（ChatGPT / Claude / Gemini 助手底栏均无逐条删除）。后端 `DELETE .../messages/{id}` 保留但前端不再调用。
