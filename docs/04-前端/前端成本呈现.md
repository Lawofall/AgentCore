# 前端成本呈现

> 后端不变量 → [成本配额与计费](/docs/05-平台与运维/成本配额与计费.md)。本文只记 VIEW 层决策。数据：`services/usage.ts`、`stores/usage.ts`、`lib/format.ts`、`RunNode.{cost,usage}`。

## 信息分层

**无粒度开关**（`usageDetail` 已下线）——恒展示，靠位置分层：inline 只做信号（¥+token 摘要）；详情进面板。→ `UsageSettings.tsx`、`RunDetailBody.tsx`。

## 格式化

金额整数 nano；展示 = nano/1e9（`cny_total` 已是元）；**符号随币种**——产品名义价恒 `¥`。0 成本显「—」，绝不「¥0.00」；<1 分显「<¥0.01」。额度还剩走 `formatQuotaRemaining`（用尽显「¥0.00」，不是「—」）。run 详情构成（输入+输出）按展示分找齐，避免分项各自取整后和总额差 1 分。

## 三级呈现

| 层 | 位置 | inline | 详情 |
|---|---|---|---|
| 回合 | 气泡 meta / footer | ¥ + 秒数 | token 树（输入含缓存，输出含思考与速度）+ 轮次(>1) |
| run | run-detail「资源消耗」 | 该 run ¥ | 模型与思考强度同行（有 `run_completed.reasoning_effort` 则官方 token，否则回落思考开关；旧 journal 无该字段）；构成=输入+输出（`cached` 为其中实付，不叫「省」）；token；**默认折叠** |
| 账户 | 用量页 | 还剩主卡 + 今日三数 + 近 7 日趋势（折线 + 锚点，零日落基线） | 只留构成；无命中不出缓存 0% |

账户用量页（大众面）：主数字是额度还剩（不是已用 %；% 只做条上辅信息）。日成本帽只在剩余比月额度更紧时占据主卡，不与月额度并排两条钱条；不限的维不画空槽。今日花费 / tokens / 请求用数字卡；token / 请求 ≥80% 且有上限才另出条。明细不重复主卡与今日行已有的成本与请求。缓存：无命中且非「按未命中计价」则不出。将尽 CTA 写在主卡内，走 primary。BYOK 先说明卡、token 面、有价目再出 ¥（不扣额度）。月与日成本都不限时主卡改「本月已用」无条。

图节点 face **不显钱**（仅用时·工具）；**否决** face 叠 ¥。对话累计 caption **已退役**（零噪音）。多 Agent：¥ 归主回复末尾（气泡 meta/footer）；状态条不挂花费。具名恢复只藏重新生成；复制与费用行仍留在回复末尾，不回挂状态条。token 树与 ReAct 轮次只进底栏「用量」弹出层（不重复 ¥；**否决**气泡脚再挂「N 轮」或 tok/s）。窗口占满比例挂在整块输入框外侧右边的窗口环上（`last_prompt` / 目录 `context_length`），不是第二套用量产品、不用字符估 → [上下文传递可视化](/docs/03-AI核心/上下文传递可视化.md)。

**两口钟（有协作图时）**：条上「用时」= 协作事实流跨度（`run_plan` 后的帧，不含派工前 CEO 与图后终稿流式）；气泡脚秒数 = 整轮产品 AI 墙钟（`message_end.duration_ms` / `messages.usage.duration_ms`）。两处可不同。条上冠「用时」；气泡脚只写 `12s` / `2m 34s`，不冠「用时」（完成时刻已在同一行）。无图时只有气泡脚这一口。→ `elapsedMs` / `turnElapsed.ts` · `AssistantMessageFooter`。

暂停（提问 / 审批 / 限流续跑）与停止一样：回复末尾用已经入账的调用画费用和「用量」。再次挂起不把用量写成 0。→ `project_settled_message_cost` · [成本配额与计费](/docs/05-平台与运维/成本配额与计费.md)。

**用量弹出层**：底栏「用量」一棵树。输入、输出为总数，完整整数、千分位（≥100 万仍紧凑）。缓存命中与未命中缩进在输入下，思考与速度缩进在输出下；子集为 0 不画。上游省略缓存拆分时，输入下只留「按未命中计价」。速度 = `输出 token ÷ generation_ms`（各次 LLM 调用「首个输出块 → 该次结束」之和，含思考、含队员），文案「速度」「42.0 tokens/s」，不写 TPS。缺 `generation_ms`、输出不足 10、吐字时长不足 250ms 不出速度，不拿用时假算、不写 0。工具 / 等队员 / 等你拍板在脚上秒数里，不进这个除数。流式过程不跟活数字。→ `UsageDetailPanel` · `formatOutputSpeed` · `message_end.generation_ms`。

## BYOK

有 curated 卡的模型（含用户自选 DeepSeek 4.1）出与平台相同的 `¥`（Flash 同为 DeepSeek 中文官价）；额度仍不扣。说明只在详情 / tooltip（「按产品价目，不扣额度」）。无卡的模型费用位空，只留 token，不再标「未计价」。遗留社区 USD 估算行仍可出 `≈$`。`byok 分支 = billing_mode==="byok"`（平台代付休眠时走 token + 名义价面）。

## 配额拒绝

429 按 code 分流：`QUOTA_EXCEEDED` 可次级 CTA 去设置接 Key；`RATE_LIMITED` 等亦只出错误条文案（**否决**错误条一键重试）。限流族（`RATE_LIMITED` / `LLM_RATE_LIMIT`）在 attested `retry_after` 大于共享 `MAX_RETRY_AFTER`（30s，`@agentcore/contract-types`）时气泡与状态条都不展重试——与文案「重试会失败」对齐；阈值比较用 `>`，恰好 30 秒仍可重试。**不加** wire `retryable`。文案以后端 `message` 为单一来源。→ `lib/errors.ts` · `turnOutcome.ts`。
