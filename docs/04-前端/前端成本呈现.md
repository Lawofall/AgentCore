# 前端成本呈现

> 后端不变量 → [成本配额与计费](/docs/05-平台与运维/成本配额与计费.md)。本文只记 VIEW 层决策。数据：`services/usage.ts`、`stores/usage.ts`、`lib/format.ts`、`RunNode.{cost,usage}`。

## 信息分层

**无粒度开关**（`usageDetail` 已下线）——恒展示，靠位置分层：inline 只做信号（¥+token 摘要）；详情进面板。→ `UsageSettings.tsx`、`RunDetailBody.tsx`。

## 格式化

金额整数 nano；展示 = nano/1e9（`cny_total` 已是元）；**符号随币种**——记账恒 `¥`，BYOK 估算随 `estimated_currency`（社区价卡原币 USD → `$`）；API 不下发汇率，两币不互折、不相加。0 成本显「—」，绝不「¥0.00」；<1 分显「<¥0.01」。

## 三级呈现

| 层 | 位置 | inline | 详情 |
|---|---|---|---|
| 回合 | 气泡 meta / footer | ¥ + Agent 数 + 轮次(>1) | token 拆分 |
| run | run-detail「资源消耗」 | 该 run ¥ | model/三价/token；**默认展开** |
| 账户 | 用量页 | 额度条 + 近 7 日趋势 | 明细恒显 |

图节点 face **不显钱**（仅用时·工具）；**否决** face 叠 ¥。对话累计 caption **已退役**（零噪音）。多 Agent：¥ 归主回复末尾（气泡 meta/footer）；状态条不挂花费。具名恢复关掉操作 footer 时，费用行仍留在回复末尾（与复制/重新生成解耦），不回挂状态条。token/轮次补气泡 meta（不重复 ¥）。

## BYOK

估算一律「≈ + 币种符号」+「估算」标注——社区价卡抄的是厂商官网 USD 标价，故 BYOK 出 `≈$`（不折人民币）；`unpriced` 出「—」且必挂「自带密钥·未计价」（防误读免费）。记账与估算**永不相加**（币种都不同）。`byok 分支 = billing_mode==="byok"`（平台代付休眠时走 token/估算面）。

## 配额拒绝

429 按 code 分流：`QUOTA_EXCEEDED` 可次级 CTA 去设置接 Key；`RATE_LIMITED` 等亦只出错误条文案（**否决**错误条一键重试）。限流族（`RATE_LIMITED` / `LLM_RATE_LIMIT`）在 attested `retry_after` 大于共享 `MAX_RETRY_AFTER`（30s，`@agentcore/contract-types`）时气泡与状态条都不展重试——与文案「重试会失败」对齐；阈值比较用 `>`，恰好 30 秒仍可重试。**不加** wire `retryable`。文案以后端 `message` 为单一来源。→ `lib/errors.ts` · `turnOutcome.ts`。

开跑前拒绝（402 `LLM_KEY_REQUIRED` / 429 `QUOTA_EXCEEDED`·`RATE_LIMITED` / 503 `PLATFORM_BILLING_UNAVAILABLE`，且用户消息未落库）与本发已 `turn_saved` 的空失败（`LLM_RATE_LIMIT` / `LLM_KEY_INVALID` / `LLM_INSUFFICIENT_BALANCE`，无正文、无工具、0 token）：发送当没发生——撤泡并还草稿，`turnPhase` 回 idle。

**首发**（本发刚 `POST` 出的空会话）：软删该会话、列表拿掉、回到 `/` 草稿；错误画在输入框卡片上（不进 textarea、不依赖「有气泡才出条」）。作废 `client_request_id`（复用会领回已软删行）。软删进「最近删除」，侧栏对话列表不再出现。**跟发**只回滚本发，不拆会话。**禁止**把 Class B 码并进开跑前 Class A 白名单。**禁止**把 400 / 530 / 空响应并进 Class B。重新生成不删旧 user。会话级 RetryBanner 仍由聊天输入区读（指挥台已随总览撤）。→ `useComposerSend.ts` / `ComposerSendErrorNotice` / `zero_output_rollback.py`.
