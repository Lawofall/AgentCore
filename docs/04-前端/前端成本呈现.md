# 前端成本呈现

> 后端不变量 → [成本配额与计费](/docs/05-平台与运维/成本配额与计费.md)。本文只记 VIEW 层决策。数据：`services/usage.ts`、`stores/usage.ts`、`lib/format.ts`、`RunNode.{cost,usage}`。

## 信息分层

**无粒度开关**（`usageDetail` 已下线）——恒展示，靠位置分层：inline 只做信号（积分+token 摘要）；详情进面板。→ `UsageSettings.tsx`、`RunDetailBody.tsx`。

## 格式化

金额整数 nano；展示 = nano/1e9（1 积分 = ¥1 卖价）；**平台 CNY 写积分**，**自己的 Key 写 ¥**，遗留 USD 仍 `$`。0 成本显「—」，绝不「0.00 积分」；<1 分显「<0.01 积分」/「<¥0.01」。积分还剩走 `formatQuotaRemaining`（用尽显「0.00 积分」，不是「—」）。run 详情构成（输入+输出）按展示分找齐，避免分项各自取整后和总额差 1 分。

## 三级呈现

| 层 | 位置 | inline | 详情 |
|---|---|---|---|
| 回合 | 气泡 meta / footer | 平台积分 / 自己的 Key ¥ + 秒数 | token 树（输入含缓存，输出含思考与速度）+ 轮次(>1) |
| run | run-detail「资源消耗」 | 该 run 已入账积分或 ¥（进行中标「至今」） | 模型与思考强度同行：写 billed 模型 id。有 `run_completed.reasoning_effort` 则官方 token，否则回落思考开关；旧 journal 无该字段。构成=输入+输出（`cached` 为其中实付，不叫「省」）；token；**默认折叠**。第一次模型调用返回后即出现，不必等 `run_completed`；失败 / 取消 / 中途停下仍带已经打到模型上的花费 |
| 账户 | 用量页 | 额度行（右还剩 + 席位胶囊；搜索次数 / tokens 将尽并进同一张卡）+ 近 30 日趋势 + 按对话活动表（列头筛模型，本月分页，汇总跟筛选） | 无命中不出缓存 0%；活动表点进那场对话，工资单仍在气泡「用量」 |

账户用量页（大众面）：主数字是积分还剩（不是已用 %；% 只做条上辅信息）。额度行是设置行：左标签、右还剩、席位胶囊链到订阅；有上限才出条，% 跟在已用 caption。日成本帽只在剩余比月积分更紧时占据额度行，不与月积分并排两条钱条；不限的维不画空槽。搜索次数正交于金额，有日/月上限才写在额度行 caption。token ≥80% 且有上限才在额度行另出条。明细不重复额度行已有的还剩数字。缓存：无命中且非「按未命中计价」则不出。将尽 CTA 写在额度行内，走 primary（去订阅；次级接入自己的 Key）。BYOK 先说明卡、token 面、有价目再出 ¥（不扣积分）。月与日成本都不限时同一行改「本月已用」无条，不撑仪表盘卡。不做月维度按角色看板。近 30 日折线 + 锚点，零日落基线。活动表按对话一行（组团不拆队员；无会话的 AI 改写单独一行、不可点）；固定本月（额度周期；模型名单同本月 `cost_calls`）；列头筛模型。表上汇总是本月（及模型筛）合计（花费 · `↓ 输入 ↑ 输出`），不是这一页；条数跟表底分页。分页替换本页，不追加。点行打开那场对话。逐次调用、IP、端点、密钥、TTFT **否决**进账户页（气泡「用量」已分层）。

图节点 face **不显钱**（仅用时·工具）；**否决** face 叠积分。对话累计 caption **已退役**（零噪音）。状态条不挂花费。多 Agent 气泡脚只有一张账单：队长 + 队员 + 辩论的已入账合计（有图时不把未完成节点丢掉，也不把账本当成只加已完成节点）。回复未收口，或队长已结束但队员仍在后台跑，标「至今」；全部 run 终态且气泡已收口后去掉「至今」。具名恢复只藏重新生成；复制与费用行仍留在回复末尾，不回挂状态条。token 树与 ReAct 轮次只进底栏「用量」弹出层（树下再列每人一行：称呼、积分或 ¥、token；进行中的行标「至今」；树的总数是这些行相加）。**否决**气泡脚再挂「N 轮」或 tok/s，也**否决**按人并排两笔（主 Agent 一笔、队员一笔）。队长走平台、队员走自己的 Key 时脚上按付款来源拆开：`0.01 积分 · ¥0.04`。窗口占满比例挂在整块输入框外侧右边的窗口环上（`last_prompt` / 有效窗口：装配调低的那一档，否则目录 `context_length`），不是第二套用量产品、不用字符估 → [上下文传递可视化](/docs/03-AI核心/上下文传递可视化.md)。

**两口钟（有协作图时）**：条上「用时」= 协作事实流跨度（`run_plan` 后的帧，不含派工前 CEO 与图后终稿流式）；气泡脚秒数 = 这条回复的主动时间（`message_end.duration_ms` / `messages.usage.duration_ms`）。提问、审批、限流把回合挂起时，等人的空档不计入；续跑把下一段的墙钟加进同一条。两处可不同。条上冠「用时」；气泡脚只写 `12s` / `2m 34s`，不冠「用时」（完成时刻已在同一行）。无图时只有气泡脚这一口。→ `elapsedMs` / `turnElapsed.ts` · `AssistantMessageFooter`。

暂停（提问 / 审批 / 限流续跑）与停止一样：回复末尾用已经入账的调用画费用和「用量」。再次挂起不把用量写成 0。→ `project_settled_message_cost` · [成本配额与计费](/docs/05-平台与运维/成本配额与计费.md)。

**用量弹出层**：底栏「用量」一棵树。输入、输出为总数，完整整数、千分位（≥100 万仍紧凑）。计数单位只写在父行标签「输入 token」「输出 token」；缓存、思考不重复。缓存命中与未命中缩进在输入下，思考与速度缩进在输出下；子集为 0 不画。上游省略缓存拆分时，输入下只留「按未命中计价」。速度 = `输出 token ÷ generation_ms`（这条回复各次 LLM 调用「首个输出块 → 该次结束」之和，含思考、含队员，含续跑加进去的次数），文案「速度」「42.0 tokens/s」，不写 TPS。分子和分母是同一笔主动账。缺 `generation_ms`、输出不足 10、吐字时长不足 250ms 不出速度，不拿用时假算、不写 0。工具 / 等队员 / 等你拍板在脚上秒数里，不进这个除数。TTFT 单独一行跟在速度后面，不缩进在输出下：队长第一段流里更早的正数（思考或正文/工具），文案「TTFT」，不足一分钟一位小数秒（`1.8s`）。缺了不画、不写 0。气泡脚不挂速度和 TTFT。→ `UsageDetailPanel` · `formatOutputSpeed` · `formatTtft` · `message_end.generation_ms` · `message_end.ttft_ms`。

金额不跟逐 token。每次模型调用返回后，把该 run 已入账的各次调用价加总（不把跨峰谷的 token 再合价一次），经临时事件 `run_spend` 推到气泡脚和已打开的「资源消耗」。未收口标「至今」。刷新丢掉这次临时事件，下一笔调用或终态帧再补上；终态以 `run_completed` / `run_failed` / `run_cancelled` 上的花费为准。单聊没有协作图，队长的 `run_spend` 先记在当条消息上，收口后改读 `message.cost`。→ `resolveReplyInvoice` · `run_spend`。

## BYOK

有 curated 卡的模型（含用户自选 DeepSeek 4.1）出 ¥（Flash 按官网；平台代付仍写积分，官网 ×0.25）。不扣账户积分。说明只在详情 / tooltip（「按官网价目」）。无卡的模型费用位空，只留 token，不再标「未计价」。遗留社区 USD 估算行仍可出 `≈$`。`byok 分支 = billing_mode==="byok"`（平台代付休眠时走 token + 卖价面）。

## 配额拒绝

429 按 code 分流：`QUOTA_EXCEEDED` 可次级 CTA 去设置接 Key；`RATE_LIMITED` 等亦只出错误条文案（**否决**错误条一键重试）。限流族（`RATE_LIMITED` / `LLM_RATE_LIMIT`）在 attested `retry_after` 大于共享 `MAX_RETRY_AFTER`（30s，`@agentcore/contract-types`）时气泡与状态条都不展重试——与文案「重试会失败」对齐；阈值比较用 `>`，恰好 30 秒仍可重试。**不加** wire `retryable`。文案以后端 `message` 为单一来源。→ `lib/errors.ts` · `turnOutcome.ts`。

本发还没开始回复（无思考正文、无回答、无工具、无派工；转圈不算开始）即发送当没发生——撤泡并还草稿，`turnPhase` 回 idle。错误（若有）挂输入框卡片。用户停止 / 空中断同样还稿，不挂错误。限流暂停 / 要你拍板 / 重新生成不还稿。已有思考或半句则留下。账单 token 不挡还稿。

**首发**（本发刚 `POST` 出的空会话）：软删该会话、列表拿掉、回到 `/` 草稿；错误画在输入框卡片上（不进 textarea、不依赖「有气泡才出条」）。作废 `client_request_id`（复用会领回已软删行）。软删进「最近删除」，侧栏对话列表不再出现。**跟发**只回滚本发，不拆会话。断线可能仍在跑：不还字，走重连。重新生成不删旧 user。会话级失败横幅仍由聊天输入区读（指挥台已随总览撤）。→ `useComposerSend.ts` / `ComposerFailureBanner` / `zero_output_rollback.py`.
