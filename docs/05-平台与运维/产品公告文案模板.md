# 产品公告文案模板

运营发「产品公告」（Admin Notice / Banner + Modal + IM 官方号）时套用；**勿每次现编结构**。

- **Admin UI**：`/notices` → 新建公告 → 顶部「套用模板」→「快捷填写」槽位 →「生成正文」→ 再微调标题/正文（同源：`apps/admin/src/lib/noticeTemplates.ts`）。
- **CLI（发版两段式）**：`pnpm release:notice`（`scripts/release-notice.mjs` → 调 `publish:notice`）。`--phase preview|done` · `--kind release|hotfix`。维护/政策/故障仍走 Admin UI。
- **半自动发版清单**：`pnpm release:ship`（打印步骤；`--track api|full`；`--check` 探桌面 draft）。
- **CLI（底层）**：`pnpm publish:notice`（`deploy/scripts/publish-product-notice.mjs`）——自定义标题正文时用。

字段默认（未特别说明时）：`severity=high` · `surface=both` · `dismiss_policy=once` · **`card_template=service`**（官方号服务通知卡，卡面看完）。维护/故障可把 `dismiss_policy` 改为 `never`。政策/额度/安全类用 `surface=modal`（仅 `dismiss_policy=once`）。长文 changelog / 功能故事用 **`card_template=article`**（须填 `summary`；`cover_url` 可选）→ [管理员后台 · 官方号双模板](/docs/05-平台与运维/管理员后台.md#官方号双模板服务通知--图文)。

**发版 / 热修 CTA ✅**：`release` / `hotfix` 模板与 `release:notice` 默认 `检查更新` → `/more/about`；`--no-cta` 或清空字段可关。

**横幅标题写法（`surface∈{banner,both}`）**：Banner 只渲染标题。格式为 **约时/窗口在前** · **劝停句在后**（定稿：`请按需规划好时间 · 提前停止使用 AI 功能`）；版本号、亮点放正文，勿挤进标题。

## 发版公告两段式（定案 D）✅

全端发版与后端热修走 **预告 → 收口**，避免「约时已过代码未上」或「已上线无人知」单段错位。

| 段 | 何时发 | 命令骨架 | 用户听感 |
|---|---|---|---|
| **预告** | 人定「今天发 + 约时」后**立刻发**（与 `release:gate` / 修拦阻**并行**）；**勿**等 gate 全绿才预告。门禁不过 → **改约时**或 Admin **归档预告**，禁止闷头修却不改点 | `pnpm release:notice -- --phase preview --kind release\|hotfix --at HH:MM …` | 劝停 AI；写清约时 |
| **收口** | 后端验收通过；全端还须 **桌面 release 已 Publish + 官网已 deploy**（api-only 则后端验收即可） | `pnpm release:notice -- --phase done --kind release\|hotfix …` | 已完成、如何更新 |

- **部署前**仍须 `release:gate` 全绿（预告早发 ≠ 可带红灯上线）。
- 预告默认 `--end-hours 4`；收口默认 `2`（可改）。收口后可在 Admin **归档预告条**，减少双横幅。
- **禁止** `deploy:backend` 成功回调自动发公告（误发成本高；热修/全端文案不同）。
- 清单卡位见 `pnpm release:ship` 与 `.cursor/rules/cursor-deploy.mdc`。

## 1. 后端短更新（热修 / 无感或近无感）

**标题**：`约 {HH:MM} 更新 · 请按需规划好时间 · 提前停止使用 AI 功能`

**正文**：

```text
我们将于今天约 {HH:MM} 进行一次系统更新，预计 1–3 分钟。

更新期间 AI 功能不可用。请按需规划好时间 · 提前停止使用 AI 功能，以免进行中的对话或任务被中断。

更新完成后刷新即可；一般无需重装客户端。
本次：{一句话变更摘要；多条用「；」分隔，勿贴 commit hash}

若结束后仍异常，打开消息页「AgentCore 官方」或稍后重试。
```

**适用**：只发 `pnpm deploy:backend`、无桌面/手机发版。Admin 模板 id：`hotfix`。

## 2. 全端发版（含桌面 / 手机）

**标题**：`约 {HH:MM} 发版 · 请按需规划好时间 · 提前停止使用 AI 功能`

**正文**：

```text
新版本将于今天约 {HH:MM} 起陆续上线。

更新期间 AI 功能不可用。请按需规划好时间 · 提前停止使用 AI 功能，以免进行中的对话或任务被中断。

升级方式：
· 桌面：应用内检查更新，或到官网重新下载安装
· 手机 / Web：刷新页面，或按官网指引安装新包

本次亮点：
{≤5 条，每行一条用户能感知的变化}

完成后按上面方式升级即可继续使用。
```

Admin 模板 id：`release`。版本号可写在正文首句或亮点前（如「桌面 {版号}」），**不必**进标题。

## 3. 计划维护（较长中断）

**标题**：`{开始}–{结束} 维护 · 请按需规划好时间 · 提前停止使用 AI 功能`

**正文**：

```text
计划维护：今天 {开始}–{结束}（约 {N} 分钟）。

维护期间无法登录或发送消息，AI 功能不可用。请按需规划好时间 · 提前停止使用 AI 功能。

窗口结束后自动恢复，无需重装。
原因：{一句话，如「数据库迁移 / 证书轮换」}
```

建议：`dismiss_policy=never`，并设 `end_at` 为窗口结束后约 30 分钟。Admin 模板 id：`maintenance`。

## 4. 政策 / 额度变更（必读弹窗）

**标题**：`{政策或额度主题} · 生效 {日期或「即日起」}`

**正文**：

```text
{一句话说明变更是什么、对用户有何影响}

生效：{日期 / 即日起}
详情：{可选 CTA 文案，如「查看完整说明」}
如有疑问，打开消息页「AgentCore 官方」查看本条归档。
```

**字段**：`surface=modal` · `dismiss_policy=once`（不可 `never`）· 建议 `severity=normal` 或 `high`。首次 publish 会同步写入 IM「AgentCore 官方」。Admin 模板 id：`policy`。

**适用**：配额调整、计费政策、服务条款更新等需用户登录后确认一次的通知。

## 4.1 平台额度临时不可用（接入自己的 Key）

**标题**：`平台额度暂时不可用 · 请接入自己的 Key`

**正文**：

```text
平台提供的额度暂时不可用。

请到「设置 · 服务商」接入自己的 Key 即可继续使用。

如有疑问，打开消息页「AgentCore 官方」查看本条归档。
```

**字段**：`severity=high` · `surface=both` · `dismiss_policy=once`；**不设**外链 CTA。可选槽位「补充说明」可写恢复预估等。Admin 模板 id：`quota_unavailable`。

**口径**：只说明平台额度暂时不可用，并引导到「设置 · 服务商」接入自己的 Key；不点名第三方中继，**不附**注册 / 充值步骤。走运营 Notice，勿在客户端硬编码 Banner。

**适用**：平台侧额度临时不可用。恢复后归档或设 `end_at`。已发出的旧模板 `quota_jiurelay` 须运维另行归档（改模板不会自动归档已发公告）。

## 4.2 平台额度已恢复（单模型 Flash · OpenCode Go）

**标题**：`平台额度已恢复 · 当前仅 DeepSeek V4 Flash`

**正文**：

```text
平台测试额度已恢复（内测期提供测试额度）。

当前平台模型：DeepSeek V4 Flash（经 OpenCode Go 订阅上游，非免费档。该路上 DeepSeek 按 OpenCode Go 当期 zero-retention / 零留存条款，声明写到 2026-08-31 且按月续约，非永久承诺）。额度仍为每月 / 每日上限；用尽后可在「设置 · 服务商」接入自己的 Key 继续使用。

如有疑问，打开消息页「AgentCore 官方」查看本条归档。
```

**字段**：`severity=normal` · `surface=both` · `dismiss_policy=once`；可不设 CTA。Admin 模板 id：`quota_platform_restored`。

**口径**：说「内测期提供测试额度」，不说「送 N 元」；点明单模型（付费 Flash）与 BYOK 高级选项；**不**把 Go 说成免费或无限；隐私跟 Go DeepSeek ZDR **当期条款**（写到 2026-08-31、按月续约），不写成永久承诺，不沿用 Zen `-free` 措辞。发前先归档进行中的 `quota_unavailable`（以及仍在线的旧 `quota_jiurelay`）。

**适用**：从临时 `byok` 切回 `billing_mode=platform` 且目录仅 `deepseek-v4-flash`（OpenCode Go）时。

## 5. 故障 / 降级（突发）

**标题**：`服务异常 · 处理中`（或补具体范围）

**正文**：

```text
我们已察觉到 {功能/范围} 异常，正在紧急处理。

当前影响：{登录 / 对话 / 消息等}
临时建议：稍后再试；已打开的对话可先保存草稿。
进展会同步到消息页「AgentCore 官方」。
```

**字段**：`severity=critical` · `surface=both` · `dismiss_policy=never`。恢复后归档，或设 `end_at` 避免过期横幅残留。Admin 模板 id：`outage`。

## 6. 功能上线（小功能 / 体验改进）

**标题**：`新功能 · {功能名}`

**正文**：

```text
{功能名}现已上线。

你可以：{1–2 句怎么用 / 入口在哪}
如有反馈，请通过设置 → 反馈告诉我们。
```

**字段**：`severity=normal` · `surface=inbox`（需要顶栏曝光可改 `both`）· `dismiss_policy=once`。Admin 模板 id：`feature`。

## 7. 安全提醒（必读弹窗）

**标题**：`安全提醒 · {主题}`

**正文**：

```text
{发生了什么：如「我们已为你重置密码 / 检测到异常登录」}

请你：{改密 / 核对设备 / 忽略说明}
如非本人操作，打开消息页「AgentCore 官方」或通过设置 → 反馈联系我们。
```

**字段**：`severity=high` · `surface=modal` · `dismiss_policy=once`。Admin 模板 id：`security`。

## 8. 内测 / 活动

**标题**：`邀请 · {活动名}`

**正文**：

```text
{活动/内测一句话}

参与方式：{入口或步骤}
时间：{起止或「即日起」}
欢迎把体验反馈发到设置 → 反馈。
```

**字段**：`severity=normal` · `surface=inbox` · `dismiss_policy=once`；需要外链时填 CTA。Admin 模板 id：`campaign`。

## 填写清单（发之前勾）

- [ ] 时间用用户本地习惯（北京时间），写清「约」
- [ ] **`surface∈{banner,both}`：标题须「约时/窗口在前 · 劝停句在后」**（定稿劝停句：`请按需规划好时间 · 提前停止使用 AI 功能`）；Banner 不展示正文
- [ ] 摘要写**用户能感知的事**，不写内部文件名 / SHA
- [ ] 热修用模板 1；有桌面 bump 用模板 2；政策/额度变更用模板 4；平台额度临时不可用引导接入自己的 Key 用模板 4.1（`quota_unavailable`）；平台额度恢复（单模型 Flash）用模板 4.2（`quota_platform_restored`）；故障用模板 5；安全用模板 7
- [ ] **发版/热修**：预告 + 收口两段都发了（或收口时归档预告）；`pnpm release:notice` / `pnpm release:ship`
- [ ] 发完自检：桌面顶栏 Banner / 登录弹窗 / IM「AgentCore 官方」对应 surface 能看到
- [ ] 部署完成且验收通过后，可在 Admin 归档本条（可选）
