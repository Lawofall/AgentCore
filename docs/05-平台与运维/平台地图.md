## 三条读序

**上线 / 发版**  
认证与会话 → 部署拓扑与环境 → 发布与门禁 → 安全权限与治理

**改计费 / 模型目录**  
平台 LLM 接入 → 成本配额与计费 →（前端）成本呈现 / UX §十三

**查产品 AI 失败回合**  
`conversation-logs.mdc`（`apps/server` 跑 `log_timeline`）。假卡 / 横幅 / 缺窗等才开 [分析指南 · 症状进层](/docs/05-平台与运维/对话日志分析指南.md#症状进层）。

**首次自托管**：拓扑 §一–三 → 配置 §八 → 发布 §7.8 清单  
**日常发版**：发布 §七 + 本地手册  
**改门禁 / conformance**：发布 §九
