# 辩论质询证据与证人

> **权威范围**：质询式交锋（质询·记分·举证·结辩）、证人模式、证据台账。主干循环见 [辩论编排设计](/docs/03-AI核心/辩论编排设计.md)；前端 → [辩论室 UX](/docs/04-前端/辩论室UX.md)。
>
> **主循环归属**：随辩论归「**组**」+「**看**」；本文是其交锋质量面 → [主循环](/docs/01-产品/产品定位与品牌.md)。

## 一、决策：独白相递 → 质询式交锋

三支柱咬合：质询产出交锋事实 → 记分据此奖惩 → 举证让「无据」结构可见可罚。复用 round / `continue_run` / SSE / 双产物，不重建引擎。

**否决**：① 只改辩手 prompt；② 独立 Arena / 独立 SSE；③ 质询 CX 全开（`thorough=False` 跳过 CX）。

## 二、质询（P1）

- 主持人对各方发尖锐必答题；被质询方以 `continue_run` 在**自己的 transcript** 上答——非新辩手。
- 仅 `thorough=True`；回避由裁判读 Q↔A 裁定（诚实认输 ≠ 回避）；前端只渲中性 Q→A，不贴褒贬。

## 三、记分（P2）

- 逐轮三维分 + 罚分；收场 `leaning/confidence` 由累计分推导，`brief.decisive` 点名胜负手。
- `evidence` 按【来源等级】：一手/权威可满；决定性事实仅靠单一二手即便【已核实】也只算弱证据。
- **记分仅收场消费**：live `debate_round` 可携 `scores`，进行中叙事**有意不带**。

## 四、举证（P3，方案 A 内联）

- 关键事实紧跟 `【已核实·#eN】` / `【待核实·推断】`；未标按待核实。
- 诚实标【待核实】不罚；把无据当已核实才罚。待核实/单一二手不得当既定事实定倾向。
- 场级台账：`#eN` 可溯；成稿 id 闸＝本方笔记引用集；不上 `citations_event`。
- **方案 A 而非 B**（结构化 `claims` 演进未上）。已核实=success 绿、待核实=muted 灰（禁用琥珀）。

## 五、结辩（P4，方案甲）

- 收敛后、简报前：各场辩手最后一次短结辩；硬禁新论点/新证据。**新场跳过**（`closing_enabled` 恒假）；结辩 runner / `closing_task` 留旧场回放与单测。
- 协作图：**一列=一轮**（质询折进同轮节点；旧场结辩保留「终章」列）。否决质询/结辩全独立成列。
- **方案甲而非乙**（完整发言角色状态机未上）。

## 六、两阶段成稿 + 对局台账

- 检索笔记（不进 outputChunks）→ 无工具干净成稿；结辩跳过检索。否决靠 preamble 剥除治收工混入。
- 辩手检索顶与 worker 共用 `engine_worker_token_ceiling`（独立辩论档已并入）。
- 裁判兼产 `ledger_events`（withdrawal/correction/disputed_fact/concession），双向注入下轮；**只进 prompt、不上 wire**。与论点账本分工：账本喂裁判，台账喂辩手行为约束。

## 七、证人模式

- 幕1 透镜**不再**以证人入开辩：开辩是独立重活。证人机制代码仍在，产品路径不探测。
- 无透镜 session → 整场零行为；失败/空点名不阻塞。
- **否决**全量续派转任辩手（冷起接线/图锚/RunSpec 契约硬墙 + 滤镜污染中立）。**暂不做**透镜摘要注入辩手起点。
- 席位在辩论幕、答问挂证人节点（不挂幕1）；用户点名/辩手主动传证人 v1 不做。
