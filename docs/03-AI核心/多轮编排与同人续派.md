# 多轮编排与同人续派

> **定位**：看到队员产物后，让「同一队员带现场记忆接着干」。CEO 入口 = `delegate.tasks[].continue_from_run_id`（[编排器 §2.7](/docs/03-AI核心/编排器与CEO主Agent.md)）。
>
> **主循环归属**：「**收**」之后回到「**说**」的短回路——用户对产物提改法，不必重新组队 → [主循环](/docs/01-产品/产品定位与品牌.md)。

## 心智与统一原语

- **P-1**：用户只对 CEO 说改法；不在 worker 卡做定向修改入口。
- **统一原语**：worker run = 可恢复 `RunSession`；续干 = 在 transcript 上追加指令再跑 `react_loop`。改稿与新任务同一动作（内容不同）。不重建 system；本轮 `team_brief` 挂在续干 user 指令里（冷开局才进 system）。
- 收编：自动返工 / CEO 续派 / `run_redirect` 热修 / 辩论续轮。

**否决**：多套「重做/续任务」并存；`revise` 与续派双轨（已统一进 `continue_from_run_id`）。

## 甲 / 乙

| | 形态 |
|---|---|
| **甲** 冷委派 | 旧产物当输入，派新人 |
| **乙** 带现场续派 | 唤回原作者，续写 transcript |

乙在内存+盘双 miss 时**明确拒绝**并提示回落甲（不静默降级）。调查/审查批 → 用户确认按结论修 → **默认乙**（对各调查 run `continue_from_run_id`；换 title ≠ 换职能）。甲仅：真换职能 / 无现场 / 合并多产物 / 调查失败无现场（救失败稿若 transcript 仍在亦可乙）。

## 批次收口后：乙就是那个一等入口

批次收口（harvest 回合）后 `replan` 不可用——它只活在受监督态。此时**唯一**能动同一支团队的正式入口就是再调 `delegate`、在 `tasks[]` 上点名上一批的 `run_id`（乙 = `continue_from_run_id`，补缺口 = `replaces_run_id`）。D3（点名一并限流、模型只剩 `force`）**已修**，CEO 契约已删 `force`。闸口径 → [编排器 · 同队续派一等入口](/docs/03-AI核心/编排器与CEO主Agent.md#同队续派一等入口)。

## 契约约束

| 项 | 约束 |
|---|---|
| 校验 | 未登记/自指/双 miss → 拒该项；**只有真·未终局**才回「进行中，用 `depends_on` 等它完成」，CANCELLED（改方向 / 超时强杀 / 只停这项）与 SKIPPED 是**终局且无可续现场**，各自说实话并指冷委派 + `replaces_run_id`——不得叫 CEO 去等一个不会完成的节点；拒绝折成的 FAILED 标 `error_retryable=False` |
| 唤回上限 | 作者链 `recall_count` 合计 **3**（CEO 续派与 redirect 共用）；**辩论续写豁免**（归 `RoundPolicy`） |
| 工具面 | 执行层默认全开（不靠手填收窄）；乙续派兼容字段若仍带 `tools`，merge **只增不减**进现场，未声明则沿用；不得静默减面、不得换马甲冷开特例 |
| 登记 | 单 run 终局即登记（COMPLETED 或 FAILED 且 transcript 非空）；CANCELLED 的 salvage 现场只在同批 redirect 热续里用、**不入名册**；SKIPPED 无现场 |
| 落盘 | `run_sessions`；「对话在，现场就在」级联删；默认不按时长清扫 |
| 深度 | 续写不增委派深度；硬上限 `depth ≤ 3` |
| 同人表达 | wire `continues_run_id`；**否决**跨 run 稳定 `agent_id` 实体化 |

## 产品 / 技术决策

| # | 决定 |
|---|---|
| P-2 | 接续链可见、可对比（图上「续 ×N」） |
| P-3 | 回落甲默认无感 + `replaces_run_id`「接手」角标；否决每次硬告知弹窗 |
| P-4 | 改稿=新任务，同一 `continue_from_run_id` |
| P-5 | 现场随对话生命周期，非 7 天产品语义 |
| T-2 | transcript 独立表，异于图回放 journal |
| T-4 | 每次续写独立 member ledger 行 |

## 投影接缝：星型存 · 链式渲

- 后端：`continues_run_id` **恒指现场根**；`parent_run_id` 恒为真正委派父（不兼职修订锚）。
- 前端：`buildGraphStructure` 把星型**铺成链**交 ELK（曾照星型平行边 → 坐标重合）。
- `run_started` 携 `round`/立场；缺则从现场根继承。三端 conformance 金样钉死。
- **入口兼容**：续派成功后 roster 登记「链末端 id → 根」别名，使 CEO 误填图上可见末端仍可溯根；拒续派须发 `run_failed`（否则图卡「排队中」）。优先仍填现场根。

## 交付正文只留最终交付

- `deliverable_only`：非终止工具前旁白从成品回退，入 journal；终止轮工具前文本保留。
- **worker 发 `run_output_reset(reason=narration)`**（显示=数据单通道，直播须对齐 `message_final`）；**CEO 不发**（正文与过程双通道）。
- **否决**给 worker 开旁白双通道。多段拼接靠 `join_segments` + continuity 操舵，不另开全量重写。

## `run_redirect` 接缝

并行中「立即改此人」：单人 cancel → **热优先** salvage 续写；空/失败 → **冷诚实** `_redir` 接手（`replaces_run_id`）。`run_cancelled.reason` 逐一分清 `redirect` / 整轮 `stop` / `user_stop` / 硬超时强杀 `worker_timeout`（口径见 [执行引擎 · 协作取消](/docs/03-AI核心/执行引擎架构设计.md)）。须走 interaction 桥（CEO 卡在 await 上）。忽略/确定性失败走 accept-outcome REST，**不新增 SSE**。

## 否决 / 暂不做

- 删甲只留乙；前情摘要代替 transcript；跨 run `agent_id` 实体化；语义裁判（暂沿用机械 contract）。
