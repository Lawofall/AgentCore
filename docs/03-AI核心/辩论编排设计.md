## 一、产品目标

**目标**：用对抗性多视角思考，帮用户得到能信、考虑过反面的**结论或决策**，同时看懂**思想如何交锋**。

| 三问 | 答案 |
|---|---|
| 谁用 | 决策者 / 学习者 / 方案作者 |
| 解决什么 | 决策（选 A/B）、压力测试方案、学懂争议话题、思辨 |
| 如何呈现 | 不主动启动，仅推荐结构化正反辩论；用户同意后再开。产出**过程 + 结论**双产物 |

**主持人为何存在**：辩论需要有状态编排——发起对抗 → 逐轮判收敛 → 裁决 → 交付双产物。它不是独立执行引擎，而是 **CEO 之下、辩手之上**的编排角色；底层仍复用并行委派 + 上游产物注入。「轮次」对用户隐藏，由收敛自停。

---

## 二、主持人循环

主持人 =「主持 + 裁判 + 书记」三合一。一轮四步：

| 步 | 做什么 |
|---|---|
| 1. 定本轮议题 | 首轮 `_frame` 拆争议焦点；后续优先用上轮 `verdict.next_focus`；`focus_override`（主框插手）最高优先 |
| 2. 派各方发言 | 新场只派正反并行波；缺席方标 `absent`，跳过对其质询 |
| 3. 质询交锋 | 仅正反 DEBATE；细节 → [质询证据与证人](/docs/03-AI核心/辩论质询证据与证人.md) |
| 4. 裁判 + 决策下一步 | 一次调用兼产：是否真交锋 / 可否收场 / 本轮小结（须带新点、仍争议；若有让步也写上）/ `next_focus`；收敛 → 简报收场，未收敛 → 下一轮 |

**结辩**：冷冻回放，新场不跑 → [质询证据与证人](/docs/03-AI核心/辩论质询证据与证人.md)。

**收敛**：由裁判逐轮自判（无实质新论点 / 焦点已成价值之争）；`max_rounds` 仅安全保险丝。正反约 5 轮上限。主持「裁判」= 辩论域交锋与收敛判定，≠ 通用 worker 质量门。

## 三、产品入口与 runtime 形态

产品入口只认**正反**：CEO 不主动开辩，仅推荐结构化正反辩论；用户同意后再调 `debate`。工具 description 开辩即正反，schema 不暴露 `form`，执行也不读该键。`DebateForm` / wire / `DEBATE_FORM_VALUES` 只认正反；未知或历史 form 字符串 coerce 成 debate，旧磁带不炸。加形态默认否决 → [扩展点清单 · §二 新增一种辩论形态](/docs/03-AI核心/扩展点清单.md#二新增一种辩论形态)。

| 形态 | 参与方 | 轮内拓扑 | 质询（新场） | 产物侧重 |
|---|---|---|---|---|
| **正反辩论** | 正 / 反 | `parallel_wave`（+ 质询） | ✅ | 简报先行 |

## 四、双产物

结束交付两样，不分主次：

1. **结论 · 决策简报**（正反用户面四件套）：倾向（可带「若…则翻」）+ 胜负手 + 把握档 + 未决清单（`value` / `fact` / `question`——按谁能闭合分，用户面不写类型名）。有未决就不另写建议复述倾向。用户面只写上列字段（wire 另有键不是一等公民）。
2. **过程 · 交锋叙事线**：逐轮焦点与小结，点进看全文与交锋边（`clashes`）。

呈现顺序：决策类（正反）简报先行。前端 → [辩论室 UX](/docs/04-前端/辩论室UX.md)。双产物走辩论室 / `debate_result`，不再落 `debate/` 约定柜。

## 五、开赛材料

有材料就当底料汇入来源账；没有就发言时自己查。完整度只作内部预算（材料齐则立论不再外搜），**不另开准备阶段**，也不拦「材料不够就不能辩」。

1. **开赛材料汇流**（CEO `background` / 附件 / 已声明 `#rN`）→（可选）附件已在主持人上下文时组装共享证据包。
2. 完整度为 **`full`** → 立论外搜预算 **0**。
3. 否则各方在**发言期**做对称有界检索，命中写入同一串 `#rN`；成稿**只引台账**。

**已退役（勿再写为现行）**：开赛后主辩点单 → 主持人代派取证员 → 并行登记；`gap_fill` 派员；不留「深证」窄门；开赛前再问用户要不要先调研。

**就地否决**（仍否决）：给辩手 `delegate` 提深度；中立取证员；取证笔记全文灌主辩起点。→ 见代码: `runtime/debate/evidence_pack.py`。

## 六、进行中插手

用户是老板：辩论默认自动跑、**永不硬停**。进行中对这场说话走**主输入框**（传输仍 `/debate-steer` continue），主持人在**下一轮边界非阻塞**捞起。产品面不暴露 conclude（协议仍接受、无界面入口）；空队列回落裁判自动收敛。Stop 取消整回合、不产双产物。

干预只作用议程 + 价值层，不篡改事实层。收场后再辩 = 对 CEO 说话重开全新辩论（无 durable resume / 结构化补轮）。前端 → [辩论室 UX](/docs/04-前端/辩论室UX.md)。→ 见代码: `runtime/debate/steer_queue.py`。

**「永不硬停」的边界**：指辩论**自身不设阻塞式逐轮闸**——不会停下来等用户点头才进下一轮。它**不豁免全局 Stop**：用户显式 Stop 照常取消整个回合（含在跑的辩论），权威 → [执行引擎 · 协作取消](/docs/03-AI核心/执行引擎架构设计.md)。两者不冲突：一个说辩论内部不主动挂起，另一个说用户始终能掐断。

## 七、技术落点摘要

- **入口**：用户点名后 CEO 调编排工具 `debate`（schema 在 `tools/builtin/debate/`；域逻辑在 `runtime/debate/`）。主持人 = 确定性 Python 循环 + 逐步结构化 LLM 判定，非自由发挥编排 agent。判定调用的思考与人读产物走既有 `run_reasoning_delta` / `run_output_delta` 挂在主持人 run（侧面板同其它 AI 的 ProcessTimeline）；`thinking` 仍声明 false。交锋全文仍在辩手 run / 辩论室。
- **复用**：并行委派 / `continue_run`（辩手跨轮带记忆）/ WaveScheduler / 工人发射闸 / steer 队列；不重建引擎。
- **图结构**：CEO → 主持人（完成态节点）→ 辩手。开辩独立成图，不链调研宿主、不把调研员拉进场当证人。跨回合开幕另起一张锚在本回合的图（旧磁带 `prev_execution_id` / divert 仍可回放） → [编排器 · 跨回合延续](/docs/03-AI核心/编排器与CEO主Agent.md)。
- **契约**：`DebateResult` = brief + rounds + `narrative_first`；收场 `debate_result` 为 journal 权威；发言全文靠 `run_id` 取回，不进事件。
- **约束**：`stance` 薄单句（禁论点清单）；`background` 可选底料双方共享；辩手 `collaboration=False`。填参 `sides[].key` 可选，省略由引擎编号；leftover 非空且不重复仍认。
- **真·多模型辩手**：**接线 ✅**——各方可填不同厂商模型（目录身份 `@platform/{id}` / `@byok/{provider_id}/{id}` 或口语消歧含用户「平台的」偏好 / `cross_model` 默认对阵；勿写未加 `@` 的路由键）；第一刀仅正反 2 方；空身份 = 同模型场，不读目录。桌面 sidecar 要目录时经 account 票 `GET /v1/account/models`，不打本机库；读不到则硬失败，不退回空目录。**端到端真跑验收 ⏳**（平台 vs DeepSeek 真跑待验）→ [路线图摘要](/docs/01-产品/产品路线图摘要.md)。细节 → 见代码: `runtime/debate/`（model plan / router extras）、`llm/turn_catalog.py`。

## 八、否决项

| 方案 | 结论 |
|---|---|
| **独立 Arena 子系统**（独立 SSE / 状态机 / `arena` RunKind） | **仍否决**——主持人不是独立引擎，只补产品层 |
| CEO 一次 `delegate` 静态展开 2N 节点 | 被主持人逐轮推进替代 |
| 机械 `min_rounds` 楼层 | 被裁判自适应收敛替代；`max_rounds` 仅保险丝 |
| 二元 pro/con 专属 | 被立场标签替代；产品入口与 wire 只认正反 |
| 再加辩论形态 / 历史 form 硬拒 | 否决。产品与 wire 只认正反；未知或历史字符串回落正反，旧磁带不炸 |
| 辩论室收成过程列 + 结论卡 | 否决；赛事页仍是看的面 |
| 开辩另开快速档 / 单轮对碰 | 否决；开辩即认真档 |
| 主持人 = depth-1 LLM 编排 agent | 改为工具内确定性循环 |
| 辩论独立 SSE 通道 / 散乱事件族 | 仍否决；收场靠 `debate_result` |
| 逐轮阻塞挂起（`DEBATE_ROUND`） | 被主框 ambient steer 替代 |
| 主输入框「出结论」 | 产品面已删；收场靠裁判收敛 / 轮次上限。协议 `conclude` 仍接受、无入口。勿扫正文猜「够了收」，勿把收场键搬回记分牌 |
| 人设模拟当「多模型」 | 否决；走真·多模型 |
| 非法模型身份 silent 回退 | 否决；空身份回退合法，非法硬失败 |
| 庭前调查员舰队（主辩点单→代派取证员→并行登记 / `gap_fill` 派员） | 否决；开赛材料 = CEO background / 附件 / `#rN` + 可选共享证据包 + 发言期对称有界检索入台账 |
| 把一场辩论冻成可复跑死图 | 否决——命题一次性，可复用的是形态不是这一场；入口合同写 `debate` description，不另立图。技术上辩论不写 `plan_snapshot`、辩手 `depth=2`、身份在 `DebateConfig` 不在 plan 层 |
