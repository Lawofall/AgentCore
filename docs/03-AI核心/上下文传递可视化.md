# 上下文传递可视化

> 让用户看见每个 Run **实际被喂进**什么。装配机制（保真度/工作区）→ [编排器 · 派单填参面](/docs/03-AI核心/编排器与CEO主Agent.md#派单填参面)；是否统一 Assembler → [上下文工程](/docs/03-AI核心/上下文工程.md)。
>
> **主循环归属**：「**看**」——把「队员到底知道什么」摊开给用户 → [主循环](/docs/01-产品/产品定位与品牌.md)。
>
> → 见代码: `runtime/runs/executor/context.py`

## 核心：单一源 / 双投影

先装配系统消息原文与有序材料 `ContextBlock`。材料块渲染 user prompt；`run_context` 的 sink = 镜像 `system` 块 + 开场 `tools` 表 + 材料块（CEO 则镜像 messages 数组 **和** 当时发给模型的 function-calling 表）。

CEO：blocks **镜像** LLM 请求（`system` 块 = 系统消息原文，不进 user；`tools` 块 = 开场 `tool_defs` 的人读投影，不是事后从注册表重拼）。队员：`system` / `tools` 同样镜像本回合 `system_content` 与开场工具表；**user 消息仍只由材料块拼出**——把 system 块再 join 进 user 会双份注入。`tools` 是开场快照：中途不改表（consult 不晋升、收尾不收窄），不回写这一块。

**否决**另起「为展示而拼」的路径（与真实 prompt 漂移比「不展示」更坏）。阅读器可以把同一条 `system` 正文按已有装配标签切成目录行——这是投影，不是第二套装配。

## 通道

端到端五路：① CEO 输入 · ② 上游产物 · ③ 工作区 · ④ 任务装配 · ⑤ worker→CEO 回流。worker 开工面展开为多值 `channel` 枚举（含 `request`/`tools`/`dependency`/`workspace`/`task`/…）；辩论续写 / 带现场续派另扩（`continuation` 等）——详见代码与 [辩论编排](/docs/03-AI核心/辩论编排设计.md)、[续派](/docs/03-AI核心/多轮编排与同人续派.md)。

## 四条决策

| # | 决策 |
|---|---|
| ① | `run_context` **进 journal**（重载可回放） |
| ② | `system` 切片：宽屏按需可见；窄屏（`isNarrow`，非 `platform===mobile`）整组恒隐藏 |
| ③ | **不分级**（无 usageDetail/powerMode）+ **简报阅读器**（`channel=system` 镜像按已有标签切目录：`<设定>` / `<按需目录>` / `<工作区>` 排在出厂指令前；CEO 当轮信封 XML 并进同一 `system` 体、不新开 SSE channel，模型仍把信封当成独立 user；无设定时目录标明未注入、不回填文件页；CEO 默认设定否则原始请求；队员坞默认第一条材料）。后来查阅从本回合 `consult` 回执索引，不回写 `run_context` |
| ④ | 事件投影 body 有标记截断护 journal；**prompt 仍全文**；CEO 与队员的 `system` 块均豁免截断 |

前端：CEO 弹窗与队员右坞共用同一阅读器壳；弹窗固定框（`max-w-2xl` × `min(32rem,70vh)`），不随选中段伸缩。队员坞入口在详情标题行右侧（「上下文」，无段数），点开同一弹窗；目录只在弹窗里。CEO 另有整块输入框外侧右边的窗口环，绑最后一条助手泡的 `captainContext`（生成中 `run_context` 一到就亮，弹窗开着随回传 / 后来查阅变长）；不进卡片、不跟发送簇；与底排＋/语音/发送同一行盒（`md` 铬条按钮），不贴卡片底边。按钮画窗口环：分子是本场对话的一条水位，即 CEO 最近一次已返回 usage 的请求 prompt（与压缩水位同一个数）。`window_prompt` 和回合收口带上的 `last_prompt` 都写入这一个数，后一次覆盖前一次，挂起后续跑因此会跟着变小或变大。本场还没有观测时，用最近一条已落盘的 `last_prompt`，所以新回合第一次计量前沿用上一回。不从协作图 `run_completed` 再拼一份，也不是回合累加 `input` 或 `chars/4`，分母是目录 `context_length`；两数都有才画比例，否则空环。悬停只写 used/window（`120.0k / 1.0M`），不重复名称和百分比；名称在按钮 `aria-label` 与弹窗标题。气泡底栏「收到的上下文」仍可翻该回合快照，不撤。来源角色写在目录行（`回传 · 角色` / `前置 · 角色`），正文顶不重复「来自 / 递指针 / 全文」。**已截断**只标预算或 journal 帽真切了正在读的副本；落盘走 pointer 不标（策略不是截断）。**否决**等权折叠卡；**否决**通道/段顶栏 tab；**否决**坞内铺目录/全文；**否决**后端去重/指针化（破双投影）；**否决**为展示重跑装配；**否决**把文件页未注入规则补进弹窗；**否决**每轮 `messages[]` / 完整 tools schema 写入 journal。CEO 开场 = 回合级 `captainContext`（非图节点）；回流 `team_result` 追加不覆盖。resume 不重发开场 `run_context`。
