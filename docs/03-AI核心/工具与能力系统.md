## 一、Tool / Skill / Rule 边界

| | Tool | Skill | Rule |
|---|---|---|---|
| 是什么 | 副作用 / 读写 / 需审计 | HOW 教法（按名拉取） | 行为约束（进 `<设定>`） |

### 模型面工具名 ✅ {#模型面工具名}

schema / journal / function calling 的 `name` 与给人看的过程线不是同一套词。用户面用人话（如「Read page」），**不**把 schema 名暴露给用户；历史 journal 保留当时原始 `tool_name`。

**没有全行业预训练标准词表。** 各家官方表连同一件事的标识符都不统一。改名须点名对照哪一家的哪张**官方** `name` 列、且职责同形；对不上就保持产品名。禁止用「贴合预训练 / 行业标准」当唯一入场理由。

| 对照源 | 用不用 |
|---|---|
| DeepSeek Harness 官方 `docs/tool-catalog.md`（standard / code 预设） | **用**：现网默认模型的写码短表；职责同形时取这套蛇形名与 `file_path` 字段 |
| Anthropic Messages API / Managed Agents 的官方 `name` 列（蛇形） | **用**：与 DSH 重叠的（`web_search` / `web_fetch` / `glob` / `grep`）已同形 |
| Claude Code 权限规则 PascalCase（`WebFetch` / `Read`） | **不用**：词根可参考，大小写不跟 |
| OpenAI Responses 托管工具 | **只认已公布的**：有 `web_search`，**没有**托管 `web_fetch`；知识库 MCP 深读约定是 `search` + `fetch`（≠ Anthropic `web_fetch`） |
| Cursor 公开 Agent 文档 | **不公布** wire 名；第三方逆向 PascalCase 表不作金标 |

**已对齐**（职责同形）：`read` / `write` / `edit`（DSH `dsh-tool-fs`；路径字段 `file_path`）；`glob` / `grep`；`web_search` / `web_fetch`。过程线人话仍是 Read file / Write file / Edit file。

**刻意不改**（假朋友 / 产品分裂）：

| 现状 | 不改成 | 理由 |
|---|---|---|
| `run` | `bash` / `shell` / `pwsh` | DSH `bash` 是一次性 `bash -c`，后台另有 `job_*`；本产品 `run` 还扛验证 / 长驻 / `action`，Windows 上按真 shell |
| `ask_user` | `ask_user_question` | 后置；提问不是写码主路径 |
| `delegate` | DSH `subagent` / Cursor `Task` | 假朋友（编排原语 ≠ 子代理工具） |
| `consult` | DSH `skill` | 假朋友 |
| `file_delete` / `file_list` / `file_batch` / `read_conversation` | 外家短名 | 职责本产品才有，DSH 默认预设无同形 |

**别名**：未知名只 did-you-mean，**永不**自动改写执行；**不**给废名注册第二把可执行工具。Unix `fetch`/`wget`/`curl` → 指向 `run`（不是 `web_fetch`）。废名 `file_append` / `str_replace_editor` → `edit`；`read_image` → `read`。旧产品名 file_read / file_write / str_replace **不**留别名（内测硬切）。废名连删（如已删的 `read_url` / `download_url`），禁止靠点名废字段「禁复活」。表 → 见代码：`tools/registry.py` `_KNOWN_TOOL_ALIASES`

**否决**：全套改成 Claude Code PascalCase；`run` → `bash`/`shell`；复活 `str_replace_editor` / 第三把写笔；裸 `fetch` 指到 `web_fetch`；独立 `download_url`；按 SKU 挂第二套工具表；把 Cursor 逆向表当预训练金标。不把 DSH 的 `todo_write` / `lsp` / `cordis_*` / `job_*` / `terminal_*` 当对齐赠品。

→ 见代码：`tools/registration/`、`runtime/skills/`、`tools/catalog.py`、`tools/registry.py`

### 工具目录（ToolFace + resident）

图鉴与模型按需栏共用一份**名册**（同一 `resident` / `catalog_summary` / `blurb` / `ToolFace`）。出厂工具与接上的连接器动作一律开场即用；没接上的连接器不列出动作。人侧不再盖「查阅后启用」。**模型 FC 表不再按 `resident` 扣留**。模型 `<按需目录>` 低频栏只列**有 HOW 正文**的面（工具侧现无，栏空则不渲染），开场即用不进该栏。人在工具箱「我的」铺能整理的教法（钉住的 / 按需夹 / 市场装来的），在「MCP」接本机 Server，在「官方」查阅提示词（准则与教法同一货架）与出厂工具。点开弹窗即说明书（干什么 / 要填的参数），不出 schema；卡标题是 `catalog_summary`（「这是什么」一句）；简介是 UI 专用 `blurb`（与标题相同则简介留空；禁把 schema description 铺上卡；协议名只在点开说明书；`blurb` 不进 `<按需目录>`）。提示词源（skill / 有 HOW 的工具 / rule；memory 不列活人目录）经 `consult` 骑同一按需目录，**不**另开工具种类 tab、**不**另开第三块「工具」货架。夹名是种类标记。人侧壳 → [用户技能](#用户技能与可编目录) · [前端 UX · 工具箱](/docs/04-前端/前端UX设计.md)。

九面：文件 / 文件夹 / 检索 / 网络 / 执行 / 本机·浏览器 / 表格 / 文档 / 编排。文件夹 = 产品 Folder 实体（用户规则作用域）；表格 / 文档面仍在枚举（创作多维表、创作文档均无 Agent 工具；白板面已卸）；工作区读图走 `read` 同一主力，不收图则诚实说明；编排 = 组队协作原语。注册面 `ceo_orchestration` 不是展示面，禁止把 CEO 专属工具默认丢进编排。超时豁免只跟真编排原语走（分组 ≠ 超时）。

| | 开场即用（`resident=True`） |
|---|---|
| 何时进 FC 表 | 装配即在开场工具表 |
| 人侧货架 | 出厂工具与接上的连接器动作都是这列；未接线不出现动作卡 |

`resident=False` 不再给人盖「查阅后启用」。引擎 grant / 授权白名单按**显式工具名**集合，不从 `ToolFace` 派生（分组 ≠ 授权）。→ 见代码：`core/types.py` `ToolFace` · `tools/catalog.py` · `tools/on_demand.py` · `tools/builtin/__init__.py` `file_mutation_tool_names`

### 系统 Skill 按需目录 {#系统-skill-按需目录}

能力指引栏排列轴 = **决策时刻**：编排 / 工作区 / 交付 / 产品 / 工具（与低频工具栏的 `ToolFace` 正交）。模型目录按此排序，不打子标题（摘要已是触发器）；只一栏时也不打「能力指引」，旁边有「低频工具」或「设定」时才打栏名。人侧工具箱目录仍用同一组名。目录行只写「这是什么」（`product_help` 另带一句何时翻，见下表），名字只出现在 `consult("name")` 里，不裸列在行首。HOW 默认在 `consult` 正文，本文不抄手册。编制 HOW、提问 HOW 不进本目录（分别在 `delegate` / `ask_user` 按钮）。工具箱货架简介是 `blurb`（UI 专用，不进 `<按需目录>`）。正交 WHEN 不合本（例：`product_help` vs `page_ui`）→ [上下文工程 · 目录行是触发器](/docs/03-AI核心/上下文工程.md#目录行是触发器)。装配表 → 见代码：`runtime/skills/catalog.py`

| 组 | `consult` 名 | 目录行 |
|---|---|---|
| 交付 | `data_file_landing` | 整理表 |
| 交付 | `page_ui` | 页面观感 |
| 产品 | `product_help` | 本产品是什么、入口在哪。用户在问这个产品本身时查阅。 |

## 二、引用质量闸

`web_search` / `web_fetch` 双通道：**成稿引用集**（`citations_event` = 正文实际引用）与**回合证据台账**（除 `blocked` 外全量登记）。档位单源 `citation_tier_for_url`——禁第二套分级器。对话气泡把已登记 `#rN` / `[n]` 画成 **favicon + 站名**（标题只在预览）；模型已写的 `[短名](url)` 且 url 在台账里则保留短名、只补同一颗 favicon。**不再**另挂来源卡。

| 档位 | 对话气泡 | 台账登记 |
|---|---|---|
| `blocked` | 出口剔除、永不写成链接 | **永不进** |
| `weak` | 仅成稿 `#rN` 引用时写成链接（不打档位徽标） | 登记宽、`citable=true` |
| `official` / `media` / `unknown` | 同上 | 登记宽 |

- **对话成稿 = 检索产物（✅ 重设计）**：正文链接 = 实际引用的已登记 id（`citable`，含 search-only / `weak`）。`#rN` 行内是 favicon+站名，不打档位徽标；`deep_read` 在预览标「已读」，搜索摘要引用保持沉默。模型 GFM `[短名](url)` 命中台账时保留短名。`finish_guard` / settle **不因** `#rN`、悬空 `[n]`、书目形态清空气泡或整篇 Rework；未登记号不当可点链接（可留白字），**不** `content_reset`。深读是终稿前模型自己 `web_fetch` 的加分，不是入场券。**已删**交卷后自动深读升级、气泡脚来源卡。
- **`selected`**：settle 时正文实际引用且已 `deep_read` 的 id 持久标 selected；跨回合 hydrate 保留。可选 `doc_kind`（登记时可写；否则 title/snippet 启发式）。
- **跨回合 hydrate**：新回合 `#r` 台账从历史 assistant `evidence_ledger` 合并进引擎核；LLM history 可不带 ledger 全文。
- `search_policy`：per-run 结构化信号（禁 prompt 触发）；`debate_evidence` 额外硬剔 weak / 商城词典等。
- 前置：query 词数/CJK 加权上限（超限可机械规范化并明示；无法规范化才拒）；CJK 查询剔无 CJK 命中；缓存键 casefold + 拉丁词序归一。
- 名单无真实分布依据——以合成样本校准（目前无真实数据，以下为假设）。

→ 见代码：`runtime/citations.py`、`runtime/evidence_ledger.py`、`tools/builtin/web/`

## 三、沙箱

代码执行：subprocess + `SandboxProvider`；云端 **云桌执行环境**（长寿命 gVisor guest，**默认开**；紧急 `GVISOR_ENABLED=false`）——工作区 rw-bind、uid≡文件侧 `app`、出站 SSRF chokepoint（与 `web_fetch` 同政策）；guest 用户态是声明的 packed rootfs，不是 API `/usr`；sidecar **本机桌**保留 subprocess。本机 `language=python` 的启动器按主机解析（POSIX `python3` 优先 → PEP 394；Windows `py -3` → PEP 397），语言 id 仍是 `python`；云桌 guest 仍只 exec 镜像里的 `python3`，不做 PATH 搜索。**本机引擎坐无绑定的云文件夹不装配** `run`：隔离执行只属于云执行面，sidecar 禁止在用户电脑上假装起隔离沙箱（Windows 会 `not_linux` 10ms 炸、还把本机解释器说成坏了；也禁止用 sidecar subprocess 冒充云隔离 → [安全 · 三、代码执行沙箱](/docs/05-平台与运维/安全权限与治理.md)）。缺口、换桌注册表与 `code_execution_enabled_for` 同一谓词。云协作 Linux 回合正常。云端 `run` / `package_install` / `browser` 同一装配谓词。云桌 guest 启动失败走 `exec_env_sandbox_unavailable`（对用户说云端隔离，不说本机）。云端 Chromium 在该 guest 内（能看桌上 `127.0.0.1` 开发服务器）；本机健康 Bridge 仍走 Local。

执行面切流、第二刀用户预览（观察 · 不排期）→ [安全 · 三、代码执行沙箱](/docs/05-平台与运维/安全权限与治理.md)。部署 → [部署拓扑 · 云端执行](/docs/05-平台与运维/部署拓扑与环境.md#云端执行gvisor)。Sandbox 相对 HTML 诚实失败见下节 `browser`。

### 写码验证双环（修码自检 / 外环门禁）✅

行业对齐：改码循环不要烧全仓 CLI，交付验收才跑**全量项目 check**。禁止把全仓 `tsc` 当修码自检、禁止靠盲加超时掩盖误用。

| 环 | 工具 / 机制 | 用途 |
|---|---|---|
| **内环** | 写盘后读已改文件；运行时问题用 browser / 读入口 | 不计入外环验绿。无独立语言服务工具 |
| **外环** | `run`（验证类） | 验收员 / `task.verify`：install · test · typecheck · build · 显式 command。超时只留**灾难顶安全网**强制中止 → `exec_forced_stop` / `contract_failure`（**不算工具家族熔断**）；**不**因一段时间没刷出新字就掐。真实执行失败按原因分类（退出码 127 / 找不到解释器 / 启动被拒），只失败该次，不卸工具。其它语言解释器失败不误伤 python 路径。 |

外环超时（定案：前台 ``run`` 不因沉默中止，**不**按命令长得像不像打包换钟；**废弃**「300/600 验证预算」合同与「墙钟熔断」口径）：绝对安全网 **20min（1200s）** 强制中止 → `exec_forced_stop` / `contract_failure`（**不算工具家族熔断**）。云端 gVisor 时长 cap **1230s**（≥ 灾难顶 1200 + slack；`GVISOR_TIMEOUT_MAX_SECONDS`）。验绿诚实口径仍 = **落盘 ∩ 外环真绿**（引擎不按验收 kind 硬判批次完成 → [编排器 · 交付验收](/docs/03-AI核心/编排器与CEO主Agent.md)）。修码：全量 typecheck 仅验收/外环。`verify_policy` 只认 CEO 显式 `inner` / `outer`（不按角色名猜测）；显式 `inner` 时 `run` 验证类拒全仓 typecheck/build，改道读已改文件 / browser。→ 见代码：`tools/builtin/run_verify.py` · `tools/sandbox/exec_env.py` · `runtime/runs/worker_budget.py`

### 执行三分（短 / 有界验证 / 长驻）

模型面 **一个工具 `run`**。三类 **CEO+worker** 同形，审批不因角色另造闸。`command` 按这台电脑的真 shell 执行（云端 / Linux / 已装 Git 的 Windows = bash；否则 PowerShell）。写了 `| tail` / `&&` / `cd` 就按写的发生。每次调用从工作区根起（或这次的 `cwd`）；`cd` 只在这一行有效，走出工作区或已授权根 → 失败并明说。长驻用 `background=true`（省略 `wait_for` 则起来就返回），已有进程用 `action=read|stop|list`。运行时按命令分类（短执行 / 验证 / 长驻）；分类是实现细节，不是三道模型题。缺口有无 `run`（`package_install` 仍独立）。审批 → [安全 §二](/docs/05-平台与运维/安全权限与治理.md)。

| 类 | 用途 |
|---|---|
| 短执行 | 会很快自行退出的内联代码 / 短命令；墙钟与验收同一灾难顶（20min），**不**因沉默掐、**不**按长得像不像打包换钟。永不退出的等结果 / 开发服务器 → 长驻类（`background`）或本机 `host`。同会话多 worker 的短执行串行排队（验证 / 长驻不在此锁内）。读已有源码正文走 `read`，搜符号走 `grep`，勿 dump 或 open+re 到 stdout。派工把本回合已给的凭据写进 task（任务书落库；对外展示打码） |
| 有界项目验证 | **外环**项目 check（**install** / test / typecheck / build / 显式 verify）；流式输出走同一条 `on_output` → `tool_use_progress`：沙箱 subprocess / gVisor 直接回调；桌面 `execute` 在 op 未结时把 stdout/stderr 片段送回同一回调，调用结束仍以整段结果为准；超时 = **灾难顶 20min 安全网强制中止** → `exec_forced_stop` / `contract_failure`（验证未完成，**不算工具家族熔断**）；**不**因一段时间没刷出新字就掐。真实执行失败（退出码 127 / 启动被拒）只失败该次。同 `execution_id` 内 sibling 相同验证（解析后 argv 指纹）**inflight 合流 + 结果复用**，避免双 worker 各烧满超时；任一队员成功写盘后 cache **失效**（generation 丢弃陈旧入缓存）。执行中 busy=`verify`（不挡 idle patrol / `cancel_worker`）。云端装包 = 桌上 SSRF chokepoint（netns + 代理，与 `web_fetch` 同政策）+ 包装源白名单 env + 拒改源旗（`--registry` / `--index-url` 等）；PM 白名单 = npm/pnpm/yarn **与** uv/pip/poetry（同纪律；纯 Python 仓 install 不落 npm）；工作区即 guest 盘，`node_modules` / `.venv` 直接落盘。本地装包 = 权限轴 + 钉源 env（不吃主机 `registry_egress_available`），装在用户绑定目录。无授权 / 云无 chokepoint → 诚实甲降级（结构自检 / export_to_local），勿空转。修码自检读已改文件 / browser，勿用验证类冒充内环 |
| 长驻 | 开发服务器等永不退出进程；`background` / `long_running` 分流。本机传统：桌面主进程托管（`WorkspaceOp.process_*`）。云协作：同一张云桌 guest 内起进程，按 `conversation_id` 记账（同 Folder 多对话不共用一条 vite）。schema `GRANTABLE`（`action=read|stop|list` 免审；启动吃 `command` 轴）。健康失败则整类不装配（与 `run` 同一谓词） |

外环验绿（`task.verify`）**默认走** `run` 验证类。项目级慢命令（`npm/pnpm/yarn install|ci|test|build`、`uv sync` / `pip|poetry install`、`tsc`、`pytest`/`vitest`/`jest` 等）由运行时分进验证核：**任一段**像检查即整串进核（`rebuild; typecheck`、`test && echo hi` 同形），按灾难顶跑，**不**拒跑再改道到已合并掉的 `test_run`。装包闭环：链里只要有正规 install 段（`pnpm add` / `uv sync` 等）就钉源；拒改源旗（`--registry` / `--index-url`）；`cd` 只许落在工作区内。否决整串 `cmd /c`；否决剥掉 `| tail` 冒充真终端。引擎解析出的 check（无用户 command）仍走 argv，不套壳。→ 再 build/typecheck。打开源码再 print/dump 或正则扫描进短执行核 → **硬拒**并改道 `read` / `grep`（同构 `contract_failure`；解析表格 / 改文件 / 跑计算仍走短执行）。这些**选错通道**的硬拒在过程时间线上是 `tool_use_end.status=redirect`（「改用搜索」一类中性步），不是失败红行；模型回执仍是失败以便换工具。真短脚本仍走短执行核（解析 / 装包分流；墙钟与验收同一灾难顶）。云端沙箱 / GRANTABLE 与 `run` 同级治理（`code_execution_enabled_for`）。

写工具 miss 回执：执行类未装配 → 对照 `<工作区>` 缺口，勿空转；`escalate` / `handoff` 仍仅工人通道。worker 面工具已默认全开（含写盘），不催写盘的交付只约束进度（不要求 `edit`），不靠硬卸写工具。CEO 同样持写盘与 `run`（与工人同形；开场表有写盘族；导出仍按需）。Local 破坏性删（`run` / `host` 命令启发命中）→ 回滚主（回合 zip 基线）+ 窄闸辅；与 `file_delete` 软删分轨对齐 → [工作区 · 脚本破坏](/docs/02-架构/工作区.md) · [安全权限 · 熔断](/docs/05-平台与运维/安全权限与治理.md)。事实层只报根有无 Git，不软提示 `init_baseline`。→ 见代码：`tools/builtin/run.py` · `run_verify.py` · `run_short.py` · `run_process.py` · `source_inspect.py` · `runtime/engine/tool_exec.py` · `workspace/destructive_fs.py`

**长文落盘（✅）**：不成系统 Skill（不进按需目录；写工具 schema 只留「这是什么」）。【主路径】完整正文（含超长）一次 `write`（不硬拒字数、不扫括号配平 / 省略套话 / 覆盖缩水）；成篇后修订只用 `edit`。写盘只留这两把笔。HOW 在写回执与参数契约 landing 族；正式长文当场 brief 可由撰稿 task 带。截断逃生：更短但完整的 `write`，或用 `edit` 在唯一锚（含写回执 `end_preview`）后续写。成篇草稿 `file_delete` 不硬拒（默认可逆软删）。`edit` 找不到：单行短锚可附邻近原文（非精确、不标百分比）；多行只报整段不在（不按行模糊打分）；不唯一仍给精确命中 + 可复制邻行。写工具参数解析失败 → 过程线人话提示改完整写入或按锚续写，模型回执保留技术细节；连续失败**不**停用写文件（`force_segmented` 只留笔、不摘工具表）。空必填参数（如 `edit` 空 `old_string`）仍为 `contract_failure`，但指纹收敛为稳定 sentinel，使 REPEATED_FAILURE / validation streak 能收口（禁止靠换 file_path/new_string 刷空参）。CEO 识别用户粘贴的旧「参数不是合法 JSON」报错时禁教转义。否决：第三把写笔 / 骨架填空专收 append / 成篇后禁 append 硬闸；失败回执用单行模糊满分冒充整段已匹配；再立独立成文落盘 Skill / 并进 `data_file_landing`。→ 见代码：`tools/builtin/file_ops/` · `runtime/engine/tool_exec.py` · `runtime/loop_controller.py`

**工具参数契约（✅）**：LLM tool-call `arguments` 恒为 JSON **字符串**；协议渣预清洗后走唯一解析点 `parse_tool_call_arguments`：`json.JSONDecoder().raw_decode()` 接受完整值后的尾部多余字符；EOF 截断闭合对所有工具通用。失败按统一分型 `parse_class`∈`truncated|escape|other`（sanitize **后**计算；不确定归 `other`），回灌与熔断文案**只读 class + 工具族**——禁止截断场景教「原样重发全部」、禁止靠「是否写工具」猜根因。族策略：landing＝长文落盘姿势（截断改短或按锚续写/不停笔）；orchestration（`delegate`/`ask_user`）＝禁双包 + parse-only 不停用；handoff 无参数、不走字段 salvage（**禁**再按工具打第三条 salvage、**禁**通用 JSON repair 黑盒）；解析失败一律不改写参数，走 `args_parse_failed`。用户规则走 `write` `.agentcore/rules/*.md`（landing 族；半截/`…` 收尾或中段残缺标记 → **拒写入**）。日志 `tool.args_parse_failed` 带 `parse_class`。→ 见代码：`runtime/engine/tool_exec_args.py` · `tool_exec_call.py` · `tool_protocol_sanitize.py` · `runtime/loop_controller/` · `tools/builtin/file_ops/user_rules.py`

**工作区 Office/PDF 读（✅）**：`read` 对「看一下文件」交**观察信封**（成功结果），不是失败作文。docx（python-docx 段落+表，抽到字符顶即停）/ pdf（`start_page` 开窗、每窗约 40 页走 pdfminer；仅第 1 页窗抽失败才 markitdown）/ pptx·odt·rtf 与附件预解析同一核、可杀子进程。抽取闸是**抽出字符 + 墙钟约 12s**，不是整文件 5 MiB 入场券。摄入三闸分开：磁盘后端（sidecar / 云盘）**100 MiB**；过桥 `LocalWorkspace` IPC **25 MiB**；用户上传 **50 MiB**。sidecar / 云盘父进程只 stat，抽取子进程按路径打开；过桥仍走通道 `read_bytes`（桌面 Node 无 Python 抽取栈）。嗅探误后缀 / OLE 取 size 走 `read_head`（头字节 + 总大小），不走整文件闸。超时 / 扫描件 / 旧版 `.doc` OLE / 抽失败 / 超摄入顶 → 成功信封（`kind`: extract / scan / binary / truncated），`next` 指向按文件名归类，**禁止**「请用户转文本 / 提供更小文件」。抽出成功仍走现有编号窗口；PDF 页脚写明本窗页码，后面的页用 `start_page` 再读（`offset`/`limit` 仍是本窗文本行号）。`start_page>1` 不读旁路 `*.md`（旁路只覆盖首页窗）。xlsx/csv 不抽全文，同样成功信封。读时默认不写 `*.md`。文案不提抽取库、不教 `run` 硬解 Office。文本整读仍 5 MiB，超限才是 `too_large` 失败。→ [工作区 §七](/docs/02-架构/工作区.md) · 见代码：`tools/builtin/file_ops/observe.py` · `workspace/file_kind.py` · `workspace/attachment_parse.py`

**公网单文件落盘（已撤销独立工具）**：行业无 `download_url` 开场原语（Claude Code / Codex / Cursor 走 shell `curl`/`wget`；深读走 `web_fetch`）。现状：有 `run` 则命令里拉公网 URL（guest 出站与 `web_fetch` 同 SSRF 政策）；无 `run` 请人经面板上传。Unix `fetch`/`wget`/`curl` 只 did-you-mean 到 `run`，永不自动改写、**不**指到 `web_fetch`。废名 `download_url` 连删。**已撤**整段 curl/wget 改道到独立下载工具。用户面板 upload = 人推文件进工作区；`git` 浅克隆 = 仓进工作区。

**`web_fetch` / `read` 入参互斥（✅）**：工具保持拆开。`web_fetch` 仅 `http`/`https` 公网页；工作区相对路径、`file://`、盘符误喂不抓取、改道 `read`（`policy_failure`，不计网页深读熔断）。**禁止**给路径补 `https://` 再抓公网（文件夹名可长得像域名）。反向：`read` 收到 `http://`/`https://` 开头的 path 改道 `web_fetch`（`contract_failure`）；`http_client.py` 这类文件名不是 URL。不扫用户原文猜「这是文件」、不拦 GitHub URL。→ 见代码：`tools/builtin/web/web_fetch.py` · `tools/builtin/file_ops/read.py`

**`read` 区间视图（✅）**：默认整读（省略 `offset`/`limit` 读到 EOF 或安全顶）。安全顶 = **2000 行或 8 万字符**（磁盘原文，先到先停、完整行；单行超字符顶则整行留下）。未截断页脚「全文 N 行」；安全顶「第 a–b 行，共 N 行；已达行顶/字符顶」；自愿开窗且未达安全顶「第 a–b 行，共 N 行；未达安全顶，省略 limit 可整读」。**禁止**静默丢尾、**禁止**在正文插入通道头尾省略、**禁止**把安全顶做成 4k 头尾裁。`ToolResult.output_limit` 覆盖整段视图。通道/预算截断标记（`[系统视图截断·非磁盘内容]`）与交付残缺标记（「中间省略…」）**语义拆开**；压缩账本摘录标明磁盘未截，**不等于**文件被切。教员（`read` / `grep` / 审查纪律）同向：定位用检索，单文件默认整读，仅页脚已达安全顶或已有行号时开窗。超 5 MiB 磁盘闸禁止再教 `offset`/`limit`（分段仍先整文件入内存）。当轮堆叠税由同窗 **window compact**（压一次 → 新冻前缀）管；**否决**每轮滑动 `tool_clear`。完整视图页脚「全文 N 行」不进摘要。→ [执行引擎 · 同窗 window compact](/docs/03-AI核心/执行引擎架构设计.md#同窗-window-compact当轮唯一瘦身)。

**`glob` / `file_list` / `grep` 定位（✅）**：职责拆开，不是换名。不知目录时从工作区根搜。**`glob` = globstar 按名找**（与 Cursor Glob / Claude Code Glob 同类）：无斜杠按 basename 任意深度（`*.py`）；有斜杠按相对路径（`src/*.py` 一层，`pkg/*/name` 一层子目录，`src/**/*.py` 递归，`**/name/**` 任意深度该目录下）。**禁止**只填 `*` / `**` 当一层列举或整仓倒文件（失败，不改写执行）；一层走 `file_list`；递归全部须明确 `**/*`。`path` 可省=整仓；`path` 不是目录时从根按该段目录名（或同一 pattern）续找，回执诚实说明，不红。回执扁平相对路径、不是树。**已知目录一层**走 `file_list`（无 pattern；残留 `pattern`/`recursive`/`max_depth` 失败并改用 `glob`）。当前出生桌列目录 / 读文件走通用 `file_list` / `read`，不必先 `folders`。`file_list` / `glob` 按文件名列出图片（png/webp 等）；`grep` / `index_files` 仍跳过像素与其它 AI 噪音（列名 ≠ 进检索）。编译产物与工作区根压缩包仍不进列表（区外压缩包 / `*.zip` glob 豁免不变）。`grep` 一次 `rg` 满 N 停（`files_only` 只列路径）；省略 path 默认整仓。截断 = 本批触顶，返回集再排序，不是全库字母序前 N。跨桌按名找 / 摸底走 `delegate`；本回合点名的邻桌活文件走 `read`（不加换桌参数）。→ `file_ops/` · `grep.py`

**同轮并行 `read` 去重（✅）**：同一模型轮内 key = path + 有效窗，重复调用只执行一次。否决同 path 次数天花板（误伤迭代改稿；税由 window compact + 单次安全顶 + 本去重管）。→ 见代码：`runtime/engine/tool_exec_coalesce.py`

**确定性导出 Word/PDF（✅）**：`md_export`（`format=docx|pdf`）把工作区 `.md` 导出为同目录同名 `.docx` / `.pdf`（共享 `docs_export`；PDF 引擎 fpdf2）。排版两档 `standard`（默认，中文技术报告）/ `official`（正式文书通例：首行缩进两字、两端对齐、公文页边距、页码「— n —」）；档位只认入参，不扫正文猜。文件树右键「导出 Word」弹窗选档：技术报告 = standard，正式文书 = official。用户要「PDF / 可分享」时成文主路径 = 落盘 `.md` → `md_export(format=pdf)` → handoff；**禁止**多份 HTML 顶替 PDF，**禁止** `run`+reportlab 做主路径。云 = 本地同能力。→ 见代码：`docs_export/` · `tools/builtin/md_export.py`

**FILESYSTEM 容量合同 ≠ 活性超时（✅）**：文本整读字节顶（5 MiB）/ 行 / 条目触顶 → 早失败 `contract_failure`（`too_large` 等）+ 可执行下一步（不计工具熔断累计）。Office/PDF **抽取**墙钟约 12s 或无文本层 = 成功观察信封，不是合同失败、不是通道活性挂起。墙钟只表示通道/协程**活性挂起**（文案禁原样重试；仍计熔断，steer 强调缩小范围/换策略）。云 `ServerWorkspace` 文本整读上限与桌面 Local `WORKSPACE_READ_MAX=5MiB` 对齐；过桥抽取摄入 `WORKSPACE_EXTRACT_SOURCE_MAX=25MiB`（IPC）；磁盘抽取 `OFFICE_EXTRACT_DISK_MAX_BYTES=100MiB`；上传 50 MiB。三闸不许绑死。Local 通道 deadline **由外层工具活性预算派生**（非第二套独立 60s）；`timeout_ms` 下发桌面 AbortSignal，迟到 settle 仍 stale no-op。单次 settle 超时只失败该 op。履约流断开时桌面已在跑的文件通道 op 立刻失败（「桌面在重连，请再试这一下」），不算连不上；尚未投到桌面的仍走 reconnect grace。文件连不上只认履约在场（桌面未连接 / 未持根 / 发起设备离线），不认超时次数；桌面重新连上后恢复文件工具与写盘派工。用户可见句：「工作区/本地文件连不上，请稍后重试或重开桌面」；写盘派工硬拒。本机执行环境失败不粘性收走 `run`（新队员仍能看见工具）。通道有界并发（默认 16）：仅约束 Local `WorkspaceChannel` 同时 await 桌面的 op；超额排队（计入外层墙钟）——云盘/`workspace_lock` 不动。**过桥 settle（✅）**：云 `interactions` POST 带墙钟；桌面对 `NetworkError` / 5xx / 429 **进程内短重试**（仍在服务端 op 预算内）；重试耗尽才记 fail，并强制 SSE 走 transport-drop → rejoin，避免「本地已算完、settle 毛刺当连不上」与后续 `workspace_op` 无人履行。→ 见代码：`workspace/limits.py` · `workspace/channel.py` · `runtime/tool_deadline.py` · `runtime/engine/tool_exec.py` · 桌面 `clientToolFulfill.ts` · `interaction.ts` · `streamConversation.ts`

## 四B、本机 Host（第三能力面）✅ 单工具 `host`

> 与 Workspace / Browser 正交。模型面 **一个工具 `host`**，只有必填 `command`（用户这台电脑上的短命令）。装包是 `winget` / `brew` / `apt install`，恒确认；格式化磁盘与静默安装器仍熔断。运输层是桌面回填 `HostOp.SHELL`。GUI 面见 [§四B′](#computer-use)。

| 通道 | `ChannelProfile`（`X-Client-Platform` → surface / `desktop_online` / `can_bind_folder`）为单源；缺头 / 未知 → fail-closed（两旗均为假）；**禁止**用 `location=local` 抬升 `desktop_online`（与鉴权 `parse_client_platform` 缺头/未知 fail-closed 同精神，aud 侧则直接拒）。**本机引擎（sidecar）回合**与云端桌面回合同构：传 `desktop` → `desktop_online=True` → 建 `DesktopClientChannel`（真机已验收） |

| 分工 | CEO 持 `host`（与工人同形，只有 `command`）。另持 `run`（工作区命令；非 Host 面；与工人同形）。分集 → [编排器 · 核心定位](/docs/03-AI核心/编排器与CEO主Agent.md) |

`<工作区>`：短坐标 + 缺口（只报未装配的 `run` / `package_install` / `host` 等）；云 reach =「执行：云端 · 出站：产品网络」；本机 =「执行：用户本机 · 出站：这台电脑」（本机 Host 以开场表 / 缺口为准）。云端 `run` 已装配时，系统行列 packed guest 声明在 PATH 上的命令（与 guest 阶同步，见代码 `CLOUD_GUEST_SURFACE`）；未装配只写 OS/壳。本机系统行是用户 OS，不套云菜单。出站被挡靠工具回执，不要 `consult(browser)`。通道是否可达由装配表达，**不**每轮打 INFO、**不**把电量/磁盘/应用列表塞进每轮上下文。`host_ping` 不进模型面（通道不可达则整面不装配）。**`package_install` 与 `run`**：云端同一装配谓词（桌 guest）；本机装依赖跟执行类。装用户这台电脑上的软件是 `host` 命令（`winget` / `brew` / `apt install`），开场表有 `host` 即可，该命令恒确认。

**否决**：13 个 `host_*` 旧名注册或转发；再立 `action` / `panel` / `package_id` 等参数；每加一种观测就加一个工具；用工具名隔离 CEO / 恒确认；Web/手机假装已查本机；任意 URL / exe 静默装；云 Alone 假装装到用户本机；模型填任意 abs cwd（cwd 由运行时注入已授权根）；单点音频特例工具；用「工具很多」当隐私闸（隐私写在 handler 返回什么）。

→ 见代码：`desktop/channel.py` · `tools/builtin/host.py` · `runtime/pipeline/prepare.py`

| 装配 | **账户/会话级**：用户启用的 Server → 本回合 **注册表**（CEO+worker）且 **开场 FC 表灌入该批 `mcp_*` schema**（不再 consult 晋升）。**prepare/resume 只读进程缓存**（`cache_only`，miss → 未装配、不 await ClientTool）；打开文件夹 / 非回合暖写入缓存（seed 或显式 network `list_tools`）；桌面按 warm 回传的 `ttlSeconds` 在 `startTurn`/`resume` 过期后续暖，并在 **detached execution 存活期**周期续暖（与账户用户规则注入同纪律，避免后台团队仍跑时下一回合空装配）。用户中途启用/关掉 Server → 下一次用户回合开场可改表（一次前缀击穿，等同换插件）。不做按文件夹 / Agent 绑定。用户规则注入 → [记忆 · 注入](/docs/03-AI核心/Agent记忆与知识系统.md#注入) |
| 失败 | Server 未启 / 握手失败 / 崩溃 / stderr 诊断 → **降级为无该批工具**（错误明细含 stderr 尾 + 日志 + 缺口 `mcp`），不阻断纯聊；**禁止**整段 ignore stderr |
| UX | 工具箱「官方」查阅提示词（准则与教法）与出厂工具；MCP 是顶栏独立栏（无本机通道不画）；点开弹窗接线；不把插头报出的动作再铺一层；手册「MCP」 |

## 四D、Git 闭环 {#git-闭环}

> **产品心智**：模型用 `run`（工作区）或 `host`（用户这台电脑）写 git / `gh` 命令。用户 SCM = 改动面板下方的文件夹版本轨，与模型命令同一当前文件夹仓。**回合 zip 基线**仍是「本回合可回滚」主路径（即将改文件 / 可能删盘才留底，问候不打点），与 git **正交**。凭据：**人配置、进程继承、失败诚实**——命令参数里不收密码。→ [安全 · git force 统一 DENY](/docs/05-平台与运维/安全权限与治理.md) · [前端 UX · 改动双轨](/docs/04-前端/前端UX设计.md)

模型面没有 `git` 工具。`git push` 与 `gh pr create` 恒确认。`git push --force`（含 `--force-with-lease`）、把 `main` / `master` 当作 push 目标、`git reset`、`git clean` 硬拒。开 PR 写 `gh pr create`。私仓账户级 PAT（设置 · Git 凭据，AES-GCM）只注入云端单独一条 `git` / `gh`（短命令与后台启动同一规则，可带 `git -C`；拼上别的命令则不注入）。Local 继承 OS credential helper / `gh auth`。**UI** `clone_repo` 仍为任意 http(s)+SSRF，与模型命令分开。有 `local_subpath` 时用户 SCM 落该文件夹子目录（与 `read` / `write` / `edit` 同基准）。

| 面 | 要点 |
|---|---|
| 用户 SCM | 分支条（干净也显示）→「改动」上这次对话 / 下 Git 仅脏或领先落后 → 人可 stage/commit/push/pull；Git 只认当前文件夹是仓库 |
| 同仓串行 | 模型 git 走 `run` / `host` 的进程，不再用独立 git 工具锁 |

**否决**：再立结构化 `git` 工具；AI 代持密码；改动 tab 冒充三方冲突工具；默认放开 hard reset / force / 保护分支 push；全局 git 锁（不同仓库/工作区互相排队）。→ 见代码：`tools/builtin/git_ops/spawn.py`（云端凭据）· `workspace/git.py` · `workspace/git_credentials.py` · `runtime/command_policy.py` · `runtime/safety_breaker.py`

## 用户技能与可编目录 ✅ {#用户技能与可编目录}

> **主循环归属**：**组**（CEO `consult` 看见的那份目录；文件夹设定仍沿近的覆盖远的）。跨用户货架 → [能力商店](#能力商店)。

已确认并落地。账号级「我的技能」加成 `<按需目录>`；官方 HOW 只读（代码真源，不占槽、不搬家）。出厂工具与官方 HOW 的人侧查阅在「官方」；本机插头在工具箱「MCP」栏。开口仍是一句话：配置发生在工具箱，不摊进「说」。

**三面怎么打开**

| 面 | 用户可配 | 仍只读 |
|---|---|---|
| 技能 | 基座条目：加成目录行（名字 + `description` + 正文） | 系统薄技能代码真源；全员准则；官方 HOW 不开放改 / 换 / 搬家 |
| 工具 | MCP 栏增删启停与接线（不把插头报出的动作再铺一层） | `DECLARED_TOOLS`；不开放注册内置级工具；不按名卸掉某个内置工具（权限轴已管写盘 / 命令 / Host）；不因技能新装工具、不跳审批 |
| 目录 | 人侧：加或编「我的」行并切常驻·按需 | 模型仍只吃一份 `<按需目录>`（`name` + `description`）；`GET /v1/capabilities` 仍是部署级图鉴，不是用户配置真源 |

**官方 HOW 不是用户资产。** 系统薄技能的 `name` 仍是运行时槽位（`consult(page_ui)` 等），正文只出厂。不喜欢某一条 → 写「我的」，不能卸能力、不能把用户稿接到官方槽。

**编辑面不再绑工具。** 常驻只把正文打进 `<设定>`；按需只加成目录行。存量 / 市场上架快照里的 `offers_tools` 给人看，**不**当启用闸、**不**把常驻技能再塞进按需目录。

**存储。** 用户技能是普通基座条目，不新建 Skill 表、不把系统 Skill 搬进 DB。协作桌成员吃这张桌文件夹层的设定；账号层「我的」仍私有。

**人侧。** 工具箱四栏：官方 / 我的 / MCP / 市场。账号层，不钉回 `/files`。无左栏文件树。「我的」里人能改的提示词怎么进模型：必带矮卡 / 按需行。MCP 是独立栏（没有本机通道不画这个 Tab）。用户夹是区标题，包住我的 / 市场卡（名字 + 触发语进 `<按需目录>`——触发语写干什么、何时查阅，空则不可检索；`consult` 才拉正文）。未入夹的按需进「其他」。准则与官方 HOW 同在「官方」的「提示词」货架（准则在前），出厂工具另区；都只读、不能拖、不能按名关掉；registry 的 `group` 不投影成用户夹。MCP 栏一行一个 Server，顶栏「添加」接线，不把插头报出的动作再铺一层。读 = 居中 Dialog。点卡直达正文，弹窗不再出夹名单（`?tool=` / `?skill=` 打开官方读卡）。官方 HOW / 准则只预览；我的有正文默认预览、空条目默认编辑。编辑面名称，按需才出一句话（干什么、何时查阅；空着不可检索），停敲自动存。市场装来的不改姓成我的。顶栏「新建」只在「我的」，默认进刚建的夹，否则进「其他」；「新建夹」在按需区头；空夹是「拖到这里」。换档 = 拖到必带区或拖进某一夹的区（弹窗里不提供常驻\|按需开关；右键不列搬家）。我的 / 市场不要了就删（可多选，对齐文件树；官方 / 出厂不进选区）。上架只接受自己写的、夹里的文件。工具箱不提供停用。不要把 `<按需目录>` 做成整块 XML 文本框。不要把 AI 笔记做成与常驻 / 按需平级的第三区（停写停注入）。存量偏好 / 画像 / 导航不进这本货架。壳面细节 → [前端 UX · 工具箱](/docs/04-前端/前端UX设计.md)。

## 能力商店 ✅ {#能力商店}

> **主循环归属**：**组**——工具箱货架给 CEO 的 `<按需目录>` 增加可安装的域级 Skill。形态仍是工作台，不改称生态平台 → [定位 §四](/docs/01-产品/产品定位与品牌.md)。

与 ✅ [用户技能](#用户技能与可编目录)（账号层「我的」；文件夹层是设定）正交：那边是自己写；这边是陌生人上架与一键安装。货架只列用户 listing，不代码合成出厂 SKU。

**只卖 Skill。** 上架对象 = 用户技能那类基座条目（名字 + `description` + 正文）。全员准则仍只读、不许上架。Agent 不是 SKU。Tool 仍只走 MCP，不进货架。Rule / Memory / Team / 工作流图 **不上架**（否决按其做远期）。

**后端货架 API ✅**（`/v1/skill-store`，须登录；admin 下架 / 举报队列 `/v1/admin/skill-store`）。工具箱壳 ✅（桌面 `/toolbox/market` + 自己写的提示词上架；admin `/store`）。

### 上架（开放）

自己写的提示词可 **上架**：把当时的名字、一句话介绍、正文、场景分组打成 **版本快照** 送进公开货架，无预审。分组是闭集（法律合规 / 写作成稿 / 研究调研 / 产品商业 / 开发工程 / 决策对抗），上架必拣一组；只给人逛货架，不投影进提示词树、不进 `<按需目录>`。缺介绍或空正文拦住（人话：先写介绍 / 先写正文），不报英文字段名。之后改草稿不影响已上架版本；再上架 = 新版本（可改组）。下架只下 listing（`unpublished`；平台 `taken_down`），已安装副本仍在各账号。公开列表只 `published`。

### 安装（一键 · 快照复制）

入口在工具箱 **市场**（桌面；窄屏不上工具箱故不上）。点卡片出居中 Dialog：先见一句话介绍（旁标「装进去之后，CEO 靠这句决定什么时候翻开」；与标题重复则不铺），快照若写过工具名则列出「会用到这些」（空不画；不是启用闸），正文直接展示。主 CTA **安装** = 把该版本快照复制进提示词目录（徽标「市场」），立刻进 `<按需目录>`。壳 → [前端 UX · 工具箱](/docs/04-前端/前端UX设计.md)。

不绑：作者后续改稿不活跟随（有更新则再点一次）；删掉已装副本即卸装，货架回到可安装（不显示已装 / 有更新）。不改官方 HOW；不摊进「说」。

新实体只三件（现有基座条目盖不住跨用户发现）：**listing**、**version 快照**、**本账号安装记录**（指向那条本地文档）；另加 **reports**。不新建 Skill 表、不把系统 Skill 搬进 DB、不复活 Agent 版本当货架单元。注销级联 listing / installs / reports，已装副本不删。

信任（开放上架 = 无预审；Skill 正文经 `consult` 进模型）→ [安全 · 能力商店](/docs/05-平台与运维/安全权限与治理.md#能力商店开放上架)。壳 → [前端 UX · 工具箱](/docs/04-前端/前端UX设计.md)。→ 见代码：`api/routes/skill_store.py`

### 否决（商店）

| 方案 | 理由 |
|---|---|
| 上架 Agent / 复活 Agent 版本当 SKU | Agent 是运行时参与者 |
| 活跟随作者草稿 | 别人的 prompt 突然改写你所有对话的 consult |
| 安装即占官方槽 | 官方 HOW 只出厂；装进来是并列的一行，徽标「市场」 |
| 货架卖 Tool / Rule / Memory / Team / 工作流 | 代码副作用 / 常驻污染 / Team 与死图盖不住现有技能；拆法写技能 |
| 技能包内嵌脚本 / 新工具当 SKU | 装进去的是教法，不卖新工具 |
| 常驻注入焊开绑定工具 | 常驻只带教法；工具开场就在，不因查阅才启用 |
| 绑定跳过审批 | PermissionAxes / GRANTABLE 不因技能改道 |
| 对话里逛商店 | 配置在工具箱 |
| 对 Skill 正文做意图分类硬闸 | 阶梯 2：详情可见 + 举报下架；扫自由文分叉 → [安全 · 能力商店](/docs/05-平台与运维/安全权限与治理.md#能力商店开放上架) |
| 付费 / 创作者入驻账号类型 / 评分体系 | 第一刀不做 |
| 其余提示词整库竖铺 / 自由标签当主 IA | 进场整库仍按场景组出条（库顶官方精选）；不打成无分组一张网。上架必拣闭集一组 |
| 分组投影进提示词树 / 组变成种类 tab | 「我的」树按常驻 / 按需；顶栏官方 / 我的 / MCP / 市场。MCP 不是提示词种类 |
| 扫正文自动归组 | 意图分类器；上架时人拣 |
| 代码合成出厂商店 SKU | 货架只列用户 listing；域级 SOP 用户自写或上架。已撤法律 SOP 不挂回 |
