## 二、引用质量闸

`web_search` / `read_url` 双通道：**来源卡**（`citations_event` = 成稿实际引用）与**回合证据台账**（除 `blocked` 外全量登记）。档位单源 `citation_tier_for_url`——禁第二套分级器。

| 档位 | 来源卡 | 台账登记 |
|---|---|---|
| `blocked` | 出口剔除、永不挂卡 | **永不进** |
| `weak` | 仅成稿 `#rN` 引用时挂卡 + 弱源徽标 | 登记宽、`citable=true` |
| `official` / `media` / `unknown` | 同上 | 登记宽 |

- **对话成稿 = 检索产物（✅ 重设计）**：气泡来源卡 = 正文实际引用的已登记 id（`citable`，含 search-only / `weak`；`weak` 仍徽标）。`finish_guard` / settle **不因** `#rN`、悬空 `[n]`、书目形态清空气泡或整篇 Rework；未登记号不当可点角标（可留白字），**不** `content_reset`。深读是终稿前模型自己 `read_url` 的加分，不是入场券。**已删**交卷后自动深读升级。
- **落盘成文仍闸窄**：文件合同 / `two_phase` 升 B / 内容类落盘走 `citation_quality_reworks`，可引用集 = `deep_read ∪ selected`（对齐辩论 `commit_research`）。`AgentCore/文档/research/*.md` 成功落盘时，正文已引用且可登记的 `#rN` 升为 `selected`（供 CEO 汇总继承）。伪造/越界 id 仍不进台账。
- **`selected`**：settle 时正文实际引用且已 `deep_read` 的 id 持久标 selected；调研方向笔记落盘亦可 promote（见上）；跨回合 hydrate 保留。可选 `doc_kind`（登记时可写；否则 title/snippet 启发式）。
- **书目形态闸**：只打在**落盘成文**上——学位论文/期刊式著录绑定 `#rN` 时该 id 须 deep_read；元数据呈开题/答辩/公告类 → 文件合同回炉（禁域名黑名单）。无 `#rN` 绑定的 GB/T `[D]`/`[J]` 著录亦然。对话气泡不跑此闸。调研 `research/*.md` 遇未绑定书目时不再文末补脚注装锚。
- **调研两阶段引用**：**只认** `citation_mode=two_phase`（playbook 内部盖戳）→ 阶段 A 草案**不**跑成稿引用闸；同 worker 升 B 后再验；未声明退出。draft 不进 `delivery_status.artifacts` 主清单。**路径入口已撤**（原「落盘/声明路径在 `AgentCore/文档/research/` · `reviews/` 即算调研类」）：那个落点由扫 role·task 的正则填出，是隔一层的自由文推断；即兴成稿走 `cite_write_review`。✅ 该字段已离开 CEO schema，仅 playbook 内部盖戳。权威 → [编排器 · 派活单三档](/docs/03-AI核心/编排器与CEO主Agent.md)。→ 见代码：`runtime/runs/research_quality.py:is_two_phase_citation_deliverable`
- **跨回合 hydrate**：新回合 `#r` 台账从历史 assistant `evidence_ledger` 合并进引擎核；LLM history 可不带 ledger 全文。
- `search_policy`：per-run 结构化信号（禁 prompt 触发）；`debate_evidence` 额外硬剔 weak / 商城词典等。
- 前置：query 词数/CJK 加权上限（超限可机械规范化并明示；无法规范化才拒）；CJK 查询剔无 CJK 命中；缓存键 casefold + 拉丁词序归一。
- 名单无真实分布依据——以合成样本校准（目前无真实数据，以下为假设）。

→ 见代码：`runtime/citations.py`、`runtime/evidence_ledger.py`、`tools/builtin/web/`

## 三、沙箱

代码执行：subprocess + `SandboxProvider`；云端 **云桌执行环境**（长寿命 gVisor guest，**默认开**；紧急 `GVISOR_ENABLED=false`）——工作区 rw-bind、uid≡文件侧 `app`、出站 allowlist chokepoint；sidecar **本机桌**保留 subprocess。**本机引擎坐无绑定的云文件夹不装配** `run`：隔离执行只属于云执行面，sidecar 禁止在用户电脑上假装起隔离沙箱（Windows 会 `not_linux` 10ms 炸、还把本机解释器说成坏了；也禁止用 sidecar subprocess 冒充云隔离 → [安全 · 五、代码执行沙箱](/docs/05-平台与运维/安全权限与治理.md)）。缺口、换桌注册表与 `code_execution_enabled_for` 同一谓词。云协作 Linux 回合正常。云端 `run` / `package_install` / `browser` 同一装配谓词。云桌 guest 启动失败走 `exec_env_sandbox_unavailable`（对用户说云端隔离，不说本机）。云端 Chromium 在该 guest 内（能看桌上 `127.0.0.1` 开发服务器）；本机健康 Bridge 仍走 Local。

✅ **第一刀**：gVisor / Chromium 不进 API 进程；开通在 prepare / resume；聊天路径不准同步等开机。切流替换、不留 in-API 回落。装配谓词 = host 健康 ∧ 这张桌已注册（gVisor）；subprocess 逃生口仍只跟配置 / 健康。⏳ **第二刀**蓝图已确认：产品按钮换票、sandboxd 反代、就绪输出解析端口；不另立浏览器壳；Sandbox 相对 HTML 仍诚实失败（见下）。权威 → [安全 · 五、代码执行沙箱](/docs/05-平台与运维/安全权限与治理.md)。部署现状 → [部署拓扑 · 云端执行](/docs/05-平台与运维/部署拓扑与环境.md#云端执行gvisor)。

`browser`：工具装配与共控行为（本文）；**产品壳 / partition / 页签** → [前端技术 §9.12](/docs/04-前端/前端技术与架构.md)。单一工具 `browser(action=navigate|click|type|scroll|snapshot|console|screenshot)`；**全部 action 为 CEO+worker**（含 `screenshot`）。宿主分流（`browser_host_kind_for`，整会话单一 host，禁 local+sandbox 混绑）：健康 DesktopBrowserBridge → Local；无 Bridge 但云桌 guest 能起 → Sandbox（大众默认过桥）；`location=server` / Web / 无 Electron → 仅 Sandbox；真·本地引擎无 Bridge 且无 gVisor → 未装配（禁假成功）。**禁止**以 Bridge loopback 冒充云可达。云端看浏览器 = Linux API 上 Sandbox 跑通——验收口径 → [部署拓扑 · 云端执行](/docs/05-平台与运维/部署拓扑与环境.md#云端执行gvisor)。`action=console` 返回会话内环形缓冲（硬上限截断，禁止回传密码/超大 blob），**不**硬闸「没 console 不许 patch」。AI 永不经手密码（password 硬拒 → worker：`escalate(browser_login=true)`；CEO：`ask_user(browser_login=true)`）。用户明确「右坞打开 / 浏览器打开 / 帮我看页面 / 短搜短点」时 CEO 自己调 `browser`（勿为此 delegate）。mutation 成功结果含当前 `snapshot_version` 与新 ref 表；**动作回执是后置条件**：`type` 回 `typed{requested_chars, actual_chars, matched}`、`click` 回 `clicked{was_disabled}`，不满足即 `success=False`（`postcondition_failed`）。快照对表单控件把 `placeholder` 与 `value` **分列**，并附 `visible_text`。回合内发模型前投影只保留最近一次完整 elements/aria，折叠时补 `ref_delta`。

**打开本会话 HTML 站点（定案 · 甲 + 乙降级）**：仅 **host_kind=local**（真·Bridge）时 `browser(action=navigate)` 支持 workspace 相对 HTML 路径，走与用户产物「完整预览」同源的 `workspace://`（该对话的 workspace partition；URL host 须等于 partition 绑定 cid）；打开后可继续 click/type/snapshot。公网 URL 仍走该对话的 web partition（按 `conversation_id` 切开，不与其它对话共享 cookie）。**Sandbox（含过桥无 Bridge 回落）** → 相对路径诚实失败（工具回执指引「文件」面板 / 桌面「完整预览」；HOW → `product_help`），禁止假成功。→ 见代码：`tools/builtin/browser.py` · 桌面 `browser/host.ts`；产品蓝图 → [前端技术 §9.12](/docs/04-前端/前端技术与架构.md)

### 写码验证双环（内环诊断 / 外环门禁）✅

行业对齐：改码循环用**语言服务增量诊断**，交付验收才跑**全量项目 CLI**。禁止把全仓 `tsc` 当修码自检、禁止靠盲加超时掩盖误用。

| 环 | 工具 / 机制 | 用途 |
|---|---|---|
| **内环** | `code_diagnostics`；写盘成功后 in-process 桌可附带，过桥不阻塞写回执 | 本地 TypeScript LanguageService（桌面 `WorkspaceOp.diagnostics`）。按改动路径秒级反馈。过桥写盘不把查类型算进「文件还连着吗」。云桌 / 无 LS → 诚实 `unavailable`，**不**用全仓 `tsc` 冒充。不计入外环验绿 |
| **外环** | `run`（验证类） | 验收员 / task·`playbook_args.verify`：install · test · typecheck · build · 显式 command。超时分两类：**idle 挂起**（长时间无输出）→ `exec_timeout`（不卸 `run`）；跑满**灾难顶安全网**强制中止 → `exec_forced_stop` / `contract_failure`（**不算工具家族熔断**）。真实执行失败按原因分类（退出码 127 / 找不到解释器 / 启动被拒），只失败该次，不卸工具。其它语言解释器失败不误伤 python 路径。 |

外环超时（定案：**idle 挂起只失败该次**，灾难顶为辅；**废弃**「300/600 验证预算」合同与「墙钟熔断」口径）：默认 **60s** 无 stdout/stderr 即按挂起中止（`install` **120s**）→ `exec_timeout`（不卸 `run`）；绝对安全网 **20min（1200s）** 强制中止 → `exec_forced_stop` / `contract_failure`（**不算工具家族熔断**）。云端 gVisor 时长 cap **1230s**（≥ 灾难顶 1200 + slack；`GVISOR_TIMEOUT_MAX_SECONDS`）。验绿诚实口径仍 = **落盘 ∩ 外环真绿**（引擎不按验收 kind 硬判批次完成 → [编排器 · 交付验收](/docs/03-AI核心/编排器与CEO主Agent.md)）。修码：全量 typecheck 仅验收/外环。`verify_policy` 只认 CEO 显式 `inner` / `outer`（不按角色名猜测）；显式 `inner` 时 `run` 验证类拒全仓 typecheck/build，改道 `code_diagnostics` / browser。→ 见代码：`tools/builtin/code_diagnostics.py` · `write_diagnostics.py` · `run_verify.py` · `tools/sandbox/exec_env.py` · `runtime/runs/worker_budget.py` · 桌面 `fs/workspace/diagnostics.ts`

### 执行三分（短 / 有界验证 / 长驻）

模型面 **一个工具 `run`**。三类 **CEO+worker** 同形，审批不因角色另造闸。`command` 按这台电脑的真 shell 执行（云端 / Linux / 已装 Git 的 Windows = bash；否则 PowerShell）。写了 `| tail` / `&&` / `cd` 就按写的发生。每次调用从工作区根起（或这次的 `cwd`）；`cd` 只在这一行有效，走出工作区或已授权根 → 失败并明说。长驻用 `background=true`（省略 `wait_for` 时用默认就绪信号；命中前不得宣称已启动），已有进程用 `action=read|stop|list`。运行时按命令分类（短执行 / 验证 / 长驻）；分类是实现细节，不是三道模型题。缺口有无 `run`（`package_install` 仍独立）。审批 → [安全 §三](/docs/05-平台与运维/安全权限与治理.md)。

| 类 | 用途 |
|---|---|
| 短执行 | 会很快自行退出的内联代码 / 短命令；硬顶仍短（≤60s）。**第三方异步 HTTP 任务轮询 / 等结果超约 60s 不属短执行**（硬顶会杀脚本）→ 长驻类（会退出的进程 + wait）或本机短命令 `host(action=shell)`。同会话多 worker 的短执行串行排队（验证 / 长驻不在此锁内）。读已有源码正文走 `file_read`，搜符号走 `grep` / `code_search`，勿 dump 或 open+re 到 stdout。派工把本回合已给的凭据写进 task（任务书落库；对外展示打码） |
| 有界项目验证 | **外环**项目 check（**install** / test / typecheck / build / 显式 verify）；流式输出仅在沙箱内跑的通道成立（subprocess / gVisor 读 `on_output`），桌面通道不转发回调、输出结束时一次性返回；超时 = **idle 挂起（60s/装包120s 无输出）** → `exec_timeout`（不卸 `run`）；或 **灾难顶 20min 安全网强制中止** → `exec_forced_stop` / `contract_failure`（验证未完成，**不算工具家族熔断**）。真实执行失败（退出码 127 / 启动被拒）只失败该次。同 `execution_id` 内 sibling 相同验证（解析后 argv 指纹）**inflight 合流 + 结果复用**，避免双 worker 各烧满超时；任一队员成功写盘后 cache **失效**（generation 丢弃陈旧入缓存）。执行中 busy=`verify`（不挡 idle patrol / `cancel_worker`）。云端装包 = 桌上 allowlist chokepoint（netns + 代理）+ 包装源白名单 env + 拒改源旗（`--registry` / `--index-url` 等）；PM 白名单 = npm/pnpm/yarn **与** uv/pip/poetry（同纪律；纯 Python 仓 install 不落 npm）；工作区即 guest 盘，`node_modules` / `.venv` 直接落盘。本地装包 = 权限轴 + 钉源 env（不吃主机 `registry_egress_available`），装在用户绑定目录。无授权 / 云无 chokepoint → 诚实甲降级（结构自检 / export_to_local），勿空转。修码自检走内环 `code_diagnostics`，勿用验证类冒充内环 |
| 长驻 | 开发服务器等永不退出进程；`background` / `long_running` 分流。本机传统：桌面主进程托管（`WorkspaceOp.process_*`）。云协作：同一张云桌 guest 内起进程，按 `conversation_id` 记账（同 Folder 多对话不共用一条 vite）。schema `GRANTABLE`（`action=read|stop|list` 免审；启动吃 `command` 轴）。健康失败则整类不装配（与 `run` 同一谓词） |

外环验绿（task / `playbook_args.verify`）**默认走** `run` 验证类。项目级慢命令（`npm/pnpm/yarn install|ci|test|build`、`uv sync` / `pip|poetry install`、`tsc`、`pytest`/`vitest`/`jest` 等）由运行时分进验证核：**任一段**像检查即整串进核（`rebuild; typecheck`、`test && echo hi` 同形），按 idle / 灾难顶跑，**不**拒跑再改道到已合并掉的 `test_run`。装包闭环：链里只要有正规 install 段（`pnpm add` / `uv sync` 等）就钉源 + 装包 idle；拒改源旗（`--registry` / `--index-url`）；`cd` 只许落在工作区内。否决整串 `cmd /c`；否决剥掉 `| tail` 冒充真终端。引擎解析出的 check（无用户 command）仍走 argv，不套壳。→ 再 build/typecheck。打开源码再 print/dump 或正则扫描进短执行核 → **硬拒**并改道 `file_read` / `grep`（同构 `contract_failure`；解析表格 / 改文件 / 跑计算仍走短执行）。这些**选错通道**的硬拒在过程时间线上是 `tool_use_end.status=redirect`（「改用搜索」一类中性步），不是失败红行；模型回执仍是失败以便换工具。真短脚本仍走短执行核（≤60s）。云端沙箱 / GRANTABLE 与 `run` 同级治理（`code_execution_enabled_for`）。

**长文落盘（✅）**：【主路径】完整正文（含超长）一次 `file_write`（不硬拒字数、不扫括号配平 / 省略套话 / 覆盖缩水）；成篇后修订只用 `str_replace`。`file_append` **仅**骨架填空路径（本 execution 已 prose 则继续禁 append）。成篇草稿 `file_delete` 不硬拒（默认可逆软删）。骨架后按节填走 `file_append` / `str_replace`（防截断/超大）。写工具参数解析失败 → 过程线人话提示改完整写入或按节续写，模型回执保留技术细节；连续失败**不**停用写文件。同 path 连续 ≥2 次同类写硬拒（成篇后禁 append）→ 合流 `force_segmented`：收窄 `file_append`，保留 `file_write`/`str_replace`（成篇后 str_replace 修订）。空必填参数（如 `str_replace` 空 `old_string`）仍为 `contract_failure`，但指纹收敛为稳定 sentinel，使 REPEATED_FAILURE / validation streak 能收口（禁止靠换 path/new_string 刷空参）。CEO 识别用户粘贴的旧「参数不是合法 JSON」报错时禁教转义。→ 见代码：`tools/builtin/file_ops/` · `runtime/engine/tool_exec.py` · `runtime/loop_controller.py`

**工具参数契约（✅）**：LLM tool-call `arguments` 恒为 JSON **字符串**；协议渣预清洗后走唯一解析点 `parse_tool_call_arguments`：`json.JSONDecoder().raw_decode()` 接受完整值后的尾部多余字符；EOF 截断闭合对所有工具通用。失败按统一分型 `parse_class`∈`truncated|escape|other`（sanitize **后**计算；不确定归 `other`），回灌与熔断文案**只读 class + 工具族**——禁止截断场景教「原样重发全部」、禁止靠「是否写工具」猜根因。族策略：landing＝长文落盘姿势（分段/不停笔）；orchestration（`delegate`/`ask_user`）＝禁双包 + parse-only 不停用；handoff 无参数、不走字段 salvage（**禁**再按工具打第三条 salvage、**禁**通用 JSON repair 黑盒）；解析失败一律不改写参数，走 `args_parse_failed`。memory（`remember`）＝独立 `MEMORY_TOOLS` parse-only 不停用（勿塞进 dispatcher 用的 `ORCHESTRATION_TOOLS`）；截断→完整一句/分次，转义→修引号。`remember` 内容完整性：中段命中 omission 字面、或 `add`/`replace` 的 content 以 `…`/`...`/`……` 收尾 → **拒写入**（半截规则不得进库）。日志 `tool.args_parse_failed` 带 `parse_class`。→ 见代码：`runtime/engine/tool_exec_args.py` · `tool_exec_call.py` · `tool_protocol_sanitize.py` · `runtime/loop_controller/` · `tools/builtin/remember.py`

**工作区 Office/PDF 读（✅）**：`file_read` 对「看一下文件」交**观察信封**（成功结果），不是失败作文。docx（python-docx 段落+表，抽到字符顶即停）/ pdf（`start_page` 开窗、每窗约 40 页走 pdfminer；仅第 1 页窗抽失败才 markitdown）/ pptx·odt·rtf 与附件预解析同一核、可杀子进程。抽取闸是**抽出字符 + 墙钟约 12s**，不是整文件 5 MiB 入场券。摄入三闸分开：磁盘后端（sidecar / 云盘）**100 MiB**；过桥 `LocalWorkspace` IPC **25 MiB**；用户上传 / `download_url` **50 MiB**。sidecar / 云盘父进程只 stat，抽取子进程按路径打开；过桥仍走通道 `read_bytes`（桌面 Node 无 Python 抽取栈）。嗅探误后缀 / OLE 取 size 走 `read_head`（头字节 + 总大小），不走整文件闸。超时 / 扫描件 / 旧版 `.doc` OLE / 抽失败 / 超摄入顶 → 成功信封（`kind`: extract / scan / binary / truncated），`next` 指向 `read_image` 或按文件名归类，**禁止**「请用户转文本 / 提供更小文件」。抽出成功仍走现有编号窗口；PDF 页脚写明本窗页码，后面的页用 `start_page` 再读（`offset`/`limit` 仍是本窗文本行号）。`start_page>1` 不读旁路 `*.md`（旁路只覆盖首页窗）。xlsx/csv 不抽全文，同样成功信封。读时默认不写 `*.md`。文案不提抽取库、不教 `run` 硬解 Office。文本整读仍 5 MiB，超限才是 `too_large` 失败。→ [双模式 §七](/docs/02-架构/双模式工作区.md) · 见代码：`tools/builtin/file_ops/observe.py` · `workspace/file_kind.py` · `workspace/attachment_parse.py`

**工作区结构化下载（✅）**：`download_url` = HTTP(S) URL → 工作区相对路径落盘（`WorkspaceBackend.write_bytes`）。大小闸对齐用户上传顶（`workspace_upload_max_bytes`，约 50 MiB），**勿**与 AI `file_read` 5 MiB 读闸混淆。SSRF 复用 `core.net.classify_url` + 逐跳重校验 + `PinnedIPTransport`（与 `read_url` 同政策）。审批 `GRANTABLE`（FILESYSTEM 写副作用；少打断下走既有 `file_write=session` / turn grant 轴）。安装包扩展名/MIME **允许落盘并标明**，不执行、不静默安装（≠ 桶4 装软件）。边界并列：用户面板 upload = 人推文件进工作区；`git` 浅克隆 = 仓进工作区；本工具 = 单文件 URL 拉取。**禁止**教 `run` / `host(action=shell)` 当 wget/curl 主路径；正文深读仍用 `read_url`。→ 见代码：`tools/builtin/web/download_url.py`

**`read_url` / `file_read` 入参互斥（✅）**：工具保持拆开。`read_url` 仅 `http`/`https` 公网页；工作区相对路径、`file://`、盘符误喂不抓取、改道 `file_read`（`policy_failure`，不计网页深读熔断）。**禁止**给路径补 `https://` 再抓公网（文件夹名可长得像域名）。反向：`file_read` 收到 `http://`/`https://` 开头的 path 改道 `read_url`（`contract_failure`）；`http_client.py` 这类文件名不是 URL。不扫用户原文猜「这是文件」、不拦 GitHub URL。→ 见代码：`tools/builtin/web/read_url.py` · `tools/builtin/file_ops/read.py`

**`file_read` 区间视图（✅）**：默认整读（省略 `offset`/`limit` 读到 EOF 或安全顶）。安全顶 = **2000 行或 8 万字符**（磁盘原文，先到先停、完整行；单行超字符顶则整行留下）。未截断页脚「全文 N 行」；安全顶「第 a–b 行，共 N 行；已达行顶/字符顶」；自愿开窗且未达安全顶「第 a–b 行，共 N 行；未达安全顶，省略 limit 可整读」。**禁止**静默丢尾、**禁止**在正文插入通道头尾省略、**禁止**把安全顶做成 4k 头尾裁。`ToolResult.output_limit` 覆盖整段视图。通道/预算截断标记（`[系统视图截断·非磁盘内容]`）与交付残缺标记（「中间省略…」）**语义拆开**；`tool_clear` 摘录标明磁盘未截，**不等于**文件被切。教员（`file_read` / `grep` / `code_search` / 审查纪律）同向：定位用检索，单文件默认整读，仅页脚已达安全顶或已有行号时开窗。超 5 MiB 磁盘闸禁止再教 `offset`/`limit`（分段仍先整文件入内存）。`read_folder_file` 保持 500 行轻量抽样，不继承本顶。当轮堆叠税由 `tool_clear`（`keep_recent=2` 轮；一轮并行多读都留；**「全文 N 行」不进清理**）投影 → [执行引擎 · 回合内 tool_clear](/docs/03-AI核心/执行引擎架构设计.md)。

**`glob` / `file_list` / `grep` / `code_search` 定位（✅）**：职责拆开，不是换名。不知目录时从工作区根搜。**`glob` = globstar**（与 Cursor Glob / Claude Code Glob 同类）：无斜杠按 basename 任意深度（`*.py`）；有斜杠按相对路径（`src/*.py` 一层，`pkg/*/name` 一层子目录，`src/**/*.py` 递归，`**/name/**` 任意深度该目录下）；`*` / `**/*` 在深度顶 8 + 命中预算内递归列举。`path` 可省=整仓；`directory` 与 `path` 同义；`path` 不是目录时从根按该段目录名（或同一 pattern）续找，回执诚实说明，不红。回执扁平相对路径、不是树。**已知目录一层**走 `file_list`（无 pattern；残留 `pattern`/`recursive`/`max_depth` 失败并改用 `glob`）。当前出生桌列目录 / 读文件走通用 `file_list` / `file_read`，不必先 `list_folders`。`grep` / `code_search` 省略 path 默认整仓（内容 / 概念）。`list_folder_dir` 只给 CEO 派前轻量认**另一张桌**（一层；跨桌按名找走 `delegate`），不是工作区按名查找、不是跨文件夹摸底主通道。→ `file_ops/` · `grep.py` · `code_search.py` · `folder_fs.py`

**同轮并行 `file_read` 去重（✅）**：同一模型轮内 key = path + 有效窗，重复调用只执行一次。否决同 path 次数天花板（误伤迭代改稿；税由 `tool_clear` + 单次安全顶 + 本去重管）。→ 见代码：`runtime/engine/tool_exec_coalesce.py`

**确定性导出 Word/PDF（✅）**：`md_to_docx` / `md_to_pdf` 把工作区 `.md` 导出为同目录同名 `.docx` / `.pdf`（共享 `docs_export`；PDF 引擎 fpdf2）。用户要「PDF / 可分享」时成文主路径 = 落盘 `.md` → `md_to_pdf` → handoff；**禁止**多份 HTML 顶替 PDF，**禁止** `run`+reportlab 做主路径。云 = 本地同能力。→ 见代码：`docs_export/` · `tools/builtin/md_to_docx.py` · `tools/builtin/md_to_pdf.py`

**FILESYSTEM 容量合同 ≠ 活性超时（✅）**：文本整读字节顶（5 MiB）/ 行 / 条目触顶 → 早失败 `contract_failure`（`too_large` 等）+ 可执行下一步（不计工具熔断累计）。Office/PDF **抽取**墙钟约 12s 或无文本层 = 成功观察信封，不是合同失败、不是通道活性挂起。墙钟只表示通道/协程**活性挂起**（文案禁原样重试；仍计熔断，steer 强调缩小范围/换策略）。云 `ServerWorkspace` 文本整读上限与桌面 Local `WORKSPACE_READ_MAX=5MiB` 对齐；过桥抽取摄入 `WORKSPACE_EXTRACT_SOURCE_MAX=25MiB`（IPC）；磁盘抽取 `OFFICE_EXTRACT_DISK_MAX_BYTES=100MiB`；上传 50 MiB。三闸不许绑死。Local 通道 deadline **由外层工具活性预算派生**（非第二套独立 60s）；`timeout_ms` 下发桌面 AbortSignal，迟到 settle 仍 stale no-op。单次 settle 超时只失败该 op。履约流断开时桌面已在跑的文件通道 op 立刻失败（「桌面在重连，请再试这一下」），不算连不上；尚未投到桌面的仍走 reconnect grace。文件连不上只认履约在场（桌面未连接 / 未持根 / 发起设备离线），不认超时次数；桌面重新连上后恢复文件工具与写盘派工。用户可见句：「工作区/本地文件连不上，请稍后重试或重开桌面」；写盘派工硬拒。本机执行环境失败不粘性收走 `run`（新队员仍能看见工具）。通道有界并发（默认 16）：仅约束 Local `WorkspaceChannel` 同时 await 桌面的 op；超额排队（计入外层墙钟）——云盘/`workspace_lock` 不动。**过桥 settle（✅）**：云 `interactions` POST 带墙钟；桌面对 `NetworkError` / 5xx / 429 **进程内短重试**（仍在服务端 op 预算内）；重试耗尽才记 fail，并强制 SSE 走 transport-drop → rejoin，避免「本地已算完、settle 毛刺当连不上」与后续 `workspace_op` 无人履行。→ 见代码：`workspace/limits.py` · `workspace/channel.py` · `runtime/tool_deadline.py` · `runtime/engine/tool_exec.py` · 桌面 `clientToolFulfill.ts` · `interaction.ts` · `streamConversation.ts`

## 四B、本机 Host（第三能力面）✅ 单工具 `host`

> 与 Workspace / Browser 正交。模型面 **一个工具 `host`**，按 `action` 分流、运行时升审批（同构 `git`）。运输层仍是桌面回填 `HostOp`（`status` 对本刀既有 L1 op **并行 fan-out** 拼装，不改桌面契约）。GUI 面见 [§四B′](#computer-use)。

| 项 | 契约 |
|---|---|
| 可用性 | 仅桌面 + 回填通道可达；与 folder/bind 正交（裸聊云 scratch 亦可） |
| 通道 | `ChannelProfile`（`X-Client-Platform` → surface / `desktop_online` / `can_bind_folder`）为单源；缺头 / 未知 → fail-closed（两旗均为假）；**禁止**用 `location=local` 抬升 `desktop_online`（与鉴权 `parse_client_platform` 缺头/未知 fail-closed 同精神，aud 侧则直接拒）。**本机引擎（sidecar）回合**与云端桌面回合同构：传 `desktop` → `desktop_online=True` → 建 `DesktopClientChannel`（真机已验收） |
| 运输 | ClientTool / channel 回填（对标区外挂载 / `desktop_notify`）；**禁止**以 DesktopBrowserBridge loopback 冒充云可达；**禁止**在 sidecar 内再拉一套 MCP/Host stdio。`DesktopClientChannel` 在 `desktop_online` 时装配（含云 backend） |
| 工具 | 单一 `host`（`host_class` · schema `NEVER` · CEO+worker 注册）；**不**挂 `execution_class`；GRANTABLE **action** 不吃 `command=auto` 静默授。工具名不再当权限表 |
| 分工 | CEO 持 `host`（全 action 与工人同形）。另持 `run`（工作区命令；非 Host 面；与工人同形）。分集 → [编排器 · 核心定位](/docs/03-AI核心/编排器与CEO主Agent.md) |
| 权限 | PermissionAxes `host`：`off`/`ask`/`session` → [安全 §三](/docs/05-平台与运维/安全权限与治理.md) |
| **三分日志** | ① **OS Host 事件日志** → `host(action=os_log)`（仅本机 Host）；② **任务/沙箱/构建 stdout** → `run`（长驻 read / 短执行 / 验证；**云侧任务日志亦此主路径**）；③ **产品 AI 对话日志** → `search_conversations` / `read_conversation`。禁止混称 |

| `action` | 谁可调 | 审批 | 做什么 |
|---|---|---|---|
| `status` | CEO + worker | 免批 | 一次返回有界快照：OS / 磁盘 / 电源 / 网卡 / 音频设备 / 应用抽样。可选 `facets` 投影，默认全要。有界探测在 handler：不做全盘枚举、不扫端口 |
| `os_log` | CEO + worker | 免批 | 有界 OS 事件摘要（来源/时间窗/级别；条数·字节硬上限；密钥形脱敏、路径可保留；Win=Get-WinEvent / Linux=journalctl；禁整机倾倒） |
| `shell` | CEO + worker | `host` 轴 | 短时本机命令；cwd **由运行时注入**已授权根（默认工作区根；无授权根时 home）；**禁止**模型填任意 abs。Win PowerShell / Unix `$SHELL -lc`；毁灭性 + 长驻 + 静默安装启发式硬拒（dev server → `run`（`background`）；装软件 → `install_package`）；禁倾倒 Event Log / journalctl / 扫 `*\logs` |
| `open_settings` | CEO + worker | `host` 轴 | 白名单系统面板 `sound\|display\|network\|apps\|about` |
| `set_audio` | CEO + worker | `host` 轴 | 切默认音频设备（须先 `status` 观测设备） |
| `restart_service` | CEO + worker | `host` 轴 | 白名单服务（起步仅 `Audiosrv`） |
| `install_package` | CEO + worker | **恒确认**（按参数，对齐 `git push`） | manager∈{winget,brew,apt} + package id；brew 可选 `cask`；`host=session` / turn grant **不覆盖**；超时默认 600s、上限 900s |

`<工作区>`：短坐标 + 缺口（只报未装配的 `run` / `package_install` / `host` 等）；云 reach =「执行：云端；本机 Host 以开场表 / 缺口为准」。通道是否可达由装配表达，**不**每轮打 INFO、**不**把电量/磁盘/应用列表塞进每轮上下文。`host_ping` 不进模型面（通道不可达则整面不装配）。**`package_install` 与 `run`**：云端同一装配谓词（桌 guest）；本机装依赖跟执行类，装本机软件仍须开场表有 `host` + `host(action=install_package)`。

**否决**：13 个 `host_*` 旧名注册或转发兼容层；每加一种观测就加一个工具；只放开 `host(action=shell)` 当装包 / 倒日志闭环；用工具名隔离 CEO / 恒确认；Web/手机假装已查本机；任意 URL / exe 静默装；云 Alone 假装装到用户本机；模型填任意 abs cwd（cwd 由运行时注入已授权根）；单点音频特例工具；用「工具很多」当隐私闸（隐私写在 handler 返回什么）。

→ 见代码：`desktop/channel.py` · `tools/builtin/host.py` · `runtime/pipeline/prepare.py`

## 四B′、Computer Use（本机 GUI）⏳ 已确认未落地 {#computer-use}

> **产品心智**：授权后**读懂本机窗口里的控件**、点按钮、填输入框——验收 App / 走设置向导。与 Browser（网页）、`host(action=shell)`（命令行）正交。详细契约在维护者本地；此处只留已确认边界。

| 项 | 契约 |
|---|---|
| 状态 | ⏳ 蓝图已确认 · **代码未实现** |
| 可用性 | **Windows 首刀**（mac 另一刀：Accessibility + Screen Recording 两道 TCC 授权 + 公证链路，成本非同量级；Linux 不做）；仅桌面 + Host 回填通道可达；Web/手机不装配（跨端履约另案 / 未来云端架构，不绑本刀） |

| 谁持有 | **CEO+worker** 同形（档位 1）；审批走 `host` 轴 / GRANTABLE，不因角色另造闸。超规模自判 `delegate` |

## 四D、Git 闭环 {#git-闭环}

> **产品心智**：结构化 `git` = Agent 工程工具；用户 SCM = 会话旁版本面板。两边同一工作区仓；**回合 zip 基线**仍是「本回合可回滚」主路径，与 git **正交**（不合并语义、不做三方 merge UI）。主路径禁止教模型用 `host(action=shell)`/`run` 自由敲 git 当闭环。凭据：**人配置、进程继承、失败诚实**——工具永不收密码参数。→ [安全 · git force 统一 DENY](/docs/05-平台与运维/安全权限与治理.md) · [前端 UX · 改动双轨](/docs/04-前端/前端UX设计.md)

现行面：`status`/`diff`/`log`/`show`/`blame`/`add`/`commit`/`branch`/`checkout`/`fetch`/`pull`（ff-only）/`push`/`stash`/`merge`/`rebase`/`cherry-pick`/`tag`/`remote`/`clone`/`create_pr`（GitHub-only）/`init_baseline`。push / 开 PR 恒确认。force、保护分支、`reset`/`clean`、stash drop/clear、remote remove、tag 删除硬拒。pull 冲突诚实停。**工具** `git clone` 仅 GitHub http(s)；**UI** `clone_repo` 为任意 http(s)+SSRF。`create_pr` 仍 GitHub-only。私仓账户级 PAT（设置 · Git 凭据，AES-GCM）；Local 继承 OS credential helper / `gh auth`；认证失败指向「去设置凭据 / 打开已配置凭据的本地仓」。Local 通道：ServerWorkspace / Sidecar 同进程 subprocess；LocalWorkspace 经桌面 `git_run`（闭集 op，与 UI 的 `git_repo_status`/`git_scm` 分立）。有 `local_subpath` 时 cwd/探测/`init_baseline` 均落该文件夹子目录（与 file_* 同基准，禁止打到共享容器根）；无 subpath 则根即该文件夹。

| 面 | 要点 |
|---|---|
| 用户 SCM | 分支+dirty 条 →「改动」双轨（zip ∥ git 列表）→ 人可 stage/commit/push/pull，与结构化 git 同口径 |
| 同仓串行 | 按仓串行会写 index 的子命令；只读与 `push`/`create_pr`/`branch`/`tag`/`remote` 不排队；等不到报 `repo_busy` |

**否决**：AI 代持密码；改动 tab 冒充三方冲突工具；默认放开 hard reset / force 保护分支；全局 git 锁（不同仓库/工作区互相排队）。→ 见代码：`tools/builtin/git_ops/`（`repo_lock.py` · `policy.py` 超时表）· `workspace/channel.py`（`GIT_RUN`）· `workspace/git_credentials.py` · `workspace/github_pr.py` · `runtime/safety_breaker.py` · `runtime/approvals.py` · 桌面 `main/fs/workspace/gitRun.ts`
