# 角色提示与身份

> **定位**：头衔咒语（「你是资深架构师 / 产品经理 / 法律专家」）的文献证据，以及它和本产品 `<身份>` 的边界。**提示词写什么 / 不写什么**仍归 [上下文工程 · 提示词设计原则](/docs/03-AI核心/上下文工程.md#提示词设计原则)；**不做预制角色**仍归 [定位 · 五、Agent 角色策略](/docs/01-产品/产品定位与品牌.md)。本文不发明第二套入场闸。
>
> **主循环归属**：「**组**」时身份合同怎么写（头衔不是能力）；常驻 `<身份>` 为什么不写「资深某某」→ [主循环](/docs/01-产品/产品定位与品牌.md)。

**结论**：一句职业头衔几乎不能让模型更懂那个领域。它主要改口吻、篇幅和自信。顶会对客观对错的系统评测，平均效果是零到略负；无关修饰（名字、爱好）还能大幅掉分。真正有用的角色提示写的是**职责、约束和判断标准**，不是头衔。

---

## 一、三种「角色」不要混

| 人们嘴里的「角色」 | 实际在干什么 | 文献口径 |
|---|---|---|
| **头衔咒语**：「你是资深律师」 | 把采样推向「专家口吻的文本」 | 对事实准确率基本无效，有时更差 |
| **行为合同**：「你只对架构取舍负责；证据不够就说不够」 | 改决策边界、拒答、输出形状 | 这才是系统提示该干的事；本产品叫 `<身份>` |
| **概念框架**：模型始终在演一个对话角色 | 解释「看起来像有自我」 | Shanahan 等 *Nature* 2023：防拟人化的框架，**不是**提分技巧 |

机制：模型不会因为被任命而获得新权重。「专家」只是把条件分布拨向训练语料里「专家在说话」的那一块——那一块同时包含好论证、行话、以及自信的胡说。

---

## 二、对准确率：硬证据偏否定

**Zheng 等，EMNLP Findings 2024**（目前最常被引的系统评测）：162 个身份、4 个开源模型族、2410 道 MMLU。相对「不加任何角色」，**整体不提升；不少身份还略降**。领域对齐（律师答法律题）统计显著但效应极小。事后挑「每题最佳身份」能涨，但**自动选出这个身份 ≈ 随机抽**。结论：单个身份的效果很大程度上是噪声。

**Luz de Araujo & Roth，EMNLP 2025 *Principled Personas***：9 个当代开源模型、27 项任务，三条应然标准——

1. **专家身份不该比没身份更差** —— 多数任务为正或无显著；仍有不可忽略的任务会变差。
2. **无关细节不该影响对错** —— 失败得很惨：名字、喜欢的颜色，最差可掉近 30 个百分点；扩模型也救不回来。
3. **学历 / 专业度 / 是否对口领域该单调变好** —— 经常不显著或跨任务不稳定。

并点出产品风险：用户会因为「专家」外壳高估可靠性。

**同作者，PLOS ONE 2025**：7 个模型、162 个身份。身份之间的准确率差距可以很大（GPT-3.5 在 TruthfulQA 上最好/最差差约 38 个百分点）；GPT-4 收到约 4.6——**更强的模型对头衔更不敏感**。领域专家并不总是该领域第一名。给模型一个少数群体身份，能降低对「自己这群人」的刻板偏见，但答相关题的正确率会掉。部分人口统计身份会触发拒答。

合在一起：**角色会改行为，但「资深」不是可靠的提分旋钮；选错身份的代价可以很大。**

---

## 三、改的是口吻与自信，不是知识

ACL Findings 2025（*Do Language Models Mirror Human Confidence?*）：给 GPT-4o / Claude 3 / Llama-3-70B 套「专家 vs 外行」等身份，**报告的自信会按刻板印象涨跌，底层答题正确率几乎不变。**

法律场景尤其危险。Dahl 等 *Large Legal Fictions*（Stanford / *Journal of Legal Analysis*）：ChatGPT-4 对联邦案例的可核验提问，幻觉大约 58%（Llama 2 到 88%），且系统性高估自己的确定性。没有证据表明「你是律师」能压幻觉；结合自信实验，合理预期是：**外壳更专业，错误更难被用户看出来。**

厂商文档和论文测的不是同一件事。[Anthropic 教程](https://github.com/anthropics/prompt-eng-interactive-tutorial)推荐角色提示改语气，甚至举数学例子——这是产品建议，不是对照实验。OpenAI 更新的 Prompt guidance 更接近论文：Role 一两句定职能即可；Personality 管听感，Collaboration 管怎么共事，**两者都不能替代目标、成功标准和工具规则。**

## 四、有条件的正面结果（不要外推成「头衔有用」）

| 来源 | 测到了什么 | 不能推出什么 |
|---|---|---|
| Kong 等，NAACL 2024 | 两阶段角色戏在 GPT-3.5 零样本推理上涨分（AQuA 53.5%→63.8%）。作者解释为**诱发思维链** | 「你是数学老师」单独提分；对已会逐步想的强模型仍有同样边际 |
| Xu 等，*ExpertPrompting* 2023（预印本） | 为每条指令生成很长的定制专家小传，GPT-4 **偏好打分**更高 | 有金标的对错；GPT-4 偏好常偏向更长、更铺陈 |
| *The Prompt Report*（综述） | 角色提示对开放写作 / 文风更有用，对基准准确率只是「有时可能」 | 出厂常驻应写「资深某某」 |
| 厂商系统提示实践 | 角色能稳定语气和协作风格 | 头衔 = 领域能力 |

何时角色提示仍值得写：

1. **文风 / 受众 / 产品人格**——「对非技术创始人先结论后机制」。这是风格条件，不需要「资深」。
2. **仿真或对戏**——教育、游戏、用户研究。评的是像不像，不是 MMLU。
3. **活已经拆给不同人时**——编制写谁拍板、什么证据才算数、哪里必须对质。不写「你是资深 PM」。这只约束写法。
4. **诱发推理步骤**——弱模型、零样本、还没有 CoT 时，角色戏有时能当思维链开关。强模型 + 已经会逐步想时，边际很小。
5. **领域正确率**——头衔几乎不够。有效的是对口材料、工具、必须引用的结构、验收标准。身份最多当索引：「你现在按架构师的决策清单工作」，清单本身要写出来。

## 五、对本产品的操作形

| 想要的 | 写出厂头衔？ | 写什么 |
|---|---|---|
| 架构取舍 | 否 | 约束：先目标与失败模式，再组件；新依赖说清成本；禁止为复用旧实现裁需求 |
| 产品判断 | 否 | 决策权：谁用、解决什么、产品上长什么样；没这三问不准谈实现 |
| 法律 / 合规 | **有害倾向** | 强制：管辖、时效、出处；不确定就说不确定。头衔会抬自信、不降幻觉 |
| CEO / worker `<身份>` | 不写头衔、不复述工具图 | **残差**：只写工具表编码不了的策略差。CEO 工厂身份现空、不注入；回潮走入场闸。叶子 / 队长不写工厂身份；队长嵌套层数进开场事实。不写小传 / 大白话。署名 / 「你是谁」走 `product_help` → [上下文工程 · 宪法，非法例](/docs/03-AI核心/上下文工程.md#宪法非法例) |
| 队员临时专精 | 不写出厂角色库 | CEO 按任务在 `graph` 编制里给决策权与工具集；无固定「代码 Agent / 写作 Agent」→ [定位 · 五、Agent 角色策略](/docs/01-产品/产品定位与品牌.md) |

「资深」是纯噪声，还可能触发 §二 那种对无关修饰的脆弱性。用户要冻自己的编制（「你必须像某本范文」）→ 用户规则 / 上架，不出厂。

内容闸已经挡住「写得更专业」的质量菜谱。头衔咒语是同一类稀释的短形态：看起来像在赋能，实际不通过「删掉这句，前沿模型会用错本产品吗？」—— [内容闸](/docs/03-AI核心/上下文工程.md#内容闸可复现不服务更好)。

## 六、否决

| 方案 | 理由 |
|---|---|
| 出厂提示写「你是资深 X」指望更准 | §二：平均零到略负；选不准还掉分 |
| 用头衔修幻觉 / 当法律安全垫 | §三：自信涨、正确率不必涨；法律幻觉本就高 |
| 为每题搜「最佳 persona」 | Zheng：自动选择 ≈ 随机 |
| 把质量菜谱伪装成身份（「资深 PM 会先写用户故事」） | 内容闸：不服务「更好」；身份 ≠ 步骤菜谱 |
| 用人口统计身份当领域专家 | PLOS：偏见–准确率权衡；部分身份拒答 |
| 给身份加无关人设（姓名、爱好、性别）当「更真实」 | Principled Personas：无关属性可大幅掉分 |
| 用「不可重叠的决策权」论证多 Agent 因此更好 | 决策权边界是编制写法；多 Agent 不因此成为能力增益 |
