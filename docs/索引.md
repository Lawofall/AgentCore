# AgentCore 文档索引

设计文档总入口。`01`–`05` 公开主题分组。跨工具 AI 最短入口 → [`AGENTS.md`](/AGENTS.md)。

> **定位**：`docs/01`–`05` = What/Why；`.cursor/rules/` = How。  
> **⏳**：已确认未落地蓝图可出现在 `01`–`05`；详细提案不在公开仓。  
> **禁搜 / 禁写脚本**：产品 `trace_id` / `conversation_id` → `.cursor/rules/conversation-logs.mdc`（只跑 CLI）。  
> **贡献**：[CONTRIBUTING](/CONTRIBUTING.md) · [SUPPORT](/SUPPORT.md) · [SECURITY](/SECURITY.md)

| 文内标记 | 含义 |
|---|---|
| ✅ | 已落地 |
| ⏳ | 已确认、代码未实现 |
| 提案 | 讨论中（公开仓仅摘要） |

| frontmatter `status` | 含义（与文内 ⏳ **正交**） |
|---|---|
| `landed` | 主体已落地的现状说明书；文内仍可用 ⏳ 标未落地蓝图段 |
| `reference` | 入口 / 地图 / 术语 / 手册 / 操作速查 |
| `blueprint` | 主体仍是已确认目标设计（大段未落地）；少用 |
