# 产品手册

> 用户向说明的**导航页**。正文在桌面应用内 `#/toolbox/manual`；本页只串入口、信息架构与维护约定。CEO 按节取事实节的同一份正文（`consult("product_help:<节id>")`）；教练节与机制选读不导出。

## 入口

| 入口 | 说明 |
|------|------|
| 设置 · 关于 → 产品手册 | 四章全屏；另有命令面板。窄屏不上手册，关于页也不挂入口 |
| 功能页 `?` | 辩论室 / 升级等深链；**拍板卡 / 审批卡不挂**（挡路时不跳手册）；**全屏协作画布不挂**（看这张图时不跳走读图例）。登记处 `ManualHelpLink.tsx` |

## 设计目标

1. **5 分钟上手**（说目标 → 看团队 → 收结果——[产品主循环](/docs/01-产品/产品定位与品牌.md)的短版本）
2. **卡住能查到**（拍板、审批、跑偏、文件在哪）
3. **好奇再深挖**（协作图 / 机制）— 真选读，不挡主路径
4. **一句只说一次**；用户文禁止实现内部名

口径：**实用说明，不营销**。品牌理念最多在 intro「这是什么」出现一行。

## 章节地图

1. **认识 AgentCore** `#/toolbox/manual/intro`
   - `what` 这是什么 · `mindset` 你怎么用 · `quickstart` 5 分钟上手
2. **指挥你的团队** `#/toolbox/manual/collaboration`（按用户动作）
   - `briefing` 怎么下任务 · `progress` 看进度 · `checkpoint` 检查点与审批 · `autonomy` 对话边界 · `debate` 辩论室 · `control` 中途插手 · `memory` 规矩与旧对话
3. **看懂协作（选读）** `#/toolbox/manual/mechanism`
   - `live` 看团队跑一遍 · `legend` 看懂协作图 · `panorama` 从发消息到收答案 · `scenarios` 机制场景
4. **参考 · 排查 · 信任** `#/toolbox/manual/reference`
   - `tools` 工具与能力 · `workspace` 工作区与文件 · `settings` 设置速查 · `faq` 常见问题 · `troubleshooting` 故障排查 · `privacy` 数据与隐私 · `glossary` 术语

用户服务协议 / 隐私政策在应用内「设置 · 关于」，正文 `apps/desktop/src/renderer/pages/legal/content.ts`。不另做仓内 Markdown 镜像。

旧节 ID（`collab-overview` / `roles` / `continuation` / `turnflow` / `chat`）→ `sectionIds.ts` 别名表，深链滚到新节。

## 内容架构

正文 = `pages/toolbox/manual/content/*.ts`（纯数据 block）→ `BlockRenderer` / `ChapterRenderer`。节 ID：`sectionIds.ts`；路由：`paths.ts`；真组件：`embedRegistry.ts`。门禁：术语 lint + 路由/锚点 + embed key（`manual/__tests__/`）；截图：`pnpm -C apps/desktop shoot:manual`。

## 维护约定

- 用户向正文只改 `content/*.ts`；机制/契约改 `docs/03`–`05`，手册只加用户能懂的一句 + 深链。
- 新功能先问「服务[主循环](/docs/01-产品/产品定位与品牌.md)哪一拍」——答不上来的不进手册；再问「指挥动作还是查阅？」定落章。`?` 入口一律走 `ManualHelpLink.tsx`。
- **铁律**：用户可见文禁止实现内部名（如 `ask_user` / `plan_review` / `run_redirect` / SSE / Wave…）；同一技能全书只展开一次，他处一句 + 跳转；FAQ 每条须自含短答，禁止「见××节」作唯一答案。
- 删节时在 `MANUAL_SECTION_ALIASES` 登记旧 ID → 新节，勿裸删断链。
- **产品 AI 同源（事实节）**：用户向正文只改 `content/*.ts`，再 `pnpm sync:manual-corpus`（`pnpm sync:manual-corpus:check` 拦漂移）。`ai: "off"` 的教练节（你怎么用、5 分钟上手、怎么下任务）与机制选读只留手册，不进 CEO 语料；指向它们的旧节别名同样不导出。CEO 索引卡（身份 / 官网 / 入口 / 产物合同）在 `runtime/skills/product_help.py`；导出的事实节在 `product_help_corpus.json`。检查点「何时会问」与挡路拍板同一口径。桌面深链 `#/toolbox/manual/{章}?s={节}` 须过 server 侧节 ID 门禁（对照 `sectionIds.ts`，含别名；扫索引卡 + 语料 href）。手机无手册壳——skill 只短答，勿承诺可点深链。节上 `availability` 标缺席端；路径差写进手册正文 callout。
