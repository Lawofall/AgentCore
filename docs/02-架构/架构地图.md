## 三条读序

**上手开发**  
本地开发 → 项目结构 → 后端架构

**改 API / 契约**  
核心接口定义 → 对应 `apps/server/agentcore/{module}/`

**改工作区 / 文件 / 本地引擎**  
工作区（§九 HTTP 契约；§五 双通道；§七 本机传统 / Sidecar）→ 前端 UX §九/§十三

## 与 03-AI 的分界

| 02 管 | 03 管 |
|---|---|
| 模块怎么拆、HTTP/DB 形状 | CEO/delegate、波次调度、ReAct |
| `WorkspaceBackend` 协议 | `WaveScheduler` 语义 |
| 部署与基础设施选型 | 工具装配、提示词、Run 模型 |

交叉点（SSE 事件、Interaction 挂起）以 [执行引擎](/docs/03-AI核心/执行引擎架构设计.md) 为准，02 只留 API 入口指针。
