## 选型速览

> 非模块权威。分层 → [后端架构](/docs/02-架构/后端架构.md)；部署 → [部署拓扑与环境](/docs/05-平台与运维/部署拓扑与环境.md) / [发布与门禁](/docs/05-平台与运维/发布与门禁.md)；LLM → [平台 LLM 接入](/docs/05-平台与运维/平台LLM接入.md)。

| 层 | 运行时 | 说明 |
|---|---|---|
| Agent 逻辑 | asyncio 协程 | I/O 密集 |
| 普通工具 | 同进程异步 | 文件 / 搜索等 |
| 代码执行 | 受限 subprocess（本地）/ gVisor（云端默认） | 云默认开；紧急 `GVISOR_ENABLED=false` |

沙箱原则：可插拔后端；云桌出站经 allowlist chokepoint、凭据不进沙箱、FS 边界（只挂当前桌）、全量审计 → [安全权限与治理](/docs/05-平台与运维/安全权限与治理.md)。

OpenAI 兼容 `OpenAICompatibleProvider` + `ProviderRouter` 前缀路由。dev 默认 BYOK；生产可切 `billing_mode=platform`。场景参数走命名 profile（`ProfileParams`），model 与 profile 解耦。→ [平台 LLM 接入](/docs/05-平台与运维/平台LLM接入.md)、[成本配额与计费](/docs/05-平台与运维/成本配额与计费.md)。

最小组件：PostgreSQL（+ pgvector ⏳ 未接入）· Redis（现状 mainly 限流可选）· S3 兼容（快照 / 头像 ✅；大附件 bucket ⏳）。Agent 长期记忆走工作区文件树，不落 PG → [记忆与知识](/docs/03-AI核心/Agent记忆与知识系统.md)。建模约定 → [核心接口 §六](/docs/02-架构/核心接口定义.md)。多 worker 现状一律拒启 → [部署拓扑 · API 进程约束：多 worker 一律拒启](/docs/05-平台与运维/部署拓扑与环境.md#api-进程约束多-worker-一律拒启)。

后端 / 桌面 / 跨端包 → [后端架构](/docs/02-架构/后端架构.md)、[前端技术](/docs/04-前端/前端技术与架构.md)、[项目结构](/docs/02-架构/项目结构.md)。自托管 Compose；现行发布主路径 `pnpm deploy:backend` → [平台地图](/docs/05-平台与运维/平台地图.md)、`cursor-deploy.mdc`。

桌面默认本地对话 ✅；云端对话并列 ✅；本机传统入口 + sidecar 默认同侧 ✅ → [工作区（云端权威）](/docs/02-架构/双模式工作区.md)。完全离线 / 跨进程 C2 → 详细提案不在公开仓。
