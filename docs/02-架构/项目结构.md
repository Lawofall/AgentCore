# 项目结构

> **状态**：✅ 已确定

---

## 一、总览

Monorepo 布局，前后端统一管理：`apps/server`（Python/FastAPI）、`apps/desktop`（Electron + React 产品页树，含生产 webapp / Capacitor 所挂 `dist-web`）、`apps/mobile`（Capacitor 原生壳：推送 / 安全存储 / 语音 / Android 更新；业务页已改挂桌面树）、`apps/admin`（独立运营控制台，详见 [`管理员后台.md`](/docs/05-平台与运维/管理员后台.md)）；根级 `packages/`（跨端规范与契约，非业务实现）；`deploy/` 为 compose 与环境模板；`docs/` 为设计文档；根 `assets/` 为跨应用品牌素材。

→ 见代码：`apps/server/agentcore/`、`apps/desktop/src/`、`apps/mobile/`（Capacitor 壳）、`packages/`。OpenAPI / SSE 类型同步 → 见 [本地开发.md](/docs/02-架构/本地开发.md)。

本文只记录目录树看不出来的**分层边界**与非显然依赖。

## 二、后端分层（apps/server/agentcore）

> 目录与文件清单 → 见代码：`apps/server/agentcore/`。模块体系与 runtime 子包见 [`后端架构.md`](/docs/02-架构/后端架构.md)。下表只记录**非显然依赖约束**。

> **约束的粒度**：硬约束守的是「调用方向不反转 + 入口层不干执行层的活」，**不是**「禁止 import 任何符号」。共享**类型/事件/常量/目录**不算违反（它们本就是上层要消费的数据）。真正的护栏是「不在路由里构建/调用 LLM、不在路由里驱动 runtime 执行；叶子工具不依赖业务模块」。落地由 import 边界测试守（见 `apps/server/tests/test_arch_boundaries.py`）。**表内并非每行都有测试守门**——已守（api ↛ 构建/调用 LLM · 不驱动 pipeline、`llm` 网关 ↛ db、db ↛ 上行、core ↛ 业务模块、叶子工具 web/grep/`file_ops`）零违规；未守的行以 ⚠️ 标出现状，别当已成立的约束用。

| 模块 | 不依赖（硬约束） | 例外 / 说明 |
|------|------------------|-------------|
| `api/` | **不在路由内构建/调用 LLM provider、不驱动 runtime 执行** | 路由薄层：业务经 `service`（`conversation`/`assist`/…）+ `schemas`。**允许** import `runtime`/`llm`/`tools` 的类型·事件·常量·目录（`runtime.events`、`llm.protocol.TokenUsage`、`llm.pricing` 常量、`tools.catalog`、投影纯函数如 `journal.runs_from_entries`）；**禁止**在 handler 里 `build_provider`/调 provider/驱动 pipeline——这类逻辑下沉 service（如 `assist.rewrite`）。**有意例外** `api/routes/inference/`：sidecar 出网代理热路径，路由内 `build_provider`（权威 → [平台 LLM 接入](/docs/05-平台与运维/平台LLM接入.md)）；`test_arch_boundaries` 排除这棵，勿扩豁免、勿借卫生下沉 service |
| `runtime/` | api（✅ 测试守）；conversation ⚠️ 见右 | 执行核心不回依入口层。<br>⚠️ **`runtime ↛ conversation` 未全消**：开轮 / 恢复轮已收口为 `runtime.turn.driver.TurnDriver`（`conversation.service` 注入）。点名文案在 `core.mentions`，行内药丸在 `core.inline_body`，裸聊绑盘在 `workspace.locate`，crash 工厂在 `conversation.crash_delegate`（`recover_hooks` 注入），`cost.recorded` 在 `observability.cost_log`，活动 ConversationStore bind/get 在 `runtime.conversation_store`（`conversation.service` 装 Cloud 默认工厂；sidecar initialize 绑 Outbox），关机 closer 在 `runtime.turn.closer`（`conversation.service` 注入 `close_user_stop_turn`）。其余反向仍在：`interrupt` 有意走 `get_cloud_store`（sidecar 活动 store 是 Outbox）、`log_export`（附件深读）。挂起 / 插话 / 收口确需回写对话，不按「全消」处理。缺席由 `test_arch_boundaries` 守：`queue.py` / `runs.py` ↛ `conversation.service`/`turns`/`turn_persistence`；runtime ↛ `conversation.mentions`/`scratch`/`inline_body`/`crash_delegate`/`common`/`turn_persistence`/`stage_card_resolve`；runtime 除 `interrupt.py` 外 ↛ `conversation.store`；`runtime/crash_delegate.py`、`runtime/kickoff/`、`pipeline/stage_card_debate.py` 不得复活。<br>**P3-A ✅**：根横切已收子包（`closing_posture/` · `turn/` · `suspension/` · `loop_controller/`），`runs/executor/` 按生命周期收口；四簇 + executor 均为权威包路径、**无根 / flat shim**（`agentcore.runtime.<cluster>.<leaf>`）。仍**单一** `runtime` 叙事（不做顶层 `runtime_*` 拆包）。规模软闸：无豁免勿新增 >800 行文件（`tests/test_arch_boundaries.py`）；微文件「非独立复用勿单独成文件」靠文档约定，首刀未合并 ContextVar 闩（只搬家） |
| `llm/` 网关本体 | 所有业务模块 + db | `deepseek`/provider 保持**纯网关、db-free**（凭据由调用方传入）。平台池热路径 `platform_pool` 只持内存快照（`iter`/`pick`/`replace_snapshot`），**不开 session**。`factory` 作为 composition root 可开 session 注入跨 provider worker；`turn_catalog` 云端开 session 读本回合目录，sidecar 窄票据改走账号 HTTP。二者属边界测试豁免 |
| `llm/` 凭据服务 | — | `provider_service`/`resolve` 按职责桥接 `db`（读用户 BYOK 密钥仓储 + 解密）；`platform_credential_service` 为平台池凭据桥（admin CRUD + 快照 reload / 启动刷新开 session）。与网关本体区分，**不属违规** |
| `tools/` 叶子工具 | 所有业务模块 | web/grep 与 `file_ops` ⊥ runtime/llm（`CrossTurnRetry` 在 `tools.cross_turn_retry`；写窗 stub 硬拒在 `tools.cleared_write_stub`；落盘验码失效走 `ToolContext.on_file_landed`）。边界测试守整棵 `file_ops` |
| `tools/builtin/` 编排原语 | — | delegate（含带现场续派）/debate/ask_user/escalate 等**经 tool-calling 触发的编排原语**，按职责依赖 `runtime`/`llm`（与 [`后端架构.md §三`](/docs/02-架构/后端架构.md) 「编排原语与 runtime 同构」一致） |
| `memory/` | ⚠️ 无硬约束（现状） | 用户规则注入实际直连 db：`document_store.py` · `always_quota.py` 等。逻辑散在 `agentcore/memory` + `runtime/context` + `runtime/runs` 三处（见 [后端架构](/docs/02-架构/后端架构.md)），`memory/` 非唯一入口；无边界测试守。巩固 / 情景包仍在树内，不当活产品。 |
| `db/` | 所有其他业务模块（含 `runtime` / `conversation`；由 `test_arch_boundaries` 守） | 共享纯函数在叶子：`core.message_merge`、`core.mentions`、`core.inline_body`、`costing`；`TurnLeaseRepository` 从 `runtime.leases` 导入，不经 `db.repositories` re-export |
| `core/` | 所有业务模块（共享类型，零向上依赖） | `config` 视为 core 之下的**配置地基**，可被 core 依赖（settings 非业务模块）。产品错误投影（SSE/HTTP 的 code/message/context）在 `runtime/error_fields.py`，可认 `llm.errors`；`core/errors.py` 只留异常类型与文案。本机在场 / 准备中止是带 `LOCAL_*` 码的 `AgentCoreError`。边界测试守 core 零向上依赖 |

## 三、跨端共享包（packages/）

pnpm workspace 纳入 `packages/*`、`apps/desktop`、`apps/mobile`、`apps/admin`（→ 见根 `pnpm-workspace.yaml`）。**共享的是规范 / 契约**；产品页（对话 / 文件 / IM / 设置 / 登录）走桌面 renderer 一棵树，不再各端全新建。

| 包 | 职责 |
|---|---|
| `protocol-conformance` | SSE 测试向量 + golden harness + `ProjectedTurn` schema |
| `protocol-fold-kit` | 协议 fold **常量/纯谓词**（编排工具集、marker 代言、finish→status）；**非** fold 实现核 |
| `contract-types` | SSE 事件判别联合（`events.ts`）；理想态后端 schema 生成 |
| `contract-rest-types` | OpenAPI 生成 REST 类型（desktop / admin 共享单一源；Capacitor 挂桌面树） |
| `design-tokens` | 跨端语义色 token |
| `graph-layout` | 协作图 ELK 布局纯函数（desktop + video） |

协议 fold 对账：根目录 `pnpm conformance`；后端 golden 重导 `python -m agentcore.conformance.export`。→ 见 [`前端技术与架构.md` §十 SSE 与协议一致性](/docs/04-前端/前端技术与架构.md)、`.cursor/rules/protocol-conformance.mdc`。

## 四、手机端（apps/mobile）

Capacitor 8 原生壳，**webDir = `apps/desktop/dist-web`**（同一棵产品页树）。鉴权在壳内走 Bearer + 安全存储（同源 cookie 用不了 `https://localhost`）。**Android 侧载 APK 已落地**（`release:android` → 官网 + CDN；见 [`发布与门禁` §1.6a](/docs/05-平台与运维/发布与门禁.md)）。产品页与 fold 只在桌面树；旧 SPA / 手机 fold **已清**。浏览器窄屏走 `app.`；独立 `m.` 站已下线。→ 产品减法见 [`前端技术与架构.md` §五](/docs/04-前端/前端技术与架构.md)；商店 / iOS → [路线图摘要](/docs/01-产品/产品路线图摘要.md)（详细提案不在公开仓 / 维护者本地）。
