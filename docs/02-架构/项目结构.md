# 项目结构

> **状态**：✅ 已确定

---

## 一、总览

Monorepo 布局，前后端统一管理：`apps/server`（Python/FastAPI）、`apps/desktop`（Electron + React）、`apps/mobile`（Vite SPA + Capacitor，Bearer 鉴权）、`apps/admin`（独立运营控制台，详见 [`管理员后台.md`](/docs/05-平台与运维/管理员后台.md)）、`apps/town`（AgentTown — Unity 6 LTS 观测客户端，配套后端 `simulation/`；UE/R3F 已退役）；根级 `packages/`（跨端规范与契约，非业务实现）；`deploy/` 为 compose 与环境模板；`docs/` 为设计文档；根 `assets/` 为跨应用品牌素材。

→ 见代码：`apps/server/agentcore/`、`apps/desktop/src/`、`apps/mobile/src/`、`packages/`。OpenAPI / SSE 类型同步 → 见 [本地开发.md](/docs/02-架构/本地开发.md)。

本文只记录目录树看不出来的**分层边界**与非显然依赖。

## 二、后端分层（apps/server/agentcore）

> 目录与文件清单 → 见代码：`apps/server/agentcore/`。模块体系与 runtime 子包见 [`后端架构.md`](/docs/02-架构/后端架构.md)。下表只记录**非显然依赖约束**。

> **约束的粒度**：硬约束守的是「调用方向不反转 + 入口层不干执行层的活」，**不是**「禁止 import 任何符号」。共享**类型/事件/常量/目录**不算违反（它们本就是上层要消费的数据）。真正的护栏是「不在路由里构建/调用 LLM、不在路由里驱动 runtime 执行；叶子工具不依赖业务模块」。落地由 import 边界测试守（见 `apps/server/tests/test_arch_boundaries.py`）。**表内并非每行都有测试守门**——已守的四条（api ↛ 构建/调用 LLM · 不驱动 pipeline、`llm` 网关 ↛ db、db ↛ 上行、core ↛ 业务模块）零违规；未守的行以 ⚠️ 标出现状，别当已成立的约束用。

| 模块 | 不依赖（硬约束） | 例外 / 说明 |
|------|------------------|-------------|
| `api/` | **不在路由内构建/调用 LLM provider、不驱动 runtime 执行** | 路由薄层：业务经 `service`（`conversation`/`assist`/…）+ `schemas`。**允许** import `runtime`/`llm`/`tools` 的类型·事件·常量·目录（`runtime.events`、`llm.protocol.TokenUsage`、`llm.pricing` 常量、`tools.catalog`、投影纯函数如 `journal.runs_from_entries`）；**禁止**在 handler 里 `build_provider`/调 provider/驱动 pipeline——这类逻辑下沉 service（如 `assist.rewrite`） |
| `runtime/` | api（✅ 测试守）；conversation ⚠️ 见右 | 执行核心不回依入口层。<br>⚠️ **`runtime ↛ conversation` 现状不成立**：模块级 6 处（`crash_delegate.py` · `coordination/inject.py` · `turn/steer.py` · `turn/interrupt.py` 等）+ 函数内懒导入 18 处，反向 93 处；无边界测试守。挂起 / 插话 / 收口确需回写对话，故不按「全消」处理——待收窄为显式接口后再补测试。<br>**P3-A ✅**：根横切已收子包（`closing_posture/` · `turn/` · `suspension/` · `loop_controller/`），`runs/executor/` 按生命周期收口；四簇 + executor 均为权威包路径、**无根 / flat shim**（`agentcore.runtime.<cluster>.<leaf>`）。仍**单一** `runtime` 叙事（不做顶层 `runtime_*` 拆包）。规模软闸：无豁免勿新增 >800 行文件（`tests/test_arch_boundaries.py`）；微文件「非独立复用勿单独成文件」靠文档约定，首刀未合并 ContextVar 闩（只搬家） |
| `llm/` 网关本体 | 所有业务模块 + db | `deepseek`/provider 保持**纯网关、db-free**（凭据由调用方传入）。平台池热路径 `platform_pool` 只持内存快照（`iter`/`pick`/`replace_snapshot`），**不开 session**。`factory` 作为 composition root 可开 session 注入跨 provider worker，属边界测试豁免 |
| `llm/` 凭据服务 | — | `provider_service`/`resolve` 按职责桥接 `db`（读用户 BYOK 密钥仓储 + 解密）；`platform_credential_service` 为平台池凭据桥（admin CRUD + 快照 reload / 启动刷新开 session）。与网关本体区分，**不属违规** |
| `tools/` 叶子工具 | 所有业务模块 | web/file_ops/grep/code_execute 等纯工具 ⊥ runtime/llm |
| `tools/builtin/` 编排原语 | — | delegate（含带现场续派）/debate/ask_user/escalate 等**经 tool-calling 触发的编排原语**，按职责依赖 `runtime`/`llm`（与 [`后端架构.md §三`](/docs/02-架构/后端架构.md) 「编排原语与 runtime 同构」一致） |
| `memory/` | ⚠️ 无硬约束（现状） | 记忆维护实际直连 db：`document_store.py` · `consolidation.py`（并 import `runtime.leases`）· `always_quota.py` · `episode_store.py` 等十余文件。逻辑散在 `agentcore/memory` + `runtime/context` + `runtime/runs` 三处（见 [后端架构](/docs/02-架构/后端架构.md)），`memory/` 非唯一入口；无边界测试守。 |
| `db/` | 所有其他业务模块（含 `runtime` / `conversation`；由 `test_arch_boundaries` 守） | 共享纯函数在叶子：`core.message_merge`、`costing`；`TurnLeaseRepository` 从 `runtime.leases` 导入，不经 `db.repositories` re-export |
| `core/` | 所有业务模块（共享类型，零向上依赖） | `config` 视为 core 之下的**配置地基**，可被 core 依赖（settings 非业务模块）。⚠️ 已知例外 `core/errors.py`：产品错误投影懒导入 `llm.errors` / `runtime.pipeline.errors` / `workspace.limits`·`protocol`，构成 core ↔ 上层互环，边界测试已显式豁免该文件——改 STREAM_ERROR / 通道死文案要进这里，`core` 不能再当无环叶子做分层推理 |

## 三、跨端共享包（packages/）

pnpm workspace 纳入 `packages/*`、`apps/desktop`、`apps/mobile`、`apps/admin`（→ 见根 `pnpm-workspace.yaml`）。**共享的是规范 / 契约，非业务实现**（各端 stores / services / fold / 组件各自全新建）。

| 包 | 职责 |
|---|---|
| `protocol-conformance` | SSE 测试向量 + golden harness + `ProjectedTurn` schema |
| `protocol-fold-kit` | 协议 fold **常量/纯谓词**（编排工具集、marker 代言、finish→status）；**非** fold 实现核 |
| `contract-types` | SSE 事件判别联合（`events.ts`）；理想态后端 schema 生成 |
| `contract-rest-types` | OpenAPI 生成 REST 类型（desktop / admin / mobile 共享单一源） |
| `design-tokens` | 跨端语义色 token |
| `graph-layout` | 协作图 ELK 布局纯函数（desktop + promo） |
| `town-story-packs` | AI 小镇 Offline/scripted 故事剧本包单一真相源（`pnpm gen:story-packs` 物化到 Unity StreamingAssets + 后端 `simulation/data`） |

小镇 3D 资产真源：`apps/town/Assets/TownAssets/`（vendored；见该目录 README）。
剧本内容真源：`packages/town-story-packs/`（勿再双改 `scripted.py` / StreamingAssets）。

协议 fold 对账：根目录 `pnpm conformance`；后端 golden 重导 `python -m agentcore.conformance.export`。→ 见 [`前端技术与架构.md` §十 SSE 与协议一致性](/docs/04-前端/前端技术与架构.md)、`.cursor/rules/protocol-conformance.mdc`。
